工作原理

证书在 HTML canvas 上以完整的 A4 横向大小绘制（297 x 210 mm，在 150 dpi 下——1754 x 1240 像素）。每当您输入时，每个元素都从您的文字重新绘制：双线边框和角落装饰、标题、带缎带尾巴的金色印章，以及草书风格的签名线。当您下载 PDF 时，完成的绘图由 pdf-lib 库放在 A4 横向页面上——与我们其他 PDF 工具使用的库相同——因此文件打印出来与预览完全一致。在批量模式下，相同的绘图按每个姓名重复一次，进入一份多页 PDF，并带有进度条，以便您可以观看长列表完成。

常见问题解答

我可以添加自己的标志或手写签名图片吗？

不在此版本中——设计使用内置印章和印刷的签名姓名。许多人会打印证书并在签名线上方亲手签名，这样看起来更 有人情味。

为什么姓名在一些证书上缩小？

非常长的姓名会自动缩小大小，使它们始终在边框内适合一行。缩短中间名通常能保持更大、更 宏大的尺寸。

批量模式除了姓名还会改变其他内容吗？

不。标题、课程、描述、日期、颁发者、签名和设计在每个页面上都相同——只有收件人姓名改变，就像一叠印刷品一次填写一个姓名一样。
