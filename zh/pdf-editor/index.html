Loona PDF Editor

简而言之： Loona PDF Editor 让您可以在任何 PDF 页面上添加文字、图片、形状和高亮，用涂白遮盖错误，自由手绘，并放置绘制或输入的签名 — 然后下载完成的文件。它添加和遮盖内容；它不会重写 PDF 的原始文字。

需要在表单上添加备注、更正发票上的总额、放置您的徽标或签署一封信 — 无需打印和扫描？在这里打开 PDF，将所需内容直接添加到页面上，然后下载完成的文件。一切都在您的设备上完成：无上传、无注册、无页数限制、无水印。

如何编辑 PDF

  1. 点击上方框并选择您的 PDF。文件会直接在您的浏览器中打开 — 不会上传任何内容。
  2. 选择一个工具：文字、矩形、高亮、涂白或绘图 — 或添加图片或签名。
  3. 在页面上点击或拖动以放置元素。使用选择工具移动它，拖动金色角调整大小，或在改变主意时将其删除。
  4. 使用“上一页”/“下一页”按钮或页面下拉菜单在页面之间移动。每个页面都保留自己的元素，因此您可以逐页编辑长文档。
  5. 当一切无误后，点击“导出编辑后的 PDF”。您的添加内容会被压平到原始页面上，完成的文件将以 您的文件名-edited.pdf 的形式下载。

此编辑器能做什么、不能做什么

这是一个叠加式编辑器，我们宁愿直白地告诉您这意味着什么，也不愿让您日后才发现。

它能做的

  • 添加新文字 — 在页面任意位置，使用五种经典字体（Helvetica、Helvetica Bold、Times、Times Bold 和 Courier），任意大小和颜色。
  • 添加图片 — 徽标、印章、照片 — 并放置您用鼠标或手指绘制的签名，或输入姓名生成的签名。
  • 绘制矩形和高亮来标注文档，并用画笔工具自由手绘。
  • 用涂白遮盖错误：在错误的单词或数字上画一个不透明的方块，然后在上面输入更正内容。
  • 您添加的一切都可以在任何页面上移动、调整大小和删除，并导出一份压平的成品 PDF。

它不能做的

  • 它不会像文字处理软件那样更改、移动或重排 PDF 的原始文字。文件中已有的文字会准确地保留在原位置。
  • 要修正错字，请用涂白遮盖错误的单词，然后在上面输入更正内容 — 这是诚实的变通方法，对表单、发票和信件都非常有效。
  • 这里的涂白是视觉遮盖：被遮盖的内容仍存在于方块下方的文件内部。如果在分享前必须永久删除敏感内容，请改用我们的 遮盖 PDF 工具，它会将方块固化到重建的页面图片中。
  • 它无法打开受密码保护的 PDF，也不是表单填写工具 — 对于已有的表单字段，请使用 填写 PDF 表单。

隐私 — 您的文件永远不会离开您的设备

每一步 — 打开、渲染、编辑和导出 — 都使用 JavaScript 在您的浏览器中 100% 运行（PDF.js 渲染页面，pdf-lib 编写完成的文件）。您的 PDF 从不上传到服务器，从不存储，也从不被我们看到，并且编辑器本身在您工作时不会发出任何网络请求。关闭标签页，一切都会消失。无需注册，无页数限制，无水印。

常见问题

它能更改我 PDF 中的原始文字吗？

不能。Loona PDF Editor 是在页面上方添加和遮盖内容；它无法重写、移动或重排文件中已有的文字。要修正错误的单词，请在其上画一个涂白方块，然后在上面输入更正内容 — 视觉上，页面就会完全按照您的意愿呈现。

如何用此编辑器修正 PDF 中的错字？

选择涂白工具，在错误的单词上拖动一个方块。然后选择文字工具（或“添加文字”按钮），以匹配的字体和大小输入更正后的单词，并将其拖到涂白上方的位置。导出后，完成的页面只显示更正内容。

我的 PDF 会上传到服务器吗？

不会。编辑器完全在您的浏览器中运行：PDF.js 在屏幕上绘制页面，pdf-lib 在您的设备上构建完成的文件。没有任何内容被上传、存储或被我们看到，也无需注册。

Loona PDF Editor 真的免费吗？

是的 — 免费，无需注册，无页数限制，导出的文件也没有水印。您可以编辑任意多的 PDF。

我能在此编辑器中签署 PDF 吗？

可以。点击“添加签名”，用鼠标或手指在签名板上绘制您的签名 — 或输入您的姓名将其转换为签名图片 — 然后将其作为可移动、可调整大小的图片放置在当前页面上。这是视觉签名，不是基于证书的数字签名；对于仅签名的任务，您也可以使用我们专门的签署 PDF 工具。

涂白会永久删除它遮盖的内容吗？

不会，我们不会假装它会。涂白在内容上绘制不透明的遮盖层，使其不再显示或打印 — 但原始内容仍存在于文件内部的下方。如果内容敏感且必须彻底消失，请使用我们的遮盖 PDF 工具，它会将每个页面重建为图片并将方块固化其中。

我添加的文字可以使用哪些字体？

五种标准 PDF 字体：Helvetica、Helvetica Bold、Times、Times Bold 和 Courier，任意大小和颜色。由于这些字体内置于每个 PDF 阅读器中，您添加的文字可以在任何地方正确显示，而不会使文件变大。

我添加的元素会保持在正确的位置吗？

会。元素按页面以真实的 PDF 坐标（点）存储，而不是屏幕像素，因此导出文件时，每个元素都会以您安排的确切位置、大小和顺序绘制到其页面上 — 无论页面大小如何。

工作原理

当您打开文件时，PDF.js 会将当前页面渲染到浏览器中的画布上。您添加的一切 — 文字框、图片、矩形、高亮、涂白方块、自由手绘线条或签名 — 都绘制在该画布上方的透明图层上，并以真实的 PDF 坐标（以点为单位）为该页面存储。切换页面永远不会混淆元素：每个页面都按您添加的顺序保留自己的列表。导出时，pdf-lib 打开您的原始文件，并以相同的坐标将每个元素绘制到其页面上，将屏幕上自上而下的位置转换为 PDF 自己的坐标系，然后以名称中带有 -edited 的方式保存结果。由于原始页面被保留，只有您的添加内容绘制在上方，输出仍然是真正的、可选择文字的 PDF — 这与将页面重建为图片的工具不同。

实际示例

一份发票 PDF 显示了错误的总额“Rs 4,500”，并且缺少您的企业徽标。您在旧总额上拖动一个涂白方块，在上面用 Helvetica Bold 添加文字“Rs 5,400”，将徽标图片放置在页面顶部，并在签名框中输入您的姓名在底部签名。点击一次“导出编辑后的 PDF”即可下载 invoice-edited.pdf — 已更正、已加品牌、已签名，发票的其余部分保持不变。
