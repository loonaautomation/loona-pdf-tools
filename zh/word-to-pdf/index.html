常见问题

它支持 .doc 文件吗？

不支持——仅支持现代 .docx 文件。旧的二进制 .doc 格式无法在浏览器中读取。如果您有 .doc 文件，请在 Word 或 Google Docs 中打开它，先另存或导出为 .docx，然后在此处转换。

PDF 会和我的 Word 文档看起来一模一样吗？

不会完全一样——我们直言不讳。本转换器是内容忠实，而非布局忠实：您的文本、标题、列表、表格和图片会干净、易读地呈现，但精确的页面布局、栏、文本框、SmartArt、形状以及精确的字体和间距可能会改变或丢失。要获得像素级精确副本，请从 Word 本身打印为 PDF。

标题、表格和图片会保留吗？

会。标题级别、粗体和斜体、项目符号和编号列表、表格和内嵌图片都会按正确顺序带入 PDF。提供两条路线：设备上即时下载，以及使用浏览器自己的 PDF 引擎获得最接近布局的打印视图。

我的文档会上传到服务器吗？

从不。.docx 文件完全在您的浏览器中使用从本站加载的 JavaScript 库打开和转换。任何内容都不会被发送、存储或被我们看到——关闭标签页，一切都会消失。

它真的免费且无限制吗？

是的——免费、无限制、无需注册、无水印，我们不设每日限额。

技术原理

.docx 文件由 Mammoth.js（v1.13.0）解包并转换为带样式的 HTML，然后用 pdf-lib 排版为真正的基于文本的 PDF。两个库都保存在本站自己的库文件夹中——您工作时不会从 CDN 获取任何内容，也没有任何内容离开您的设备。打印视图将同样的带样式 HTML 写入打印优化页面，并让浏览器自己的 PDF 引擎进行渲染，这就是其布局最接近原件的原因。两条路线都不会将您的文档截图为图片：文字保持为您可以选择、复制和搜索的文本。
