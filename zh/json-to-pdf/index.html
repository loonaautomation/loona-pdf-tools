JSON 转 PDF 转换器

简而言之： 本工具验证并美化打印您的 JSON，然后将其排版为干净的等宽 PDF——在您的浏览器中。

API 响应、配置文件和数据导出经常需要与不阅读原始 JSON 文件的人分享。分页的 PDF 是通用的交接方式。

隐私设计： 您的文件用 JavaScript 在您的浏览器中 100% 处理。它们永远不会上传到服务器，永远不会存储，也永远不会被我们看到——关闭标签页，一切都消失了。

工作原理，分步说明

  1. 粘贴 JSON 或加载 .json 文件。
  2. 按“转换”——无效的 JSON 会连同确切的解析错误一起报告。
  3. 下载格式化后的 PDF。

常见问题

JSON 会被验证吗？

是——它先被解析；无效的 JSON 会产生解析器的确切错误，而不是损坏的 PDF。有效的 JSON 以 2 空格缩进美化打印。

为什么用等宽字体？

JSON 是代码：Courier 布局使缩进和嵌套保持可读，与编辑器完全一样。

我的数据会被上传吗？

不——解析和 PDF 构建在您的浏览器中进行。

幕后原理

JSON 被解析（这验证了它），以一致的缩进重新序列化，然后用 pdf-lib 在 Courier 中逐行绘制，换行长行并自动分页。

实际示例

一份 900 行的 API 响应变成 12 页 PDF，可以附加到错误报告中——任何人都能阅读，无需 JSON 查看器。
