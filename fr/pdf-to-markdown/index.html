Convertisseur PDF en Markdown

En résumé : cet outil extrait le texte d'un PDF et le reconstruit en Markdown structuré, avec les titres détectés depuis les tailles de police — dans votre navigateur.

Les PDF sont faits pour lire, pas pour réutiliser. Ce convertisseur récupère le texte en Markdown que vous pouvez modifier, publier ou coller ailleurs — avec une étape d'éditeur honnête avant le téléchargement.

Cliquez pour choisir un fichier PDF
ou glissez-déposez-le ici — les PDF basés sur le texte fonctionnent le mieux
Privé dès la conception : vos fichiers sont traités à 100% dans votre navigateur avec JavaScript. Ils ne sont jamais envoyés sur un serveur, jamais stockés et jamais vus par nous - fermez l'onglet et tout disparaît.

Comment ça marche, étape par étape

  1. Choisissez un PDF textuel.
  2. Examinez le Markdown extrait dans l'éditeur — corrigez toute ligne que le convertisseur a mal lue.
  3. Téléchargez le fichier fini.

Questions fréquemment posées

Comment fonctionne ici la conversion PDF en Markdown ?

PDF.js lit la couche de texte du document — le même texte que vous pouvez sélectionner dans un lecteur — et reconstruit les lignes dans l'ordre de lecture. Les tailles de police sont comparées à la médiane du document : les lignes beaucoup plus grandes deviennent des titres de premier niveau, les lignes modérément plus grandes deviennent des sous-titres.

Les images et la disposition survivront-elles ?

Non — et cet outil le dit d'emblée. La sortie Markdown est une reconstruction textuelle : les images ne sont pas intégrées et les mises en page en plusieurs colonnes sont lues colonne par colonne au mieux selon l'ordre du texte. Pour une copie parfaite au pixel près, le PDF lui-même est le document ; cette conversion sert à réutiliser les mots.

Mon PDF est un scan. Fonctionnera-t-il ?

Les PDF numérisés n'ont pas de couche de texte, donc l'extraction ne trouve rien. Passez d'abord le scan dans l'outil OCR sur Loona Text Tools, puis convertissez le texte obtenu.

Mon PDF est-il envoyé ?

Non — l'extraction se fait dans votre navigateur avec PDF.js.

Sous le capot

L'extraction regroupe les éléments de texte en lignes selon leur position verticale, les trie de gauche à droite, et mesure la taille de police de chaque ligne par rapport à la médiane de la page pour attribuer les niveaux de titre. Les sauts de page deviennent des séparateurs. Le résultat apparaît dans l'éditeur ci-dessus pour que vous puissiez tout corriger avant le téléchargement — la conversion de PDF n'est jamais parfaite, et prétendre le contraire serait malhonnête.

Exemple concret

Un rapport PDF de 12 pages devient un document Markdown structuré — le titre comme titre principal, les titres de section comme sous-titres, le corps comme paragraphes — prêt à coller dans un site web ou un éditeur de documents.
