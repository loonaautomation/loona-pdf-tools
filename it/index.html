Come funzionano Loona PDF Tools

  1. Scegli uno strumento e aggiungi il tuo file. Il tuo PDF o le tue immagini vengono letti dal tuo browser stesso - nulla viene inviato da nessuna parte.
  2. Regola le opzioni. Intervalli di pagine, formati, livelli di qualità e stili sono tutti sotto il tuo controllo.
  3. Scarica il risultato. Il file finito viene creato sul tuo dispositivo e si scarica all'istante.

Perché le persone si fidano degli strumenti basati sul browser

La maggior parte dei siti PDF online ti chiede di caricare documenti sensibili - carte d'identità, estratti conto bancari, contratti - sul server di uno sconosciuto. Loona PDF Tools è costruito nel modo opposto: il codice di elaborazione viene dal tuo file, non il contrario. Ciò significa risultati più rapidi, privacy che funziona ovunque e nulla di tuo memorizzato, registrato o condiviso. Chiudi la scheda e ogni traccia del tuo documento è sparita.

Domande frequenti

Loona PDF Tools è davvero gratuito?

Sì - ogni strumento è 100% gratuito, senza registrazione, senza filigrane e senza limiti giornalieri imposti da noi.

I miei file vengono caricati sul vostro server?

Mai. Ogni strumento funziona al 100% nel tuo browser utilizzando librerie JavaScript caricate una volta da questa pagina. I tuoi file restano sul tuo dispositivo dall'inizio alla fine.

Quali dispositivi sono supportati?

Qualsiasi browser moderno su telefono, tablet o computer - Chrome, Edge, Firefox e Safari funzionano tutti.

Gli strumenti funzionano offline?

Una volta caricata la pagina di uno strumento, la sua elaborazione funziona anche se la connessione cade, perché tutto avviene localmente sul tuo dispositivo.

Posso usare questi strumenti per documenti d'ufficio o scolastici?

Assolutamente sì - è proprio per questo che sono stati creati: moduli, compiti, report, scansioni e documenti di candidatura.
