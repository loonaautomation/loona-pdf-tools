Flatten PDF Online - Free

In short: the Flatten PDF tool makes a PDF final: it bakes fillable form fields into the pages themselves, so the answers print exactly as seen and can no longer be typed over, with an optional image mode that rebuilds every page as a picture and flattens absolutely everything on it.

Sending a filled form as-is leaves its answers editable by anyone who opens it. Flattening locks the document the way printing does - what you see is permanently what everyone gets.

Frequently Asked Questions

What does flattening actually do to form fields?

Each field's current answer is drawn onto the page as ordinary page content, and the field itself is deleted. The document then opens with no fillable fields at all - answers can be read and printed, but not edited as form data.

If my PDF has no form fields, does flattening do anything?

Form flattening alone changes nothing (the tool tells you the field count up front, so there are no surprises). Image mode still rebuilds the pages, which flattens annotations and layers and removes the text layer.

Will annotations and stamps be flattened?

In standard form-flatten mode, form fields are flattened; some separate annotations may remain. Image mode flattens everything visible on each page, because the page becomes a single picture.

Can flattening be undone?

No - that is its purpose. Always keep the un-flattened original if you might need to change an answer later.

How it works

For form flattening, the tool opens your PDF with pdf-lib, refreshes every field's appearance so its current answer is drawn correctly, then calls the library's flatten operation: field appearances are merged into the page content streams and the form definition is removed. For Image mode, each page is instead rendered with PDF.js at 2x resolution and rebuilt as a JPEG page image in a new PDF - the same burn-in approach as our Redact tool - so every visible element, interactive or not, becomes part of one flat picture. Both run entirely in your browser.

Worked example

A parent fills an admission form with our Fill PDF Form tool, then flattens it here before emailing the school. The school can read and print every answer, but nobody can quietly change the phone number or tick a different box in the file they received.

Frequently asked questions

Does the flattened PDF print the same?

Yes. Before flattening, the tool refreshes each field's appearance so the value you see is the value baked onto the page. Printouts match the screen.

Does flattening shrink the file?

Form flattening usually changes size very little. Image mode normally makes files larger, because pages are stored as 2x JPEG images.

Why would a field answer look missing after flattening in some tools?

Some poorly-made forms store a value but no visible appearance for it. This tool regenerates appearances with pdf-lib before flattening, which fixes most such cases. If a value was never stored, there is nothing to bake in.

Is the text still selectable after flattening?

After form flattening, ordinary page text stays selectable - only the fields become fixed content. In Image mode nothing is selectable, because pages are pictures.

When should I choose Image mode?

When a document carries sticky notes, highlights, stamps or layered graphics that must be locked exactly as seen, or when a receiving system rejects files containing any interactive elements.
