Konverter Markdown ke PDF

Singkatnya: alat ini merender Markdown Anda ke halaman bergaya dan membuka tampilan cetak untuk disimpan sebagai PDF — di browser Anda.

README, catatan, dan draf yang ditulis dalam Markdown sering perlu meninggalkan editor sebagai dokumen. Konverter ini menatanya dengan bersih (isi serif, blok kode rapi) dan memberikan Anda PDF.

Privat berdasarkan desain: file Anda diproses 100% di browser Anda dengan JavaScript. File tidak pernah diunggah ke server, tidak pernah disimpan, dan tidak pernah dilihat oleh kami - tutup tab dan semuanya hilang.

Bagaimana cara kerjanya, langkah demi langkah

  1. Tempel Markdown atau muat file .md — pratinjau diperbarui secara langsung.
  2. Tekan tombol untuk tampilan cetak.
  3. Pilih 'Save as PDF' dalam dialog cetak.

Pertanyaan yang Sering Diajukan

Markdown mana yang didukung?

Heading (# hingga ####), tebal, miring, kode inline, blok kode, daftar poin, tautan, dan garis horizontal — 95% kebutuhan sehari-hari. Tabel dan gambar tertanam TIDAK dirender oleh konverter ringan ini; batas tersebut dinyatakan di sini, bukan disembunyikan.

Bagaimana PDF dihasilkan?

HTML hasil render terbuka dalam tampilan cetak dan 'Save as PDF' browser Anda membuat file — sehingga font dan paginasi adalah kualitas terbaik browser Anda.

Apakah teks saya diunggah?

Tidak — perenderan terjadi secara lokal.

Di balik layar

Renderer kecil yang dibuat khusus menangani konstruksi inti Markdown dan menata output untuk cetak (lebar 720px, isi serif). Tampilan cetak menggunakan mesin PDF browser Anda.

Contoh terapan

README proyek yang ditempel menjadi ringkasan PDF 3 halaman yang bersih — heading, daftar poin, dan contoh kode tetap utuh — siap dikirim melalui email ke klien non-teknis.
