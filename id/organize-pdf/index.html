Atur Halaman PDF Online - Gratis

Singkatnya: alat Atur PDF menunjukkan setiap halaman PDF Anda sebagai thumbnail, sehingga Anda dapat menyeret halaman ke urutan baru, memutar halaman yang menyamping, dan menghapus halaman yang tidak Anda perlukan - lalu menyimpan hasilnya sebagai PDF baru, sepenuhnya gratis dan tanpa mengunggah apa pun.

Pemindai jarang mendapatkan urutan yang benar: halaman keluar tercampur, selembar kosong menyelip masuk, dan satu halaman mendarat menyamping. Alih-alih mencetak dan memindai ulang, jatuhkan saja PDF di sini, susun thumbnail sesuai cara dokumen seharusnya dibaca, dan unduh salinan bersih yang urutannya benar.

Privat berdasarkan desain: file Anda diproses 100% di browser Anda dengan JavaScript. File tidak pernah diunggah ke server, tidak pernah disimpan, dan tidak pernah dilihat oleh kami - tutup tab dan semuanya hilang. File asli Anda tidak pernah diubah; alat ini selalu membuat PDF baru.

Bagaimana cara mengatur halaman PDF

  1. Klik kotak di atas atau seret PDF Anda ke dalamnya - halaman muncul sebagai thumbnail.
  2. Seret thumbnail mana pun ke posisi baru, atau gunakan tombol panah kiri dan kanan di bawahnya (lebih mudah di ponsel). Ketuk tombol putar untuk memutar halaman yang menyamping, dan tombol hapus untuk menghapus halaman yang tidak Anda perlukan.
  3. Klik "Save PDF" dan dokumen yang telah disusun ulang terunduh secara otomatis, persis dalam urutan yang ditampilkan.

Pertanyaan yang Sering Diajukan

Apakah gratis mengatur PDF di sini?

Ya. Alat Atur PDF sepenuhnya gratis tanpa pendaftaran, tanpa watermark, dan tanpa batas halaman yang kami tetapkan.

Apakah file saya diunggah ke server?

Tidak. Pengaturan terjadi 100% di dalam browser Anda menggunakan JavaScript. File Anda tidak pernah meninggalkan perangkat Anda.

Bagaimana cara mengubah urutan halaman?

Seret thumbnail halaman mana pun ke posisi barunya, atau gunakan tombol panah kiri dan kanan di bawah setiap thumbnail - praktis di ponsel dan tablet.

Bisakah saya memutar atau menghapus halaman saat mengatur?

Ya. Tombol putar memutar halaman 90 derajat setiap kali Anda mengetuknya, dan tombol hapus menghapus halaman dari PDF baru. Tombol Atur Ulang memulihkan urutan asli dan mengembalikan setiap halaman.

Apa PDF terbesar yang dapat saya atur?

Tidak ada batas tetap, tetapi alat ini bekerja paling baik dengan file di bawah sekitar 50 MB. Semuanya berjalan di memori perangkat' Anda, sehingga file yang sangat besar bergantung pada seberapa banyak memori yang tersedia di perangkat Anda.

Bagaimana cara kerjanya

File Anda dibuka tepat di dalam browser Anda - tidak ada yang diunggah ke server mana pun. Pratinjau halaman digambar oleh pustaka pdf.js, mesin yang sama yang digunakan Firefox untuk menampilkan PDF. Saat Anda mengklik Simpan, pustaka pdf-lib membangun dokumen yang benar-benar baru dan menyalin halaman ke dalamnya persis dalam urutan thumbnail Anda, menerapkan rotasi yang Anda atur dan menghilangkan halaman yang Anda hapus. Karena halaman disalin utuh alih-alih dicetak atau dirender ulang, teks tetap dapat dipilih, gambar vektor tetap tajam, dan gambar mempertahankan data aslinya. Dokumen jadinya terunduh secara otomatis, sementara file asli Anda tetap tidak tersentuh di perangkat Anda.

Contoh terapan

Anda memindai tugas 6 halaman dan halamannya keluar dalam urutan 1, 3, 2, 6, 5, 4 - dengan halaman 5 menyamping dan halaman tutup pemindai kosong di akhir. Jatuhkan pindaian di sini, seret halaman 3 setelah halaman 2, seret tiga halaman terakhir ke urutan 4, 5, 6, ketuk putar sekali pada halaman yang menyamping, hapus halaman kosong, dan klik Simpan. Anda mendapatkan satu PDF 6 halaman bersih yang terbaca sempurna dari awal hingga akhir.

Penggunaan umum

  • Memperbaiki pindaian yang halamannya keluar tidak berurutan atau terbalik.
  • Menghapus halaman kosong yang ditambahkan pemindai atau printer.
  • Memindahkan halaman ringkasan atau tanda tangan ke bagian depan atau belakang laporan.
  • Meletakkan formulir lamaran, sertifikat, dan salinan ID dalam urutan yang diminta kantor - dalam satu kali proses, sebelum menggabungkan atau mengirim.

Pertanyaan yang sering diajukan

Apakah mengatur akan mengubah kualitas halaman saya?

Tidak. Halaman disalin persis seperti adanya ke dokumen baru - teks tetap dapat dipilih dan gambar mempertahankan kualitas dan ukuran aslinya. Setiap halaman juga mempertahankan ukuran halaman aslinya sendiri.

Bisakah saya mengatur PDF yang hanya memiliki satu halaman?

Ya. PDF satu halaman terbuka secara normal; Anda dapat memutar halaman jika menyamping dan menyimpannya lagi, atau membiarkannya begitu saja.

Saya menghapus halaman karena kesalahan - bisakah saya mendapatkannya kembali?

Ya. Klik "Reset Order" dan alat ini memulihkan setiap halaman dalam urutan asli. File asli di perangkat Anda juga tidak pernah berubah, sehingga Anda selalu dapat memulai lagi darinya.

Bisakah saya mengatur PDF yang dilindungi kata sandi?

Tidak. File yang memerlukan kata sandi untuk dibuka tidak dapat dibaca oleh alat ini dan akan menunjukkan kesalahan. Hapus kata sandinya di aplikasi yang membuat file tersebut terlebih dahulu, lalu atur di sini.

Apakah kecepatan internet saya memengaruhi pengaturan?

Tidak. Setelah halaman ini dimuat, semua pekerjaan terjadi di memori perangkat' Anda, sehingga pengaturan sama cepatnya pada koneksi lambat - file Anda tidak pernah bepergian ke mana pun.
