PDF unterschreiben Online - Kostenlos

Kurz gesagt: das Tool PDF unterschreiben platziert Ihre Unterschrift auf jeder Seite eines PDF: Zeichnen Sie sie mit Maus oder Finger oder laden Sie ein Unterschriftsbild hoch, positionieren Sie sie mit der Live-Vorschau und laden Sie die unterschriebene Datei herunter.

Formulare, Vereinbarungen und Erlaubniszettel verlangen ständig eine Unterschrift. Statt zu drucken, zu unterschreiben und zu scannen, erledigen Sie es direkt hier: Zeichnen Sie Ihre Unterschrift einmal, ziehen Sie die Platzierungsregler, während Sie die Vorschau beobachten, und laden Sie ein unterschriebenes PDF herunter.

Klicken, um eine PDF-Datei zu wählen
oder hierher ziehen & ablegen
Noch keine Unterschrift - zeichnen Sie eine oder laden Sie ein Bild hoch.
Privat durch Design: Ihre Dateien werden zu 100 % in Ihrem Browser mit JavaScript verarbeitet. Sie werden nie auf einen Server hochgeladen, nie gespeichert und nie von uns gesehen - schließen Sie den Tab, und alles ist weg.

So unterschreiben Sie ein PDF

  1. Wählen Sie das PDF, das Sie unterschreiben müssen.
  2. Zeichnen Sie Ihre Unterschrift auf dem Feld (oder laden Sie ein Unterschriftsbild hoch), dann wählen Sie die zu unterschreibende Seite.
  3. Verwenden Sie die Positions- und Größenregler, während Sie die Vorschau beobachten, dann klicken Sie auf „Unterschreiben & Herunterladen".

Häufig gestellte Fragen

Ist eine elektronische Signatur wie diese rechtlich bindend?

Für Alltagsformulare und interne Dokumente wird es weithin akzeptiert, aber die Regeln unterscheiden sich nach Land und Dokumententyp. Für hochwertige Rechtsverträge prüfen Sie die lokalen Anforderungen oder verwenden Sie einen zertifizierten E-Signatur-Dienst.

Kann ich mit dem Finger auf einem Handy unterschreiben?

Ja. Das Unterschriftsfeld funktioniert mit Berührung - zeichnen Sie mit Ihrem Finger oder einem Stift.

Kann ich eine gescannte Unterschrift wiederverwenden?

Ja. Laden Sie ein klares Foto oder einen Scan Ihrer Unterschrift hoch (PNG mit schlichtem Hintergrund funktioniert am besten).

Wird mein Unterschriftsbild hochgeladen oder gespeichert?

Nein. Alles geschieht in Ihrem Browser; Ihre Unterschrift und Ihr Dokument verlassen Ihr Gerät nie.

So funktioniert es

Dieses Tool platziert ein Bild Ihrer Unterschrift auf eine Seite Ihres PDF. Sie zeichnen entweder auf dem Unterschriftsfeld - Ihre Striche werden als transparentes PNG erfasst - oder laden ein Unterschriftsbild hoch, das als PNG oder JPG eingebettet wird. Eine Live-Vorschau, gerendert mit PDF.js, zeigt die Unterschrift auf der tatsächlichen Seite, während Sie drei Regler anpassen: horizontale Position, vertikale Position und Größe als Prozentsatz der Seitenbreite. Bei Unterschreiben & Herunterladen zeichnet pdf-lib das Bild an diesen Koordinaten auf die eine von Ihnen gewählte Seite und speichert das Ergebnis mit -signed zum Dateinamen hinzugefügt. Es ist eine visuelle Unterschrift - ein auf der Seite platziertes Bild - keine zertifikatbasierte kryptografische digitale Signatur, und der ganze Prozess läuft in Ihrem Browser: Weder Dokument noch Unterschrift wird je hochgeladen.

Rechenbeispiel

Ein Elternteil muss Seite 4 eines Schulzulassungsformulars unterschreiben. Er zeichnet seine Unterschrift mit der Maus auf dem Feld, wählt Seite 4, stellt die Größe ein auf 25%, und verschiebt die Positionsregler, bis die Vorschau die Unterschrift auf der Unterschriftslinie unten auf der Seite sitzen zeigt. Ein Klick lädt admission-form-signed.pdf, bereit, an die Schule zurückgemailt zu werden.

Häufig gestellte Fragen

Ist dies dasselbe wie eine zertifizierte digitale Signatur?

Nein. Dieses Tool stempelt ein Bild Ihrer Unterschrift auf die Seite - oft einfache elektronische Signatur genannt. Es trägt kein digitales Zertifikat, keine Identitätsprüfung und kein manipulationssicheres Siegel. Für Dokumente, die rechtlich eine zertifizierte digitale Signatur erfordern, verwenden Sie stattdessen einen zertifizierten E-Signatur-Dienst.

Kann ich mehr als eine Seite unterschreiben oder mehrere Unterschriften hinzufügen?

Jeder Durchlauf platziert eine Unterschrift auf einer gewählten Seite. Um eine zweite Seite zu unterschreiben, lassen Sie die unterschriebene Datei einfach erneut durch das Tool laufen und platzieren die nächste Unterschrift - die vorherige bleibt erhalten.

Welche Art von Unterschriftsbild sollte ich hochladen?

Ein klares PNG funktioniert am besten, besonders eines mit transparentem oder schlicht hellem Hintergrund, denn das Bild wird als Rechteck platziert - der Hintergrund eines JPG würde als weiße Box erscheinen. Unterschreiben Sie mit dunkler Tinte, schneiden Sie das Foto nah an der Unterschrift zu und vermeiden Sie Schatten.

Wird meine gezeichnete Unterschrift eine weiße Box um sich haben?

Nein. Das Zeichenfeld speichert Ihre Striche auf Transparenz, also erscheint nur die Tinte selbst auf der Seite - sie fügt sich über Formularlinien und Text wie ein echter Stift auf Papier.

Kann ich auch ein Datum oder meinen Namen neben die Unterschrift tippen?

Nein. Das Tool platziert nur das Unterschriftsbild - es gibt kein Text-Tool. Wenn das Formular einen gedruckten Namen oder ein Datum braucht, füllen Sie diese mit unseren Bearbeiten-Tools oder Ihrem PDF-Reader vor oder nach dem Unterschreiben aus.

Verändert Unterschreiben den Rest meines Dokuments?

Nein. Die anderen Seiten und der gesamte vorhandene Inhalt werden von pdf-lib unverändert übernommen; die einzige Ergänzung ist das Unterschriftsbild auf der von Ihnen gewählten Seite.
