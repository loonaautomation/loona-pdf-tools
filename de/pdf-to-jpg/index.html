PDF in JPG umwandeln Online - Kostenlos

Kurz gesagt: das Tool PDF in JPG umwandeln rendert jede Seite eines PDF in ein separates JPG-Bild, in Standard-, Hoch- oder Druckauflösung, bereit zum einzelnen Herunterladen.

Brauchen Sie eine PDF-Seite als Bild für ein Formular, eine Präsentation oder WhatsApp? Dieses Tool konvertiert jede Seite in ein gestochenes JPG-Bild - keine Uploads, kein Warten, einfach eine Qualitätsstufe wählen und herunterladen.

Privat durch Design: Ihre Dateien werden zu 100 % in Ihrem Browser mit JavaScript verarbeitet. Sie werden nie auf einen Server hochgeladen, nie gespeichert und nie von uns gesehen - schließen Sie den Tab, und alles ist weg.

So konvertieren Sie PDF in JPG

  1. Wählen Sie Ihre PDF-Datei - die Seitenzahl erscheint automatisch.
  2. Wählen Sie eine Qualitätsstufe: Standard zum Teilen, Hoch für Dokumente, Druck für scharfe Ausgabe.
  3. Klicken Sie auf „In JPG konvertieren" und laden Sie jedes Seitenbild über die Links herunter.

Häufig gestellte Fragen

Welche Qualität sollte ich wählen?

Standard (1.5x) ist großartig für Bildschirme und Teilen. Hoch (2x) eignet sich für Dokumente, in die Sie hineinzoomen können, und Druck (3x) gibt die schärfsten Bilder.

Kann ich nur eine Seite konvertieren?

Das Tool konvertiert alle Seiten und gibt Ihnen einen separaten Download-Link pro Seite, sodass Sie einfach die nehmen können, die Sie brauchen.

Werden meine Dateien auf einen Server hochgeladen?

Nein. Das Rendern geschieht lokal in Ihrem Browser mit PDF.js.

Warum haben die JPGs einen weißen Hintergrund?

JPG unterstützt keine Transparenz, also werden Seiten auf Weiß platziert - genau wie die gedruckte Seite.

So funktioniert es

PDF.js - die Bibliothek, die Ihr Browser zur Anzeige von PDFs verwendet - lädt die Datei lokal auf Ihrem Gerät und zeichnet jede Seite auf ein unsichtbares Canvas in der von Ihnen gewählten Auflösung: das 1.5-, 2- oder 3-Fache der natürlichen Größe der Seite. Für die JPG-Ausgabe wird das Canvas zuerst weiß bemalt (JPG hat keine Transparenz), dann als JPEG-Bild in hoher Qualität exportiert. Jede Seite wird zu ihrem eigenen Download-Link, benannt nach Ihrer Datei - zum Beispiel report-page3.jpg. Nichts wird hochgeladen: Das Rendern geschieht vollständig in diesem Tab, und das Schließen des Tabs löscht alles.

Rechenbeispiel

Eine Lehrerin hat ein 5-seitiges Arbeitsblatt-PDF und braucht Seite 2 als Bild für eine WhatsApp-Gruppe. Sie wählt die Datei, wählt Druck (3x) sodass der Text scharf bleibt, wenn Eltern hineinzoomen, und klickt auf Konvertieren. Fünf JPG-Links erscheinen - sie lädt nur Seite 2 herunter, ein gestochenes Bild mit etwa 1785 x 2525 Pixeln aus einem A4-Original, und teilt es. Die anderen vier Links werden einfach ignoriert.

Häufig gestellte Fragen

Welche Pixelgröße werden meine JPGs haben?

Es hängt von der Seitengröße Ihres PDF und der gewählten Qualität ab. Eine A4-Seite hat 595 x 842 Punkt, also ergibt Standard (1.5x) etwa 893 x 1263 Pixel, Hoch (2x) etwa 1190 x 1684 und Druck (3x) etwa 1785 x 2526 - reichlich zum Drucken auf A4.

Kann ich alle Seiten in einer ZIP-Datei herunterladen?

Nein. Das Tool erstellt einen separaten Download-Link für jede Seite und es gibt keine ZIP-Option. Der Vorteil ist, dass Sie nur die Seiten speichern, die Sie wirklich brauchen - klicken Sie einfach jeden Link für die gewünschten.

Bleibt der Text im JPG noch auswählbar oder durchsuchbar?

Nein. Jede Seite wird zu einem flachen Bild, also kann Text im Bild nicht ausgewählt, kopiert oder durchsucht werden. Wenn Sie die Wörter selbst brauchen, verwenden Sie stattdessen unser Tool PDF in Text umwandeln.

Kann ich ein passwortgeschütztes PDF konvertieren?

Nein. Ein geschütztes PDF kann zum Rendern nicht geöffnet werden, bis es entsperrt ist. Entfernen Sie das Passwort zuerst in Ihrem üblichen PDF-Reader, dann konvertieren Sie die entsperrte Kopie hier.

Was geschieht mit einem sehr langen PDF?

Seiten werden nacheinander gerendert, und die Fortschrittsleiste zeigt, wie weit es gekommen ist. Ein Dokument mit hunderten Seiten in Druckqualität kann eine Weile dauern und mehr Speicher verwenden, also ist für sehr große Dateien Standard- oder Hoch-Qualität die sicherere Wahl.

Verändert das Konvertieren mein Original-PDF?

Nein. Das Tool liest nur Ihre Datei. Das Original bleibt exakt, wie es auf Ihrem Gerät war - die JPGs sind brandneue Dateien.
