Wie Loona PDF Tools funktionieren

  1. Wählen Sie ein Tool und fügen Sie Ihre Datei hinzu. Ihr PDF oder Ihre Bilder werden von Ihrem eigenen Browser gelesen - nichts wird irgendwohin gesendet.
  2. Passen Sie die Optionen an. Seitenbereiche, Größen, Qualitätsstufen und Stile sind alle unter Ihrer Kontrolle.
  3. Laden Sie das Ergebnis herunter. Die fertige Datei wird auf Ihrem Gerät erstellt und lädt sofort herunter.

Warum Menschen browserbasierten Tools vertrauen

Die meisten Online-PDF-Seiten bitten Sie, vertrauliche Dokumente - Ausweise, Kontoauszüge, Verträge - auf den Server eines Fremden hochzuladen. Loona PDF Tools sind umgekehrt gebaut: Der Verarbeitungscode kommt zu Ihrer Datei, nicht umgekehrt. Das bedeutet schnellere Ergebnisse, überall funktionierenden Datenschutz und nichts von Ihrem wird gespeichert, protokolliert oder geteilt. Schließen Sie den Tab, und jede Spur Ihres Dokuments ist weg.

Häufig gestellte Fragen

Sind Loona PDF Tools wirklich kostenlos?

Ja - jedes Tool ist zu 100 % kostenlos, ohne Anmeldung, ohne Wasserzeichen und ohne von uns gesetzte tägliche Limits.

Werden meine Dateien auf Ihren Server hochgeladen?

Nie. Jedes Tool läuft zu 100 % in Ihrem Browser mit JavaScript-Bibliotheken, die einmal von dieser Seite geladen werden. Ihre Dateien bleiben von Anfang bis Ende auf Ihrem Gerät.

Welche Geräte werden unterstützt?

Jeder moderne Browser auf Handy, Tablet oder Computer - Chrome, Edge, Firefox und Safari funktionieren alle.

Funktionieren die Tools offline?

Sobald eine Tool-Seite geladen ist, funktioniert ihre Verarbeitung auch, wenn Ihre Verbindung abbricht, weil alles lokal auf Ihrem Gerät geschieht.

Kann ich diese Tools für Büro- oder Schuldokumente verwenden?

Absolut - genau dafür sind sie gebaut: Formulare, Aufgaben, Berichte, Scans und Bewerbungsunterlagen.
