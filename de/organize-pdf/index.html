PDF-Seiten organisieren Online - Kostenlos

Kurz gesagt: das Tool PDF organisieren zeigt jede Seite Ihres PDF als Miniatur, sodass Sie Seiten in eine neue Reihenfolge ziehen, seitliche Seiten drehen und nicht benötigte Seiten löschen können - dann speichern Sie das Ergebnis als neues PDF, völlig kostenlos und ohne irgendetwas hochzuladen.

Scanner bekommen die Reihenfolge selten richtig hin: Seiten kommen vermischt heraus, ein leeres Blatt rutscht hinein, und eine Seite landet seitwärts. Statt zu drucken und erneut zu scannen, legen Sie das PDF einfach hier ab, ordnen Sie die Miniaturen so an, wie das Dokument lesen sollte, und laden Sie eine saubere, korrekt geordnete Kopie herunter.

Klicken, um eine PDF-Datei zu wählen
oder hierher ziehen & ablegen - funktioniert am besten mit Dateien unter etwa 50 MB
Privat durch Design: Ihre Datei wird zu 100 % in Ihrem Browser mit JavaScript verarbeitet. Sie wird nie auf einen Server hochgeladen, nie gespeichert und nie von uns gesehen - schließen Sie den Tab, und alles ist weg. Ihre Originaldatei wird nie verändert; das Tool erstellt immer ein neues PDF.

So organisieren Sie PDF-Seiten

  1. Klicken Sie auf die Box oben oder ziehen Sie Ihr PDF hinein - die Seiten erscheinen als Miniaturansichten.
  2. Ziehen Sie eine beliebige Miniatur an eine neue Position oder verwenden Sie die Links- und Rechts-Pfeilschaltflächen darunter (einfacher auf einem Handy). Tippen Sie auf die Dreh-Schaltfläche, um eine seitliche Seite zu drehen, und auf die Löschen-Schaltfläche, um eine nicht benötigte Seite zu entfernen.
  3. Klicken Sie auf „PDF speichern", und Ihr neu organisiertes Dokument wird automatisch heruntergeladen, in genau der gezeigten Reihenfolge.

Häufig gestellte Fragen

Ist es kostenlos, ein PDF hier zu organisieren?

Ja. Das Tool PDF organisieren ist völlig kostenlos, ohne Anmeldung, ohne Wasserzeichen und ohne von uns gesetztes Seitenlimit.

Werden meine Dateien auf einen Server hochgeladen?

Nein. Das Organisieren geschieht zu 100 % in Ihrem Browser mit JavaScript. Ihre Dateien verlassen Ihr Gerät nie.

Wie ändere ich die Reihenfolge von Seiten?

Ziehen Sie eine beliebige Seitenminiatur an ihre neue Position oder verwenden Sie die Links- und Rechts-Pfeilschaltflächen unter jeder Miniatur - praktisch auf Handys und Tablets.

Kann ich eine Seite beim Organisieren drehen oder entfernen?

Ja. Die Dreh-Schaltfläche dreht eine Seite bei jedem Tippen um 90 Grad, und die Löschen-Schaltfläche entfernt die Seite aus dem neuen PDF. Die Zurücksetzen-Schaltfläche stellt die Originalreihenfolge wieder her und bringt jede Seite zurück.

Was ist das größte PDF, das ich organisieren kann?

Es gibt kein festes Limit, aber das Tool funktioniert am besten mit Dateien unter etwa 50 MB. Alles läuft im Speicher Ihres Geräts, also hängen sehr große Dateien davon ab, wie viel Speicher Ihr Gerät frei hat.

So funktioniert es

Ihre Datei wird direkt in Ihrem Browser geöffnet - nichts wird auf einen Server hochgeladen. Die Seitenvorschauen werden von der pdf.js-Bibliothek gezeichnet, derselben Engine, die Firefox zur Anzeige von PDFs verwendet. Wenn Sie auf Speichern klicken, baut die pdf-lib-Bibliothek ein brandneues Dokument und kopiert die Seiten in exakt der Reihenfolge Ihrer Miniaturen hinein, wendet alle von Ihnen gesetzten Drehungen an und lässt alle gelöschten Seiten weg. Weil Seiten als Ganzes kopiert statt gedruckt oder neu gerendert werden, bleibt Text auswählbar, Vektorzeichnungen bleiben scharf und Bilder behalten ihre originalen Daten. Das fertige Dokument lädt automatisch herunter, während Ihre Originaldatei auf Ihrem Gerät unberührt bleibt.

Rechenbeispiel

Sie haben eine 6-seitige Aufgabe gescannt, und die Seiten kamen in der Reihenfolge 1, 3, 2, 6, 5, 4 heraus - mit Seite 5 seitlich und einer leeren Scannerdeckel-Seite am Ende. Legen Sie den Scan hier ab, ziehen Sie Seite 3 nach Seite 2, ziehen Sie die letzten drei Seiten in die Reihenfolge 4, 5, 6, tippen Sie einmal auf Drehen bei der seitlichen Seite, löschen Sie die leere Seite und klicken Sie auf Speichern. Sie erhalten ein sauberes 6-seitiges PDF, das von Anfang bis Ende perfekt liest.

Häufige Verwendungen

  • Scans korrigieren, deren Seiten in falscher Reihenfolge oder kopfstehend herauskamen.
  • Leere Seiten entfernen, die ein Scanner oder Drucker hinzugefügt hat.
  • Eine Zusammenfassungs- oder Unterschriftsseite an den Anfang oder das Ende eines Berichts verschieben.
  • Antragsformulare, Zertifikate und Ausweiskopien in die Reihenfolge bringen, die ein Büro verlangt hat - in einem Durchlauf, vor dem Zusammenführen oder Senden.

Häufig gestellte Fragen

Verändert Organisieren die Qualität meiner Seiten?

Nein. Seiten werden exakt so in das neue Dokument kopiert, wie sie sind - Text bleibt auswählbar und Bilder behalten ihre Originalqualität und -größe. Jede Seite behält auch ihre eigene originale Seitengröße.

Kann ich ein PDF mit nur einer Seite organisieren?

Ja. Ein einseitiges PDF öffnet sich normal; Sie können die Seite drehen, wenn sie seitlich ist, und sie erneut speichern, oder sie einfach lassen, wie sie ist.

Ich habe versehentlich eine Seite gelöscht - kann ich sie zurückbekommen?

Ja. Klicken Sie auf „Reihenfolge zurücksetzen", und das Tool stellt jede Seite in der Originalreihenfolge wieder her. Ihre Originaldatei auf Ihrem Gerät wird so oder so nie verändert, also können Sie immer wieder von ihr beginnen.

Kann ich ein passwortgeschütztes PDF organisieren?

Nein. Eine Datei, die ein Passwort zum Öffnen braucht, kann vom Tool nicht gelesen werden und zeigt einen Fehler. Entfernen Sie das Passwort in der App, die die Datei erstellt hat, dann organisieren Sie sie hier.

Beeinflusst meine Internetgeschwindigkeit das Organisieren?

Nein. Sobald diese Seite geladen ist, geschieht die ganze Arbeit im Speicher Ihres Geräts, sodass Organisieren auf einer langsamen Verbindung genauso schnell ist - Ihre Datei reist nirgendwohin.
