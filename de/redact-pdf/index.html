PDF schwärzen Online - Kostenlos (Echte Einbrenn-Schwärzung)

Kurz gesagt: das Tool PDF schwärzen entfernt dauerhaft, was Sie überdecken: Zeichnen Sie schwarze Rechtecke über vertrauliche Bereiche auf jeder Seite, und das Tool baut jede Seite als Bild mit eingemalten Boxen neu auf - der Text darunter existiert in der Datei überhaupt nicht mehr, also kann er nicht kopiert, durchsucht oder aufgedeckt werden.

Text mit einer schwarzen Form in einem Editor zu überdecken ist keine Schwärzung - die Wörter bleiben oft darunter verborgen, bereit zum Herauskopieren. Dieses Tool macht es auf die sichere Weise: Jede Seite wird als Bild neu erstellt, mit Ihren eingebrannten schwarzen Boxen, sodass überdeckter Inhalt wirklich weg ist.

Ehrlicher Kompromiss: weil Seiten als Bilder neu aufgebaut werden, um die Entfernung zu garantieren, ist der Text des geschwärzten PDF nicht mehr auswählbar oder durchsuchbar auf jeder Seite, und die Datei kann größer sein. Das ist der Preis für Schwärzung, die nicht rückgängig gemacht werden kann - und es wird hier genannt, nicht versteckt.

Ziehen Sie auf der Seite, um eine schwarze Box zu zeichnen. Wiederholen Sie dies auf so vielen Seiten, wie Sie brauchen - Boxen werden pro Seite gespeichert.

Privat durch Design: Ihre Dateien werden zu 100 % in Ihrem Browser mit JavaScript verarbeitet. Sie werden nie auf einen Server hochgeladen, nie gespeichert und nie von uns gesehen - schließen Sie den Tab, und alles ist weg.

So verwenden Sie dieses Tool

  1. Wählen Sie das PDF, das vertrauliche Inhalte enthält.
  2. Wählen Sie eine Seite und ziehen Sie auf ihr, um eine schwarze Box über jeden zu entfernenden Namen, jede Nummer, jedes Foto oder jeden Absatz zu zeichnen.
  3. Auf anderen Seiten wiederholen - jede Box wird aufgelistet, sodass Sie Fehler rückgängig machen können.
  4. Klicken Sie auf Schwärzen & Herunterladen. Jede Seite wird als Bild mit eingebrannten Boxen neu aufgebaut.

Häufig gestellte Fragen

Wird der überdeckte Inhalt wirklich entfernt oder nur verborgen?

Wirklich entfernt. Jede Seite wird zu einem Bild gerendert, die schwarzen Boxen werden in dieses Bild gemalt, und ein brandneues PDF wird nur aus diesen Bildern gebaut. Die originale Textebene gelangt nie in die neue Datei, also gibt es darunter nichts zu kopieren, zu durchsuchen oder zu enthüllen.

Warum ist der Text in meinem geschwärzten PDF nicht mehr auswählbar?

Weil jede Seite jetzt ein Bild ist - genau das garantiert die Entfernung. Wenn Sie ein Dokument brauchen, das auswählbar bleibt, schwärzen Sie nur eine Kopie zum Teilen und behalten Sie das Original privat.

Kann jemand die schwarzen Boxen mit einem Editor entfernen?

Nein. Die Boxen sind keine separaten Objekte, die über Text gelegt werden; sie sind Teil des Seitenbildes selbst, wie auf Papier gedruckte Tinte. Das Verschieben oder Löschen von Objekten in einem Editor kann Pixel nicht zurückbringen, die nie gespeichert wurden.

Ändert sich die Dateigröße?

Normalerweise wächst sie, weil Bildseiten schwerer sind als Textseiten - besonders bei langen Dokumenten. Seiten werden in klarer 2x Auflösung mit guter JPEG-Komprimierung gerendert, um Schärfe und Größe auszubalancieren.

So funktioniert es

Das Tool rendert jede PDF-Seite in Ihrem Browser mit PDF.js. Wenn Sie auf einer Seite ziehen, wird Ihr Rechteck in echten PDF-Koordinaten für diese Seite gespeichert. Beim Herunterladen wird jede Seite erneut mit 2x Auflösung auf ein unsichtbares Canvas gerendert, Ihre schwarzen Rechtecke werden auf das Canvas gemalt, und das Canvas wird als JPEG gespeichert. Ein neues PDF wird dann mit pdf-lib zusammengesetzt, das nur diese Seitenbilder enthält. Text, Vektoren und versteckte Ebenen der Originaldatei werden nie in die Ausgabe kopiert - weshalb überdeckter Inhalt daraus nicht wiederherstellbar ist.

Rechenbeispiel

Eine Schule muss eine Ergebnisliste teilen, aber die Ausweisnummern der Schüler verbergen. Der Sachbearbeiter zieht eine Box über die Ausweis-Spalte auf allen 3 Seiten und lädt results-redacted.pdf. Danach versucht sie, die Zahlen in der geteilten Datei zu markieren und zu kopieren - unmöglich, denn diese Spalte ist jetzt einfach schwarze Pixel.

Häufig gestellte Fragen

Welche Auflösung haben die neu aufgebauten Seiten?

Seiten werden mit doppelter Normalgröße gerendert (2x, etwa 144 DPI) und als hochwertige JPEG-Bilder in ihren originalen Seitenmaßen gespeichert, sodass Ausdrucke scharf bleiben, während die Datei vernünftig bleibt.

Sollte ich einen Scan anders schwärzen?

Nein. Gescannte Seiten sind bereits Bilder, und dasselbe Einbrennen gilt: Die überdeckten Pixel werden im neu aufgebauten Bild durch Schwarz ersetzt.

Entfernt Schwärzung auch Metadaten?

Das neu aufgebaute PDF ist eine neue Datei und kopiert den Text oder versteckten Seiteninhalt des Originals nicht. Grundlegende Dokumentinfos aus dem Original werden nicht übernommen; wenn der Dateiname oder die Metadaten selbst vertraulich sind, benennen Sie den Download um und prüfen Sie ihn mit unserem Tool PDF-Infos bearbeiten.

Kann ich nur eine Seite schwärzen und den Rest als Text behalten?

Nicht mit diesem Tool - alle Seiten werden als Bilder neu aufgebaut, damit der Prozess einheitlich ist und nichts auf einer unverarbeiteten Seite durchrutscht. Das ist eine bewusste Sicherheitsentscheidung.

Was sollte ich vor dem Teilen der geschwärzten Datei prüfen?

Öffnen Sie es und blättern Sie durch jede Seite: Bestätigen Sie, dass jede Box ihr Ziel mit einem kleinen Rand vollständig bedeckt, und versuchen Sie, Text auszuwählen - Sie sollten nichts auswählen können, was bestätigt, dass das Einbrennen funktioniert hat.
