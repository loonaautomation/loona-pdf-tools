Kostenloser Zertifikat-Ersteller Online - Druckbare Zertifikate

Kurz gesagt: tippen Sie den Namen des Empfängers und einige Details, beobachten Sie, wie das Zertifikatdesign selbst auf der Live-A4-Vorschau entsteht, dann laden Sie ein druckfertiges PDF (oder PNG) herunter - kostenlos, ohne Anmeldung und ohne Wasserzeichen. Eine ganze Klasse oder ein Kurs zu zertifizieren? Wechseln Sie in den Stapel-Modus, fügen Sie einen Namen pro Zeile ein und erhalten Sie ein PDF mit einem Zertifikat für jeden Namen.

Zertifikate bedeuten meist ein Design-Tool, das Sie nicht ganz bedienen können, eine Vorlage hinter einer Paywall oder eine umständliche Download-Gebühr im letzten Schritt. Hier geschieht alles auf dieser Seite: drei fertige Designs, jedes Wort bearbeitbar, ein goldenes Siegel wird automatisch eingezeichnet - und das fertige PDF wird in Ihrem Browser gebaut, sodass Namen und Details Ihr Gerät nie verlassen.

Jedes andere Feld oben - Kurs, Datum, Aussteller, Unterschrift und Design - bleibt auf jedem Zertifikat gleich; nur der Name ändert sich. Leerzeilen werden ignoriert und wiederholte Namen werden behalten.

Privat durch Design: Ihr Zertifikat wird gestaltet und Ihr PDF zu 100 % in Ihrem Browser mit JavaScript gebaut. Namen und Details werden nie auf einen Server hochgeladen, nie gespeichert und nie von uns gesehen - schließen Sie den Tab, und alles ist weg. Das ist bei Zertifikaten wichtig: Eine Klassenliste mit Namen bleibt auf Ihrem eigenen Gerät.

So erstellen Sie ein Zertifikat

  1. Wählen Sie eines der drei Designs und tippen Sie Ihre Details - Titel, Empfängername, Kurszeile, Beschreibung, Datum, Aussteller und Unterschriftsname. Die A4-Querformat-Vorschau zeichnet sich neu, während Sie tippen.
  2. Für ein einzelnes Zertifikat klicken Sie auf „PDF herunterladen" für eine druckfertige Datei oder auf „PNG herunterladen", wenn Sie ein Bild zum Teilen möchten.
  3. Für viele Zertifikate auf einmal wechseln Sie in den Stapel-Modus, fügen einen Namen pro Zeile ein (bis zu 200) und klicken auf „Stapel-PDF erstellen" - Sie erhalten ein PDF mit einer Seite pro Name, bereit zum Drucken.

Häufig gestellte Fragen

Ist dieser Zertifikat-Ersteller wirklich kostenlos?

Ja. Es ist völlig kostenlos, ohne Anmeldung und ohne Wasserzeichen - Stapel-Modus eingeschlossen. Viele Zertifikat-Seiten lassen Sie kostenlos gestalten und berechnen dann den Download; hier ist der Download auch kostenlos.

Werden die Namen, die ich eingebe, irgendwohin hochgeladen?

Nein. Das Zertifikat wird gezeichnet und das PDF zu 100 % in Ihrem Browser gebaut. Namen, Daten und jedes andere Detail verlassen Ihr Gerät nie.

Wie viele Zertifikate kann der Stapel-Modus erstellen?

Bis zu 200 Zertifikate in einem PDF pro Durchlauf. Fügen Sie einen Namen pro Zeile ein; Leerzeilen werden ignoriert und wiederholte Namen werden behalten, sodass zwei Schüler mit demselben Namen jeder ein Zertifikat erhalten.

Welche Größe hat das Zertifikat?

Jedes Zertifikat ist eine Standard-A4-Seite im Querformat, gezeichnet mit 150 dpi, sodass es auf jedem Heim- oder Bürodrucker scharf druckt. Wählen Sie 'Originalgröße' oder 100 % in Ihrem Druckdialog für eine exakte Passung.

Kann ich das Design ändern?

Ja. Es gibt drei eingebaute Designs - Elegantes Gold, Modernes Blau und Klassisch - und jedes Wort auf dem Zertifikat ist bearbeitbar: Titel, Empfängername, Kurszeile, Beschreibung, Datum, Aussteller und Unterschriftsname.

So funktioniert es

Das Zertifikat wird auf einem HTML-Canvas in voller A4-Querformat-Größe gezeichnet (297 x 210 mm bei 150 dpi - 1754 x 1240 Pixel). Jedes Element wird bei jedem Tippen frisch aus Ihrem Text gezeichnet: der doppellinige Rand und die Eckenverzierungen, der Titel, das goldene Siegel mit seinen Bandschwänzen und die Unterschriftslinie in einem Schreibschrift-Stil. Wenn Sie das PDF herunterladen, wird die fertige Zeichnung von der pdf-lib-Bibliothek auf eine A4-Querformat-Seite gelegt - dieselbe Bibliothek, die unsere anderen PDF-Tools verwenden - sodass die Datei exakt wie die Vorschau druckt. Im Stapel-Modus wird dieselbe Zeichnung einmal pro Name in ein einzelnes mehrseitiges PDF wiederholt, mit einer Fortschrittsleiste, sodass Sie einer langen Liste beim Fertigwerden zusehen können.

Rechenbeispiel

Eine Lehrerin beendet einen zweitägigen Trainingsworkshop mit 28 Teilnehmern. Sie öffnet den Stapel-Modus, behält den Titel „Certificate of Participation", stellt die Kurszeile auf den Namen ihres Workshops, fügt die 28 Namen aus ihrer Liste ein - einen pro Zeile - und klickt auf Erstellen. Eine Minute später hat sie ein 28-seitiges PDF; sie druckt es nach Abgleich mit der Liste aus, unterschreibt jede Seite über der gedruckten Unterschriftslinie und händigt die Zertifikate noch am selben Tag aus. Keine Design-Software, kein Hochladen der Namen ihrer Schüler und keine Gebühr.

Häufige Verwendungen

  • Zertifikate über Kurs- und Trainingsabschlüsse für eine ganze Klasse in einem PDF.
  • Anerkennungszertifikate für Schüler, Mitarbeiter oder Freiwillige.
  • Zertifikate über Workshop-, Seminar- und Webinar-Teilnahme.

Häufig gestellte Fragen

Kann ich mein eigenes Logo oder ein handschriftliches Unterschriftsbild hinzufügen?

Nicht in dieser Version - das Design verwendet das eingebaute Siegel und einen gedruckten Unterschriftsnamen. Viele drucken das Zertifikat und unterschreiben es von Hand über der Unterschriftslinie, was ohnehin persönlicher wirkt.

Warum schrumpft der Name auf manchen Zertifikaten?

Sehr lange Namen werden automatisch in der Größe reduziert, sodass sie immer auf eine Zeile innerhalb des Randes passen. Einen Mittelnamen zu kürzen behält normalerweise die größere, prächtigere Größe.

Ändert der Stapel-Modus etwas außer dem Namen?

Nein. Titel, Kurs, Beschreibung, Datum, Aussteller, Unterschrift und Design sind auf jeder Seite identisch - nur der Empfängername ändert sich, exakt wie ein gedruckter Stapel, der Name für Name ausgefüllt wird.
