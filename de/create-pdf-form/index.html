PDF-Formular erstellen Online - Kostenlos

Kurz gesagt: das Tool PDF-Formular erstellen fügt echte ausfüllbare Felder zu jedem gewöhnlichen PDF hinzu: Ziehen Sie eine Box auf der Seite, wo ein Feld hingehört, geben Sie ihm einen Namen, wählen Sie Textfeld oder Kontrollkästchen und laden Sie ein echtes AcroForm-PDF herunter, das in jedem Reader ausgefüllt werden kann - einschließlich unseres eigenen Tools PDF-Formular ausfüllen.

Viele Formulare sind nur flache Seiten mit Linien - niemand kann in sie hineintippen. Dieses Tool setzt echte Formularfelder auf diese Linien, sodass die Menschen, denen Sie das Formular senden, es auf ihrem Handy oder Computer ausfüllen können statt es auszudrucken.

Klicken, um eine PDF-Datei zu wählen
oder hierher ziehen & ablegen - ein flaches Formular, Brief oder Dokument

Ziehen Sie auf der Seite, um die Box des Felds zu zeichnen, dann klicken Sie auf „Feld hinzufügen". Wenn Sie hinzufügen, ohne zu zeichnen, wird eine Standardbox in der Seitenmitte platziert. Feldnamen müssen eindeutig sein.

Privat durch Design: Ihre Dateien werden zu 100 % in Ihrem Browser mit JavaScript verarbeitet. Sie werden nie auf einen Server hochgeladen, nie gespeichert und nie von uns gesehen - schließen Sie den Tab, und alles ist weg.

So verwenden Sie dieses Tool

  1. Wählen Sie ein beliebiges PDF - zum Beispiel ein flaches Formular mit leeren Zeilen.
  2. Ziehen Sie auf der Seite, um eine Box zu zeichnen, wo eine Antwort hingehört.
  3. Benennen Sie das Feld (zum Beispiel student_name), wählen Sie Textfeld oder Kontrollkästchen und klicken Sie auf Feld hinzufügen.
  4. Für jede Antwortfläche wiederholen, dann laden Sie Ihr ausfüllbares PDF herunter und testen es im Tool PDF-Formular ausfüllen.

Häufig gestellte Fragen

Sind die Felder echte Formularfelder oder nur Zeichnungen?

Echt. Der Download enthält eine Standard-AcroForm-Definition, erstellt mit pdf-lib: Die Felder erscheinen in Adobe Acrobat, Browsern und unserem Tool PDF-Formular ausfüllen als echte ausfüllbare Felder mit den Namen, die Sie ihnen gegeben haben.

Welche Feldtypen kann ich hinzufügen?

Textfelder (einzeilig) und Kontrollkästchen. Diese decken die meisten Alltagsformulare ab. Dropdowns, Optionsgruppen und Unterschriftenfelder werden hier nicht angeboten - diese Grenze wird ehrlich genannt statt vorgetäuscht.

Warum müssen Feldnamen eindeutig sein?

Der Name eines Formularfelds ist seine Identität - zwei Felder mit einem Namen zeigen immer dieselbe Antwort. Das Tool blockiert doppelte Namen, damit sich Ihr Formular korrekt verhält.

Kann ich ein Feld nach dem Hinzufügen verschieben?

Entfernen Sie es aus der Liste unter der Seite und fügen Sie es an der korrigierten Position erneut hinzu. Felder werden erst in die heruntergeladene Datei eingebettet, wenn Sie auf Herunterladen klicken, also ist Experimentieren hier kostenlos.

So funktioniert es

Das Tool rendert Ihr PDF mit PDF.js, sodass Sie Feldboxen auf einer Live-Seitenvorschau zeichnen können. Jedes Feld, das Sie hinzufügen, wird mit seiner Seitenzahl, seiner Box in echten PDF-Punkt-Koordinaten, seinem Typ und seinem Namen gespeichert. Beim Herunterladen öffnet pdf-lib die Originaldatei, erstellt die passenden AcroForm-Felder - ein Textfeld oder ein Kontrollkästchen für jeden Eintrag - und fügt jedes an seiner gespeicherten Position mit hellem Hintergrund und Rand zu seiner Seite hinzu, damit Ausfüllende sehen, wo sie tippen sollen. Das Ergebnis ist ein standardmäßiges ausfüllbares PDF, vollständig in Ihrem Browser erstellt.

Rechenbeispiel

Ein Schulbüro hat ein Zulassungsformular als flaches PDF mit gedruckten Linien. Der Sachbearbeiter zieht Boxen über die Linien und nennt sie student_name, date_of_birth und guardian_phone, fügt ein Kontrollkästchen namens documents_attached, und lädt das Formular herunter. Eltern füllen es nun auf ihren Handys mit dem Tool PDF-Formular ausfüllen aus und mailen es zurück - ganz ohne Ausdrucken.

Häufig gestellte Fragen

Wie werden Positionen in das PDF umgerechnet?

Sie zeichnen in Bildschirmpixeln auf der gerenderten Seite; das Tool rechnet sie mit der echten Größe der Seite in PDF-Punkt um und kippt die vertikale Achse, weil PDF-Koordinaten unten links beginnen, während Bildschirme oben links beginnen.

Verändert das Hinzufügen von Feldern die Seiten meines Dokuments?

Nein. Die Originalseiten werden von pdf-lib unverändert kopiert und die Formularfelder werden darübergelegt. Text, Bilder und Layout bleiben exakt, wie sie waren.

Wie groß sollte eine Textfeld-Box sein?

Etwa die Größe der leeren Zeile oder Box, die auf dem Formular gedruckt ist. Sehr kurze Boxen beschneiden getippten Text in manchen Readern visuell, also geben Sie handschriftgroßen Flächen etwas zusätzliche Höhe.

Können die ausgefüllten Antworten später abgeflacht werden?

Ja. Wer das Formular ausfüllt, kann unser Tool PDF-Formular ausfüllen oder PDF abflachen verwenden, um die Antworten für eine endgültige, unveränderliche Einreichungskopie in die Seiten einzubetten.

Funktioniert das Formular auf Handys?

Ja - standardmäßige AcroForm-Felder werden von den PDF-Betrachtern unterstützt, die in moderne Handys und Browser eingebaut sind. Sehr alte oder minimale Betrachter können die Seite ohne die Felder anzeigen.
