Kopf- & Fußzeile zu PDF hinzufügen Online - Kostenlos

Kurz gesagt: das Tool Kopf- & Fußzeile hinzufügen stempelt Ihren Text oben und unten auf jede Seite eines PDF: einen Dokumenttitel oder Schulnamen als Kopfzeile, eine Notiz oder Vertraulichkeitszeile als Fußzeile, mit optionalen Seitenzahlen in Formaten wie Seite 3 von 12, eingebaut in den Fußzeilentext.

Berichte, Handbücher und Prüfungspapiere sehen fertig aus, wenn jede Seite oben den Namen des Dokuments und unten einen Seitenverweis trägt. Fügen Sie beides hier in einem Durchlauf hinzu - mit Platzhaltern, sodass Seitenzahlen sich pro Seite selbst ausfüllen.

Klicken, um eine PDF-Datei zu wählen
oder hierher ziehen & ablegen

Platzhalter: {page} = die Nummer dieser Seite, {total} = Gesamtseiten. Verwenden Sie sie in einem der beiden Felder - zum Beispiel eine Fußzeile aus Seite {page} von {total}.

Brauchen Sie nur Seitenzahlen, mit mehr Positionen und Stilen? Verwenden Sie das dedizierte Seitenzahlen hinzufügen Tool - auf dieser Seite geht es um Kopf- und Fußzeilentext.

Privat durch Design: Ihre Dateien werden zu 100 % in Ihrem Browser mit JavaScript verarbeitet. Sie werden nie auf einen Server hochgeladen, nie gespeichert und nie von uns gesehen - schließen Sie den Tab, und alles ist weg.

So verwenden Sie dieses Tool

  1. Wählen Sie das PDF zum Stempeln.
  2. Tippen Sie Ihren Kopf- und/oder Fußzeilentext - verwenden Sie {page} und {total}, wo Zahlen erscheinen sollen.
  3. Wählen Sie Ausrichtung und Schriftgröße und aktivieren Sie Erste Seite überspringen, wenn das Dokument ein Deckblatt hat.
  4. Laden Sie das gestempelte PDF herunter und prüfen Sie die erste und letzte Seite.

Häufig gestellte Fragen

Wie unterscheidet sich dies vom Tool Seitenzahlen hinzufügen?

Dieses Tool ist allein Zahlen gewidmet, mit mehr Positionen und Nummernstilen. Dieses Tool stempelt freien Text oben und unten - Dokumenttitel, Schul- oder Büronamen, Vertraulichkeitszeilen - und Seitenzahlen sind in diesem Text über die Platzhalter {page} und {total} verfügbar.

Können Kopf- und Fußzeile unterschiedliche Dinge sagen?

Ja - sie sind unabhängige Boxen. Lassen Sie eine von beiden leer, um nur die andere zu stempeln.

Erscheinen Kopf- und Fußzeilen auf jeder Seite?

Auf jeder Seite außer der ersten, wenn Erste Seite überspringen aktiviert ist - die übliche Wahl für Dokumente mit Deck- oder Titelblatt.

Kann ich die Kopfzeile später bearbeiten oder entfernen?

Der Text wird auf jede Seite als echter Inhalt gezeichnet, wie beim Tool Seitenzahlen hinzufügen - er ist keine separate entfernbare Ebene. Behalten Sie Ihr Original, wenn Sie eine ungestempelte Kopie brauchen könnten.

So funktioniert es

Das Tool öffnet Ihr PDF mit pdf-lib in Ihrem Browser, bettet die Standard-Helvetica-Schrift ein und zeichnet Ihren Kopf- und Fußzeilentext auf jede Seite (wobei optional die erste übersprungen wird). Vor dem Zeichnen jeder Seite ersetzt es die Platzhalter in Ihrem Text: {page} wird zur Nummer dieser Seite - gezählt ab Ihrer gewählten Startnummer - und {total} wird zur Seitenzahl des Dokuments. Die horizontale Position wird aus der gemessenen Breite der fertigen Zeichenfolge berechnet, sodass zentrierte und rechtsbündige Zeilen auf jeder Seitengröße, Hoch- oder Querformat, korrekt sitzen.

Rechenbeispiel

Eine Lehrerin bereitet ein 12-seitiges Handout vor. Kopfzeile: Science Notes - Chapter 5. Fußzeile: Seite {page} von {total}. Bei aktiviertem Erste Seite überspringen für das Deckblatt steht im Download auf Seite 3 oben 'Science Notes - Chapter 5' und unten 'Page 3 of 12' - automatisch.

Häufig gestellte Fragen

Wo genau werden die Stempel platziert?

Die Kopfzeile sitzt 24 Punkt vom oberen Rand und die Fußzeile 24 Punkt vom unteren Rand, innerhalb des üblichen Randbereichs, in einem neutralen Dunkelgrau, das in Schwarz-Weiß gut druckt.

Was tun die Ausrichtungsoptionen?

Mitte, Links und Rechts gelten für beide Zeilen. Die vierte Option setzt die Kopfzeile links und die Fußzeile mittig - das klassische Berichtslayout - und ist eine gute Standardeinstellung, wenn Ihre Fußzeile eine Zeile Seite X von Y enthält.

Welche Zeichen kann ich verwenden?

Einfache lateinische Buchstaben, Zahlen und Satzzeichen. Die zum Stempeln verwendete Standardschrift Helvetica enthält keine Urdu-, Arabisch-, Chinesisch- oder Emoji-Zeichen - diese würden nicht dargestellt, also bleibt das Tool bei dem, was zuverlässig druckt.

Verändert Stempeln meine Seiten oder Datei stark?

Seiten, Bilder und Layout sind unberührt; nur die beiden kurzen Textzeilen werden auf jede Seite gezeichnet, also wächst die Datei nur geringfügig.

Kann ich unterschiedlichen Text auf unterschiedliche Seiten stempeln?

Nein - der Sinn einer Kopf-/Fußzeile ist Einheitlichkeit im ganzen Dokument. Für einmaligen Text auf einer einzelnen Seite ist ein PDF-Editor das richtige Tool.
