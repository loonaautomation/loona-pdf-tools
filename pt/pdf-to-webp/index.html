PDF para WebP Online - Grátis

Em resumo: a ferramenta PDF para WebP transforma cada página de um PDF numa imagem WebP - o formato web moderno que é tipicamente 25-35% mais pequeno do que o JPG com a mesma qualidade - pronta para sites, blogues e lojas online, reproduzida inteiramente no seu navegador.

O WebP é o formato de imagem que a web utiliza agora: nítido como PNG, pequeno como um JPG bem afinado. Se as páginas do seu PDF se destinam a um site, convertê-las diretamente para WebP poupa largura de banda em cada visualização.

  1. Escolha o PDF cujas páginas precisa como imagens.

Perguntas Frequentes

Porquê WebP em vez de JPG ou PNG?

O WebP produz normalmente ficheiros 25-35% mais pequenos do que o JPG com qualidade equivalente e suporta transparência como o PNG. Para imagens publicadas em sites, isso significa páginas mais rápidas sem perda visível.

Que navegadores podem criar WebP aqui?

O Chrome, o Edge, o Firefox e o Safari moderno codificam WebP a partir de uma tela. Se um navegador não conseguir, a ferramenta deteta a falha de codificação e indica-o honestamente, em vez de lhe entregar um PNG mal rotulado - nesse caso, utilize a nossa ferramenta PDF para JPG ou PDF para PNG.

O fundo é transparente?

Não - as páginas são reproduzidas sobre branco, como uma página impressa, correspondendo ao aspeto do PDF num leitor. Para imagens de página transparentes, utilize PDF para PNG.

Posso converter apenas uma página?

A ferramenta converte cada página e dá-lhe uma transferência separada para cada uma, para poder simplesmente levar as de que precisa.

Como funciona

Cada página é renderizada no seu navegador por PDF.js sobre uma tela branca com a resolução que escolheu e depois codificada pelo próprio navegador como uma imagem WebP com a sua definição de qualidade (canvas.toBlob com o tipo WebP). A ferramenta verifica se o ficheiro devolvido é realmente WebP antes de o disponibilizar - se o navegador recorrer silenciosamente a PNG, é avisado em vez de enganado. Nada é carregado em momento algum.

Exemplo resolvido

Um folheto de produto PDF de 5 páginas torna-se cinco imagens WebP com uma média de 180 KB - contra cerca de 260 KB em JPG com a mesma qualidade - e entra diretamente nas páginas de produto da loja.

Perguntas frequentes

Qual será o tamanho dos ficheiros WebP?

Depende do conteúdo e das suas definições. As ligações de transferência mostram cada ficheiro à medida que é produzido; as fotografias comprimem-se melhor, as páginas de texto denso mantêm-se muito nítidas a 144 DPI e acima.

O WebP funciona no Word e nas aplicações sociais?

O suporte é agora amplo, mas algum software de escritório mais antigo continua a preferir JPG. Em caso de dúvida, a nossa ferramenta PDF para JPG produz o formato mais universalmente aceite.
