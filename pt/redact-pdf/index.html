Ocultar Conteúdo do PDF Online - Grátis (Ocultação Verdadeira por Gravação)

Em resumo: a ferramenta Ocultar Conteúdo do PDF remove permanentemente o que cobrir: desenhe retângulos pretos sobre áreas sensíveis em qualquer página e a ferramenta reconstrói cada página como uma imagem com as caixas pintadas - o texto por baixo já não existe no ficheiro, pelo que não pode ser copiado, pesquisado ou descoberto.

Cobrir texto com uma forma preta num editor não é ocultação - as palavras ficam muitas vezes escondidas por baixo, prontas para copiar. Esta ferramenta faz o processo da forma segura: cada página é recriada como uma imagem com as suas caixas pretas gravadas, para o conteúdo coberto desaparecer verdadeiramente.

Compromisso honesto: porque as páginas são reconstruídas como imagens para garantir a remoção, o texto do PDF ocultado é já não selecionável nem pesquisável em qualquer página, e o ficheiro pode ser maior. Esse é o preço de uma ocultação que não pode ser anulada - e é indicado aqui, não escondido.

Perguntas Frequentes

O conteúdo coberto é mesmo removido ou apenas escondido?

Realmente removido. Cada página é renderizada para uma imagem, as caixas pretas são pintadas nessa imagem e um PDF totalmente novo é construído apenas a partir dessas imagens. A camada de texto original nunca entra no ficheiro novo, pelo que não há nada por baixo para copiar, pesquisar ou revelar.

Porque é que o texto no meu PDF ocultado já não é selecionável?

Porque cada página é agora uma imagem - é exatamente isso que garante a remoção. Se precisar de um documento que continue selecionável, oculte apenas uma cópia para partilhar e mantenha o original privado.

Alguém pode remover as caixas pretas com um editor?

Não. As caixas não são objetos separados colocados sobre o texto; fazem parte da própria imagem da página, como tinta impressa em papel. Mover ou eliminar objetos num editor não pode trazer de volta píxeis que nunca foram guardados.

O tamanho do ficheiro mudará?

Normalmente cresce, porque as páginas de imagem são mais pesadas do que as páginas de texto - especialmente em documentos longos. As páginas são renderizadas com uma resolução nítida de 2x e uma compressão JPEG de boa qualidade para equilibrar nitidez e tamanho.

Como funciona

A ferramenta renderiza cada página PDF no seu navegador com PDF.js. Quando arrasta sobre uma página, o seu retângulo é guardado nas verdadeiras coordenadas PDF dessa página. Ao transferir, cada página é renderizada novamente com resolução de 2x para uma tela fora do ecrã, os seus retângulos pretos são pintados na tela e a tela é guardada como JPEG. Um novo PDF é depois montado com pdf-lib contendo apenas essas imagens de página. O texto, os vetores e as camadas escondidas do ficheiro original nunca são copiados para o resultado - razão pela qual o conteúdo coberto é irrecuperável a partir dele.

Exemplo resolvido

Uma escola tem de partilhar uma pauta de resultados, mas esconder os números de identificação dos alunos. O funcionário desenha uma caixa sobre a coluna de identificação em todas as 3 páginas e transfere results-redacted.pdf. Depois, ela tenta selecionar e copiar os números no ficheiro partilhado - impossível, porque essa coluna é agora simplesmente píxeis pretos.

Perguntas frequentes

Com que resolução são as páginas reconstruídas?

As páginas são renderizadas com o dobro do seu tamanho normal (2x, cerca de 144 DPI) e guardadas como imagens JPEG de alta qualidade com as dimensões originais das páginas, para as impressões manterem a nitidez enquanto o ficheiro continua razoável.

Devo ocultar uma digitalização de forma diferente?

Não. As páginas digitalizadas já são imagens e aplica-se a mesma gravação: os píxeis cobertos são substituídos por preto na imagem reconstruída.

A ocultação também remove os metadados?

O PDF reconstruído é um ficheiro novo e não copia o texto nem o conteúdo escondido das páginas do original. As informações básicas do documento original não são transportadas; se o próprio nome do ficheiro ou os metadados forem sensíveis, mude o nome da transferência e verifique-a com a nossa ferramenta Editar Informações do PDF.

Posso ocultar apenas uma página e manter o resto como texto?

Não com esta ferramenta - todas as páginas são reconstruídas como imagens para o processo ser uniforme e nada escapar numa página não processada. É uma escolha de segurança deliberada.

O que devo verificar antes de partilhar o ficheiro ocultado?

Abra-o e percorra cada página: confirme se cada caixa cobre totalmente o seu alvo com uma pequena margem e experimente selecionar texto - não deverá conseguir selecionar nada, o que confirma que a gravação funcionou.
