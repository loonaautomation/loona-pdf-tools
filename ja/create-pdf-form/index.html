PDFフォームを作成 オンライン - 無料

要するに： 「PDFフォームを作成」ツールは、普通のPDFに本物の入力可能フィールドを追加します：フィールドがあるべき場所にページ上でボックスをドラッグし、名前を付け、テキストフィールドかチェックボックスを選び、当社の「PDFフォームに入力」ツールを含め、どのリーダーでも入力できる本物のAcroForm PDFをダウンロードできます。

多くのフォームは線のあるだけのフラットなページで、誰も入力できません。このツールはその線の上に本物のフォームフィールドを配置するため、フォームを送った相手が印刷するのではなく、スマートフォンやパソコンで入力できます。

ページ上をドラッグしてフィールドのボックスを描き、「フィールドを追加」をクリックしてください。描かずに追加した場合は、標準のボックスがページ中央に配置されます。フィールド名は一意でなければなりません。

設計によるプライバシー： ファイルは、JavaScriptを使ってブラウザで100%処理されます。サーバーにアップロードされたり、保存されたり、私たちが目にしたりすることは決してありません。タブを閉じれば、すべては消えます。

このツールの使い方

  1. 任意のPDFを選んでください。例えば空白行のあるフラットフォームです。
  2. ページ上をドラッグして、回答が入る場所にボックスを描いてください。
  3. フィールドに名前を付け（例：student_name）、テキストフィールドかチェックボックスを選び、「フィールドを追加」をクリックしてください。
  4. すべての回答欄について繰り返し、次に入力可能なPDFをダウンロードして、「PDFフォームに入力」ツールでテストしてください。

よくある質問

フィールドは本物のフォームフィールドですか、それとも単なる描画ですか？

本物です。ダウンロードには、pdf-libで作成された標準のAcroForm定義が含まれます：フィールドは、付けた名前を持つ本物の入力可能フィールドとして、Adobe Acrobat、ブラウザ、当社の「PDFフォームに入力」ツールに表示されます。

どのようなフィールドの種類を追加できますか？

テキストフィールド（一行）とチェックボックスです。それらは日常のほとんどのフォームをカバーします。ドロップダウン、ラジオグループ、署名フィールドはここでは提供されません。その制限は偽るのではなく、正直に明示されています。

フィールド名はなぜ一意でなければならないのですか？

フォームフィールドの名前はその識別子です。同じ名前の二つのフィールドは常に同じ回答を表示します。このツールは重複した名前をブロックし、フォームが正しく動作するようにします。

フィールドを追加した後に移動できますか？

ページ下のリストから取り除き、正しい位置に再び追加してください。フィールドは「ダウンロード」をクリックしたときにのみダウンロードファイルに焼き込まれるため、ここでの試行は自由です。

仕組み

このツールはPDF.jsでPDFを描画し、ライブページプレビュー上にフィールドボックスを描けるようにします。追加した各フィールドは、そのページ番号、本物のPDFポイント座標でのボックス、種類、名前とともに保存されます。ダウンロード時、pdf-libは元のファイルを開き、対応するAcroFormフィールド（各項目に対するテキストフィールドまたはチェックボックス）を作成し、保存された位置に、入力者が入力する場所が分かるよう薄い背景と枠線とともに、各フィールドをそのページに追加します。その結果は、完全にブラウザで作成された、標準の入力可能なPDFです。

実例

学校の事務室には、印刷された罫線のあるフラットなPDFの入学願書があります。事務担当者は罫線の上にボックスをドラッグし、名前を付けます student_name, date_of_birth と guardian_phone、という名前のチェックボックスを追加し、 documents_attached、フォームをダウンロードします。保護者の皆さまは今ではスマートフォンの「PDFフォームに入力」ツールで記入してメールで返送できます。印刷は一切不要です。

よくある質問

位置はどのようにPDFに変換されますか？

画面ピクセルで、描画されたページ上に描きます。このツールは、ページの本物のサイズを使ってそれらをPDFポイントに変換し、垂直軸を反転させます。PDF座標は左下から始まり、画面は左上から始まるためです。

フィールドを追加すると、ドキュメントのページは変わりますか？

いいえ。元のページはpdf-libで変更されずにコピーされ、フォームフィールドがその上に重ねられます。テキスト、画像、レイアウトは正確に元のままです。

テキストフィールドのボックスはどれくらいの大きさが良いですか？

フォームに印刷された空白行やボックスとほぼ同じサイズです。非常に短いボックスは、一部のリーダーで入力したテキストが視覚的に切れてしまうため、手書きサイズのスペースには少し余分な高さを与えてください。

入力した回答を後からフラット化できますか？

はい。フォームに入力する人は誰でも、当社の「PDFフォームに入力」または「PDFをフラット化」ツールを使って回答をページに焼き込み、最終の変更不可能な提出コピーにできます。

フォームはスマートフォンでも機能しますか？

はい。標準のAcroFormフィールドは、最新のスマートフォンやブラウザに内蔵されたPDFビューアーで対応しています。非常に古い、または最小限のビューアーでは、フィールドなしでページが表示される場合があります。
