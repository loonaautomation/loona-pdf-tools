HTML سے PDF کنورٹر

مختصراً: یہ ٹول آپ کا HTML براؤزر کے اپنے انجن سے بناتا ہے اور پرنٹ منظر کھولتا ہے جہاں آپ اسے PDF کے طور پر محفوظ کرتے ہیں — پکسل درست CSS، صفر اپ لوڈ۔

زیادہ تر 'HTML سے PDF' سائٹس آپ کا مارک اپ سرور قطار پر اپ لوڈ کرتی ہیں۔ یہ آپ کے آلے پر پہلے سے موجود پرنٹ انجن استعمال کرتی ہے — تیز تر، نجی، اور جدید CSS میں بہتر۔

ڈیزائن کے لحاظ سے نجی: آپ کی فائلیں 100% آپ کے براؤزر میں JavaScript کے ساتھ پروسیس ہوتی ہیں۔ وہ کبھی سرور پر اپ لوڈ نہیں ہوتیں، کبھی ذخیرہ نہیں ہوتیں اور ہم کبھی نہیں دیکھتے - ٹیب بند کریں اور سب کچھ گیا۔

یہ کیسے کام کرتا ہے، مرحلہ وار

  1. HTML پیسٹ کریں یا .html فائل لوڈ کریں — پیش منظر براہ راست تازہ ہوتا ہے۔
  2. پرنٹ منظر نئی ٹیب میں کھولنے کے لیے بٹن دبائیں۔
  3. پرنٹ ڈائیلاگ میں 'Save as PDF' منتخب کریں اور محفوظ کریں۔

اکثر پوچھے گئے سوالات

HTML بغیر سرور کے PDF کیسے بنتا ہے؟

آپ کے اپنے براؤزر کے پرنٹ ٹو PDF سے — وہی انجن جو Chrome اور Edge ہر 'Save as PDF' کے لیے استعمال کرتے ہیں۔ ٹول آپ کا HTML صاف پرنٹ منظر میں بناتا ہے اور پرنٹ ڈائیلاگ کھولتا ہے؛ آپ پرنٹر کے طور پر 'Save as PDF' منتخب کرتے ہیں۔ مکمل CSS (پرنٹ اسٹائل شیٹ اور @page اصول سمیت) کی تعمیل ہوتی ہے، جو سرور سے پاک کنورٹر عموماً غلط کرتے ہیں۔

کیا میرا CSS کام کرے گا؟

ہاں — کیونکہ بنانے والا انجن خود براؤزر ہے۔ حاشیوں اور صفحہ سائز کنٹرول کے لیے اپنے HTML میں @media print اور @page استعمال کریں۔

کیا میرا HTML اپ لوڈ ہوتا ہے؟

نہیں۔ یہ مقامی طور پر سینڈ باکس پیش منظر اور مقامی پرنٹ منظر میں بنایا جاتا ہے۔

پس منظر میں

پیش منظر سینڈ باکس شدہ iframe استعمال کرتا ہے (اسکرپٹ نہیں چل سکتیں)۔ پرنٹ منظر آپ کا درست HTML نئے ٹیب میں لکھتا ہے اور براؤزر پرنٹ ڈائیلاگ بلاتا ہے۔ کیونکہ کنورٹر براؤزر ہی ہے، flexbox، گرڈ، ویب فانٹ اور پرنٹ CSS بالکل اسی طرح برتاؤ کرتے ہیں جیسے آپ کی اپنی مشین پر — کوئی سرور رینڈرر اس کا وعدہ نہیں کر سکتا۔

کام کیا گیا مثال

A4 حاشیوں کے لیے @page قاعدے والا HTML انوائس ٹیمپلیٹ پکسل درست PDF انوائس بناتا ہے — وہی آؤٹ پٹ جس کے لیے ٹیمپلیٹ ڈیزائن کیا گیا تھا۔
