Redact PDF Online - Free (True Burn-In Redaction)

In short: the Redact PDF tool permanently removes what you cover: draw black rectangles over sensitive areas on any page, and the tool rebuilds every page as an image with the boxes painted in - the text underneath no longer exists in the file at all, so it cannot be copied, searched or uncovered.

Covering text with a black shape in an editor is not redaction - the words often stay hidden underneath, ready to copy out. This tool does it the safe way: every page is re-created as a picture with your black boxes burned in, so covered content is truly gone.

Honest trade-off: because pages are rebuilt as images to guarantee removal, the redacted PDF's text is no longer selectable or searchable on any page, and the file may be larger. That is the price of redaction that cannot be undone - and it is stated here, not hidden.

Frequently Asked Questions

Is the covered content really removed, or just hidden?

Really removed. Each page is rendered to an image, the black boxes are painted into that image, and a brand-new PDF is built from those images only. The original text layer never enters the new file, so there is nothing underneath to copy, search or reveal.

Why is the text in my redacted PDF no longer selectable?

Because every page is now a picture - that is exactly what guarantees the removal. If you need a document that stays selectable, redact only a copy for sharing and keep the original private.

Can someone remove the black boxes with an editor?

No. The boxes are not separate objects placed over text; they are part of the page image itself, like ink printed on paper. Moving or deleting objects in an editor cannot bring back pixels that were never saved.

Will the file size change?

Usually it grows, because image pages are heavier than text pages - especially for long documents. Pages are rendered at a clear 2x resolution with good-quality JPEG compression to balance sharpness and size.

How it works

The tool renders each PDF page in your browser with PDF.js. When you drag on a page, your rectangle is stored in true PDF coordinates for that page. On download, every page is rendered again at 2x resolution to an off-screen canvas, your black rectangles are painted onto the canvas, and the canvas is saved as a JPEG. A new PDF is then assembled with pdf-lib containing only those page images. The original file's text, vectors and hidden layers are never copied into the output - which is why covered content is unrecoverable from it.

Worked example

A school must share a results sheet but hide students' ID numbers. The clerk draws a box over the ID column on all 3 pages and downloads results-redacted.pdf. Afterwards she tries to select and copy the numbers in the shared file - impossible, because that column is now simply black pixels.

Frequently asked questions

What resolution are the rebuilt pages?

Pages are rendered at twice their normal size (2x, roughly 144 DPI) and stored as high-quality JPEG images at their original page dimensions, so printouts stay sharp while the file remains reasonable.

Should I redact a scan differently?

No. Scanned pages are already images, and the same burn-in applies: the covered pixels are replaced by black in the rebuilt image.

Does redaction remove metadata too?

The rebuilt PDF is a new file and does not copy the original's text or hidden page content. Basic document info from the original is not carried over; if the file name or metadata itself is sensitive, rename the download and check it with our Edit PDF Info tool.

Can I redact just one page and keep the rest as text?

Not with this tool - all pages are rebuilt as images so the process is uniform and nothing slips through on an unprocessed page. That is a deliberate safety choice.

What should I check before sharing the redacted file?

Open it and flip through every page: confirm each box fully covers its target with a small margin, and try selecting text - you should be unable to select anything, which confirms the burn-in worked.
