Markdown to PDF Converter

In short: this tool renders your Markdown to a styled page and opens a print view to save as PDF — in your browser.

READMEs, notes and drafts written in Markdown often need to leave the editor as a document. This converter styles them cleanly (serif body, tidy code blocks) and hands you a PDF.

Private by design: your files are processed 100% in your browser with JavaScript. They are never uploaded to a server, never stored and never seen by us - close the tab and everything is gone.

How it works, step by step

  1. Paste Markdown or load a .md file — preview updates live.
  2. Press the button for the print view.
  3. Choose 'Save as PDF' in the print dialog.

Frequently Asked Questions

Which Markdown is supported?

Headings (# to ####), bold, italic, inline code, code blocks, bullet lists, links and horizontal rules — the everyday 95%. Tables and embedded images are NOT rendered by this lightweight converter; that limit is stated here rather than hidden.

How is the PDF produced?

The rendered HTML opens in a print view and your browser's 'Save as PDF' makes the file — so fonts and pagination are your browser's best quality.

Is my text uploaded?

No — rendering happens locally.

Under the hood

A small purpose-built renderer handles the core Markdown constructs and styles the output for print (720px measure, serif body). The print view uses your browser's PDF engine.

Worked example

A project README pasted in becomes a clean 3-page PDF brief — headings, bullet lists and code samples intact — ready to email to a non-technical client.
