Frequently Asked Questions

Why a separate page per size?

Because the advice differs: 20 KB is for single-page ID scans, 2 MB is a CMS cap, 16 MB is about WhatsApp deliverability. Each page carries the context and worked example for its number, not just a different preset.

What if no target fits my document?

The tools report the smallest achievable size honestly. Splitting the PDF is then the practical route — the Split PDF tool is linked on every target page.

Under the hood

Every target page shares one engine: a lossless pdf-lib re-save first (text stays selectable), then a PDF.js render ladder that stops at the first setting under the target. No page ever degrades a document further than its number requires.
