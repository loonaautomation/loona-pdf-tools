Loona PDF Editor

簡而言之： Loona PDF Editor 讓您可以在任何 PDF 頁面上新增文字、圖片、形狀和醒目提示，用塗白遮蓋錯誤，自由手繪，並放置繪製或輸入的簽名 — 然後下載完成的檔案。它新增和遮蓋內容；它不會重寫 PDF 的原始文字。

需要在表單上新增備註、更正發票上的總額、放置您的標誌或簽署一封信 — 無需列印和掃描？在這裡開啟 PDF，將所需內容直接新增到頁面上，然後下載完成的檔案。一切都在您的裝置上完成：無上傳、無註冊、無頁數限制、無浮水印。

在頁面上的使用方法：選擇一個工具，然後在下方頁面上點擊或拖動。使用文字工具時，點擊文字應開始的位置 — 或使用「新增文字」按鈕。矩形、醒目提示和塗白透過拖動繪製。用選擇工具點擊任何元素即可移動它，拖動其金色角可調整大小，或將其刪除。每個頁面的元素都會被單獨記住。

如何編輯 PDF

  1. 點擊上方框並選擇您的 PDF。檔案會直接在您的瀏覽器中開啟 — 不會上傳任何內容。
  2. 選擇一個工具：文字、矩形、醒目提示、塗白或繪圖 — 或新增圖片或簽名。
  3. 在頁面上點擊或拖動以放置元素。使用選擇工具移動它，拖動金色角調整大小，或在改變主意時將其刪除。
  4. 使用「上一頁」/「下一頁」按鈕或頁面下拉選單在頁面之間移動。每個頁面都保留自己的元素，因此您可以逐頁編輯長文件。
  5. 當一切無誤後，點擊「匯出編輯後的 PDF」。您新增的內容會被壓平到原始頁面上，完成的檔案將以 您的檔案名-edited.pdf 的形式下載。

此編輯器能做什麼、不能做什麼

這是一個疊加式編輯器，我們寧願直白地告訴您這意味著什麼，也不願讓您日後才發現。

它能做的

  • 新增文字 — 在頁面任意位置，使用五種經典字體（Helvetica、Helvetica Bold、Times、Times Bold 和 Courier），任意大小和顏色。
  • 新增圖片 — 標誌、印章、照片 — 並放置您用滑鼠或手指繪製的簽名，或輸入姓名產生的簽名。
  • 繪製矩形和醒目提示來標註文件，並用畫筆工具自由手繪。
  • 用塗白遮蓋錯誤：在錯誤的單詞或數字上畫一個不透明的方塊，然後在上面輸入更正內容。
  • 您新增的一切都可以在任何頁面上移動、調整大小和刪除，並匯出一份壓平的成品 PDF。

它不能做的

  • 它不會像文書處理軟體那樣更改、移動或重排 PDF 的原始文字。檔案中已有的文字會準確地保留在原位置。
  • 要修正錯字，請用塗白遮蓋錯誤的單詞，然後在上面輸入更正內容 — 這是誠實的變通方法，對表單、發票和信件都非常有效。
  • 這裡的塗白是視覺遮蓋：被遮蓋的內容仍存在於方塊下方的檔案內部。如果在分享前必須永久刪除敏感內容，請改用我們的 遮蓋 PDF 工具，它會將方塊固化到重建的頁面圖片中。
  • 它無法開啟受密碼保護的 PDF，也不是表單填寫工具 — 對於已有的表單欄位，請使用 填寫 PDF 表單。

隱私 — 您的檔案永遠不會離開您的裝置

每一步 — 開啟、算繪、編輯和匯出 — 都使用 JavaScript 在您的瀏覽器中 100% 執行（PDF.js 算繪頁面，pdf-lib 編寫完成的檔案）。您的 PDF 從不上傳到伺服器，從不儲存，也從不被我們看到，並且編輯器本身在您工作時不會發出任何網路請求。關閉分頁，一切都會消失。無需註冊，無頁數限制，無浮水印。

常見問題

它能更改我 PDF 中的原始文字嗎？

不能。Loona PDF Editor 是在頁面上方新增和遮蓋內容；它無法重寫、移動或重排檔案中已有的文字。要修正錯誤的單詞，請在其上畫一個塗白方塊，然後在上面輸入更正內容 — 視覺上，頁面就會完全按照您的意願呈現。

如何用此編輯器修正 PDF 中的錯字？

選擇塗白工具，在錯誤的單詞上拖動一個方塊。然後選擇文字工具（或「新增文字」按鈕），以相符的字體和大小輸入更正後的單詞，並將其拖到塗白上方的位置。匯出後，完成的頁面只顯示更正內容。

我的 PDF 會上傳到伺服器嗎？

不會。編輯器完全在您的瀏覽器中執行：PDF.js 在畫面上繪製頁面，pdf-lib 在您的裝置上建立完成的檔案。沒有任何內容被上傳、儲存或被我們看到，也無需註冊。

Loona PDF Editor 真的免費嗎？

是的 — 免費，無需註冊，無頁數限制，匯出的檔案也沒有浮水印。您可以編輯任意多的 PDF。

我能在此編輯器中簽署 PDF 嗎？

可以。點擊「新增簽名」，用滑鼠或手指在簽名板上繪製您的簽名 — 或輸入您的姓名將其轉換為簽名圖片 — 然後將其作為可移動、可調整大小的圖片放置在目前頁面上。這是視覺簽名，不是基於憑證的數位簽名；對於僅簽名的任務，您也可以使用我們專門的簽署 PDF 工具。

塗白會永久刪除它遮蓋的內容嗎？

不會，我們不會假裝它會。塗白在內容上繪製不透明的遮蓋層，使其不再顯示或列印 — 但原始內容仍存在於檔案內部的下方。如果內容敏感且必須徹底消失，請使用我們的遮蓋 PDF 工具，它會將每個頁面重建為圖片並將方塊固化其中。

我新增的文字可以使用哪些字體？

五種標準 PDF 字體：Helvetica、Helvetica Bold、Times、Times Bold 和 Courier，任意大小和顏色。由於這些字體內建於每個 PDF 閱讀器中，您新增的文字可以在任何地方正確顯示，而不會使檔案變大。

我新增的元素會保持在正確的位置嗎？

會。元素按頁面以真實的 PDF 座標（點）儲存，而不是畫面像素，因此匯出檔案時，每個元素都會以您安排的確切位置、大小和順序繪製到其頁面上 — 無論頁面大小如何。

運作原理

當您開啟檔案時，PDF.js 會將目前頁面算繪到瀏覽器中的畫布上。您新增的一切 — 文字框、圖片、矩形、醒目提示、塗白方塊、自由手繪線條或簽名 — 都繪製在該畫布上方的透明圖層上，並以真實的 PDF 座標（以點為單位）為該頁面儲存。切換頁面永遠不會混淆元素：每個頁面都按您新增的順序保留自己的清單。匯出時，pdf-lib 開啟您的原始檔案，並以相同的座標將每個元素繪製到其頁面上，將畫面上自上而下的位置轉換為 PDF 自己的座標系，然後以名稱中帶有 -edited 的方式儲存結果。由於原始頁面被保留，只有您新增的內容繪製在上方，輸出仍然是真正的、可選擇文字的 PDF — 這與將頁面重建為圖片的工具不同。

實際範例

一份發票 PDF 顯示了錯誤的總額「Rs 4,500」，並且缺少您的企業標誌。您在舊總額上拖動一個塗白方塊，在上面用 Helvetica Bold 新增文字「Rs 5,400」，將標誌圖片放置在頁面頂部，並在簽名框中輸入您的姓名在底部簽名。點擊一次「匯出編輯後的 PDF」即可下載 invoice-edited.pdf — 已更正、已加品牌、已簽名，發票的其餘部分保持不變。
