PDF 轉 Markdown 轉換器

簡而言之： 本工具提取 PDF 的文字並將其重建為結構化 Markdown，標題根據字型大小檢測——在您的瀏覽器中。

PDF 用於閱讀，而不是重複使用。此轉換器將文字恢復為 Markdown，您可以編輯、釋出或貼上到其他地方——下載前有一個誠實的編輯步驟。

隱私設計： 您的檔案用 JavaScript 在您的瀏覽器中 100% 處理。它們永遠不會上傳到伺服器，永遠不會儲存，也永遠不會被我們看到——關閉標籤頁，一切都消失了。

工作原理，分步說明

  1. 選擇基於文字的 PDF。
  2. 在編輯器中檢視提取的 Markdown——修復轉換器誤讀的任何行。
  3. 下載完成的檔案。

常見問題

這裡的 PDF 轉 Markdown 轉換如何工作？

PDF.js 讀取文件的文字層——與您在閱讀器中可以選擇的文字相同——並按閱讀順序重建行。字型大小與文件的中位數比較：大得多的行成為頂級標題，大一些的行成為子標題。

圖片和佈局會保留嗎？

不——而且本工具預先說明了這一點。Markdown 輸出是文字重建：圖片不嵌入，多欄佈局按文字順序儘可能逐欄讀取。如需畫素級完美的副本，PDF 本身就是文件；此轉換用於重複使用文字。

我的 PDF 是掃描件。它能工作嗎？

掃描的 PDF 沒有文字層，因此提取找不到任何內容。請先透過 Loona Text Tools 上的 OCR 工具執行掃描件，然後轉換得到的文字。

我的 PDF 會被上傳嗎？

不——提取在您的瀏覽器中用 PDF.js 執行。

幕後原理

提取按垂直位置將文字專案分組為行，從左到右排序，並根據頁面中位數測量每行的字型大小以分配標題級別。分頁符變成分隔符。結果出現在上方的編輯器中，以便您在下載前修復任何問題——PDF 轉換永遠不會完美，假裝不是這樣是不誠實的。

實際示例

一份 12 頁的 PDF 報告會變成結構化的 Markdown 文件——標題作為頂級標題，章節標題作為子標題，正文作為段落——可以直接貼上到網站或文件編輯器中。
