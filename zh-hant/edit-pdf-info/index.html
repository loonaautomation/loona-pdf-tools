線上編輯 PDF 資訊（後設資料）- 免費

簡而言之： “編輯 PDF 資訊”工具顯示 PDF 的隱藏後設資料——標題、作者、主題、關鍵詞、建立者和製作程式——並讓您在儲存副本之前更改標題、作者、主題和關鍵詞。

每份 PDF 都帶有隱藏資訊：瀏覽器標籤頁和搜尋結果中顯示的標題、作者姓名等等。由掃描件或匯出生成的檔案往往數值錯誤或為空。在分享之前，在這裡檢查並修復它們。

隱私設計： 您的檔案用 JavaScript 在您的瀏覽器中 100% 處理。它們永遠不會上傳到伺服器，永遠不會儲存，也永遠不會被我們看到——關閉標籤頁，一切都消失了。

如何編輯 PDF 後設資料

  1. 選擇一個 PDF——其當前後設資料會出現在摘要網格中。
  2. 編輯標題、作者、主題和關鍵詞欄位。
  3. 點選“儲存帶新資訊的 PDF”並下載更新後的副本。

常見問題

什麼是 PDF 後設資料？

它是儲存在檔案內部的描述性資訊——標題、作者、主題和關鍵詞——供閱讀器、搜尋引擎和文件系統用來標記檔案。

編輯後設資料會改變頁面嗎？

不。只有資訊欄位會改變；頁面內容不會被觸碰。

為什麼標題很重要？

後設資料標題是顯示在瀏覽器標籤頁、PDF 閱讀器標題欄和許多搜尋結果中的內容——清晰的標題使文件看起來專業。

我可以刪除作者姓名嗎？

是。清除該欄位並儲存——儲存的副本將攜帶空的作者值。

工作原理

當您選擇檔案時，工具在您的瀏覽器內用 pdf-lib 讀取其當前文件資訊——不上傳任何內容——並向您顯示已儲存在檔案中的標題、作者、主題、關鍵詞、建立者和製作程式。標題、作者、主題和關鍵詞框預先填充了這些值以便編輯。儲存時，工具將您的新值寫入文件資訊，將修改日期重新整理為今天，並以名稱中帶 -updated 的方式下載結果。只有隱藏資訊被更改；任何頁面都不會被觸碰。

實際示例

一份下載的講義名為 scan_2026.pdf，其屬性顯示無標題，製作程式為掃描程式。您將標題設定為“Physics Notes - Chapter 4”，作者設定為您自己的姓名，主題設定為“Class 10 Physics”，關鍵詞設定為“physics, notes, chapter 4”。更新後的檔案現在在閱讀器的標題欄和屬性面板中顯示“Physics Notes - Chapter 4”，學生一眼就能識別。

常見問題解答

我在這裡實際可以編輯哪些欄位？

標題、作者、主題和關鍵詞。Creator 和 Producer 會顯示出來，讓您看到檔案當前攜帶的內容，但它們在本工具中僅供顯示——這是它能更改內容的誠實限制。

應該如何輸入關鍵詞？

用逗號分隔它們，與框中所示完全一致——例如“invoice, 2026, office”。工具在儲存時為您整理多餘的空格和空條目。

修改日期也會改變嗎？

是。儲存會以當前日期和時間作為其修改日期蓋印文件，這與大多數桌面編輯器在更新檔案資訊時的做法一致。

我在哪裡會看到新標題？

在任何 PDF 閱讀器中開啟檔案並檢查其文件屬性；大多數閱讀器還會在視窗或標籤頁中顯示文件標題，而不是原始檔名稱，搜尋工具在索引檔案時也會使用它。

我可以編輯受密碼保護的 PDF 的資訊嗎？

不——檔案必須能開啟，其資訊才能被讀取和重寫，受保護的檔案會顯示錯誤。請先在建立該檔案的應用中刪除密碼。
