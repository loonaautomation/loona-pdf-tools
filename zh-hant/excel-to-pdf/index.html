Excel 轉 PDF 轉換器

簡而言之： 本工具將 Excel 工作簿變成整潔的 PDF——每個工作表一張表格，表頭行在每個頁面重複，完全在您的瀏覽器中構建。

電子表格用於編輯；PDF 用於分享。此轉換器讀取您的 .xlsx、.xls 或 .csv 檔案，並將每個工作表排版為列印就緒 PDF 中的整潔表格——數字和日期與 Excel 顯示的完全一致。

點選選擇 Excel 或 CSV 檔案
或將它拖放到此處——.xlsx、.xls 或 .csv
隱私設計： 您的檔案用 JavaScript 在您的瀏覽器中 100% 處理。它們永遠不會上傳到伺服器，永遠不會儲存，也永遠不會被我們看到——關閉標籤頁，一切都消失了。

工作原理，分步說明

  1. 選擇或拖放您的 .xlsx、.xls 或 .csv 檔案。
  2. 選擇頁面大小和方向——當一張紙有許多列時，自動選擇橫向。
  3. 按“轉換為 PDF”，然後從出現的連結下載結果。

功能

  • 工作簿中的每個工作表成為其自己的表格，從新頁開始。
  • 格式化數值：數字、貨幣和日期與 Excel 顯示的完全一致——永遠不會是原始序列號。
  • 每個工作表的第一行被視為表頭，並在每個頁面的頂部重複。
  • 長文字在其單元格內換行，而不是被切掉。
  • 頁面大小、方向和適合寬度控制元件，適用於寬或窄的紙張。
  • 不上傳，無需註冊，無水印——檔案永遠不會離開您的裝置。

常見問題

支援 .xlsx 嗎？

是——現代 .xlsx 工作簿、舊 .xls 檔案和純 .csv 檔案都在頁面中本地讀取。不需要載入項或賬戶。

多個工作表會發生什麼？

工作簿中的每個工作表成為其自己的表格，並從新頁開始，按工作簿順序，工作表名稱列印為其標題。

公式會轉換嗎？

您得到結果——Excel 最後計算並儲存在檔案中的值，以其正常格式顯示。公式本身不會被列印。

為什麼圖表和顏色沒有出現在 PDF 中？

此轉換器將您工作表的值匯出為乾淨的表格。圖表、圖片、單元格顏色、字型和合並單元格佈局不會被保留。如果您需要帶樣式工作表的畫素級完美副本，請從 Excel 本身列印為 PDF。

我的檔案會被上傳嗎？

不。工作簿在您的瀏覽器中完全解析，PDF 也在其中構建——不會向伺服器傳送任何內容。

幕後原理

檔案由 SheetJS 解析，PDF 表格用 jsPDF 及其 AutoTable 外掛繪製。所有三個庫都從本網站自己的庫資料夾載入——您工作時不會從 CDN 獲取任何內容，也不會有任何內容離開您的裝置。這是一個忠實的表格匯出——不是電子表格克隆：單元格值及其顯示格式會保留，而圖表、圖片、顏色和合並單元格佈局不會，FAQ 在上面明確說明了這一點。

實際示例

一本包含成績表和費用表的工作簿變成一份包含兩張表格的 PDF——每個工作表各佔其頁，表頭行在每一頁重複——可以直接透過電子郵件傳送或列印存入辦公室檔案。
