線上免費證書製作工具 - 可列印證書

簡而言之： 輸入收件人的姓名和一些詳細資訊，在實時 A4 預覽上觀看證書設計本身，然後下載列印就緒的 PDF（或 PNG）——免費，無需註冊，無水印。需要為整個班級或課程頒發證書？切換到批次模式，每行貼上一個姓名，獲得一份 PDF，每個姓名一張證書。

證書通常意味著一個您不太會用的設計工具、一個鎖在付費牆後的模板，或在最後一步收取尷尬的下載費。在這裡，一切都在此頁面上完成：三種現成的設計，每個字都可編輯，自動繪製金色印章——成品 PDF 在您的瀏覽器中構建，姓名和詳細資訊永遠不會離開您的裝置。

上面的每個其他欄位——課程、日期、頒發者、簽名和設計——在每張證書上保持不變；只有姓名改變。空白行會被忽略，重複的姓名會被保留。

隱私設計： 您的證書被設計，您的 PDF 用 JavaScript 在您的瀏覽器中 100% 構建。姓名和詳細資訊永遠不會上傳到伺服器，永遠不會儲存，也永遠不會被我們看到——關閉標籤頁，一切都消失了。這對證書很重要：班級姓名列表保留在您自己的裝置上。

如何製作證書

  1. 選擇三種設計之一併輸入您的詳細資訊——標題、收件人姓名、課程行、描述、日期、頒發者和簽名姓名。A4 橫向預覽會隨著您的輸入重新繪製。
  2. 對於單張證書，點選“下載 PDF”獲得列印就緒檔案，或點選“下載 PNG”獲得可分享的圖片。
  3. 如需一次製作許多證書，請切換到批次模式，每行貼上一個姓名（最多 200 個），然後點選“生成批次 PDF”——您會得到一份 PDF，每個姓名一頁，可以直接列印。

常見問題

這個證書製作工具真的免費嗎？

是。它完全免費，無需註冊，無水印——包括批次模式。許多證書網站讓您免費設計，然後對下載收費；在這裡下載也是免費的。

我輸入的姓名會被上傳到任何地方嗎？

不。證書被繪製，PDF 在您的瀏覽器中 100% 構建。姓名、日期和每個其他細節永遠不會離開您的裝置。

批次模式可以製作多少張證書？

每次執行在一份 PDF 中最多 200 張證書。每行貼上一個姓名；空白行被忽略，重複姓名被保留，因此兩個同名的學生各得到一張證書。

證書的尺寸是多少？

每張證書都是標準的 A4 橫向頁面，以 150 dpi 繪製，因此在任何家用或辦公室印表機上都能清晰列印。在印表機對話方塊中選擇“實際大小”或 100%，以獲得精確的適合。

我可以更改設計嗎？

是。有三種內建設計——優雅金色、現代藍色和經典——證書上的每個字都可編輯：標題、收件人姓名、課程行、描述、日期、頒發者和簽名姓名。

工作原理

證書在 HTML canvas 上以完整的 A4 橫向大小繪製（297 x 210 mm，在 150 dpi 下——1754 x 1240 畫素）。每當您輸入時，每個元素都從您的文字重新繪製：雙線邊框和角落裝飾、標題、帶緞帶尾巴的金色印章，以及草書風格的簽名線。當您下載 PDF 時，完成的繪圖由 pdf-lib 庫放在 A4 橫向頁面上——與我們其他 PDF 工具使用的庫相同——因此檔案列印出來與預覽完全一致。在批次模式下，相同的繪圖按每個姓名重複一次，進入一份多頁 PDF，並帶有進度條，以便您可以觀看長列表完成。

實際示例

一位教師完成了為期兩天、28 名參與者的培訓研討會。她開啟批次模式，保留標題“Certificate of Participation”，將課程行設定為她的研討會名稱，從名冊中貼上 28 個姓名——每行一個——然後點選“生成”。一分鐘後，她得到一份 28 頁的 PDF；她對照名冊仔細檢查後列印，在每頁的印刷簽名線上方簽名，並在同一天發放證書。無需設計軟體，無需上傳學生姓名，也無需付費。

常見問題解答

我可以新增自己的標誌或手寫簽名圖片嗎？

不在此版本中——設計使用內建印章和印刷的簽名姓名。許多人會列印證書並在簽名線上方親手簽名，這樣看起來更 有人情味。

為什麼姓名在一些證書上縮小？

非常長的姓名會自動縮小大小，使它們始終在邊框內適合一行。縮短中間名通常能保持更大、更 宏大的尺寸。

批次模式除了姓名還會改變其他內容嗎？

不。標題、課程、描述、日期、頒發者、簽名和設計在每個頁面上都相同——只有收件人姓名改變，就像一疊印刷品一次填寫一個姓名一樣。
