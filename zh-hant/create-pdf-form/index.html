線上建立 PDF 表單 - 免費

簡而言之： “建立 PDF 表單”工具為任何普通 PDF 新增真正可填寫的欄位：在頁面上欄位應出現的位置拖動一個框，給它命名，選擇文字欄位或核取方塊，並下載一份可以在任何閱讀器中填寫的真正 AcroForm PDF——包括我們自己的“填寫 PDF 表單”工具。

許多表單只是帶線條的平面頁面——沒有人能在上面打字。本工具將真正的表單欄位放在這些線條之上，這樣您傳送表單的人就可以在手機或電腦上填寫，而不是列印出來。

點選選擇 PDF 檔案
或將它拖放到此處——平面表單、信件或文件

在頁面上拖動以繪製欄位的框，然後點選“新增欄位”。如果您在不繪製的情況下新增，一個標準框會放在頁面中間。欄位名稱必須唯一。

隱私設計： 您的檔案用 JavaScript 在您的瀏覽器中 100% 處理。它們永遠不會上傳到伺服器，永遠不會儲存，也永遠不會被我們看到——關閉標籤頁，一切都消失了。

如何使用此工具

  1. 選擇任何 PDF——例如帶空白線的平面表單。
  2. 在頁面上拖動，在答案應出現的位置繪製一個框。
  3. 命名該欄位（例如 student_name），選擇文字欄位或核取方塊，然後點選“新增欄位”。
  4. 對每個答案空間重複，然後下載您的可填寫 PDF 並在“填寫 PDF 表單”工具中測試它。

常見問題

這些欄位是真正的表單欄位，還是隻是繪圖？

真的。下載包含用 pdf-lib 建立的標準 AcroForm 定義：這些欄位在 Adobe Acrobat、瀏覽器和我們的“填寫 PDF 表單”工具中以您給它們命名的真正可填寫欄位出現。

我可以新增哪些欄位型別？

文字欄位（單行）和核取方塊。這些涵蓋了大多數日常表單。下拉選單、單選組和簽名欄位不在這裡提供——此限制誠實說明，而不是偽造。

為什麼欄位名稱必須唯一？

表單欄位的名稱就是它的身份——兩個同名欄位總是顯示相同的答案。本工具會阻止重複名稱，確保您的表單行為正確。

我可以在新增欄位後移動它嗎？

將其從頁面下方的列表中刪除，並在更正後的位置再次新增。欄位只有在您點選“下載”時才固化到下載檔案中，因此在這裡實驗是免費的。

工作原理

工具用 PDF.js 渲染您的 PDF，以便您可以在實時頁面預覽上繪製欄位框。您新增的每個欄位都儲存其頁碼、其在真實 PDF 點座標中的框、其型別和名稱。下載時，pdf-lib 開啟原始檔案，建立匹配的 AcroForm 欄位——每個條目一個文字欄位或核取方塊——並以淺色背景和邊框將其新增到其頁面的儲存位置，以便填寫者能看到在哪裡輸入。結果是一份標準的可填寫 PDF，完全在您的瀏覽器中建立。

實際示例

一所學校辦公室有一份平面 PDF 入學表，上面有印刷線條。職員線上條上拖動框並將其命名為 student_name, date_of_birth 和 guardian_phone,新增一個名為 documents_attached,然後下載表單。家長們現在可以用“填寫 PDF 表單”工具在手機上填寫並透過電子郵件發回——全程無需列印。

常見問題解答

位置如何轉換為 PDF？

您在渲染頁面上以螢幕畫素繪製；工具使用頁面的真實大小將它們轉換為 PDF 點，並翻轉垂直軸，因為 PDF 座標從左下角開始，而螢幕從左上角開始。

新增欄位會改變我文件的頁面嗎？

不。原始頁面由 pdf-lib 原樣複製，表單欄位分層放在頂部。文字、圖片和佈局保持原樣。

文字欄位框應該多大？

大約是表單上印刷的空白行或框的大小。非常短的框在某些閱讀器中會視覺上裁剪輸入的文字，因此請給手寫大小的空間多一點高度。

填寫的答案可以在之後壓平嗎？

是。填寫表單的任何人都可以使用我們的“填寫 PDF 表單”或“壓平 PDF”工具將答案固化到頁面中，生成最終、不可更改的提交副本。

表單在手機上有效嗎？

是——標準 AcroForm 欄位受現代手機和瀏覽器內建的 PDF 檢視器支援。非常舊或極簡的檢視器可能顯示沒有欄位的頁面。
