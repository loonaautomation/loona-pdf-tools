SVG 轉 PDF 轉換器

簡而言之： 本工具將 SVG 圖片轉換為乾淨的 PDF——每頁一張圖片，完全在您的瀏覽器中。

由 SVG 製作的標誌、圖表和插圖需要一個固定佈局的孿生版本，用於無法處理向量檔案的列印店、客戶和門戶。

點選選擇 SVG 圖片
或將檔案拖放到此處——多個檔案成為多個頁面，按順序
隱私設計： 您的檔案用 JavaScript 在您的瀏覽器中 100% 處理。它們永遠不會上傳到伺服器，永遠不會儲存，也永遠不會被我們看到——關閉標籤頁，一切都消失了。

工作原理，分步說明

  1. 選擇一個或多個 SVG 圖片。
  2. 選擇適合、A4 或 Letter 頁面。
  3. 按“轉換”並下載您的 PDF。

常見問題

如何將 SVG 轉換為 PDF？

在上面選擇一個或多個 SVG 檔案，選擇頁面大小，然後按“轉換”。每張圖片按您選擇的順序成為一份 PDF 的一頁。

質量會改變嗎？

SVG 在被放入 PDF 之前，在其長邊上以最高 2048 px 清晰地柵格化——在正常尺寸下列印清晰。如需無限縮放的向量輸出，您需要向量原生轉換器；本工具誠實地說明它生成的是高解析度柵格頁面。

我可以重新排列頁面嗎？

檔案按選擇順序新增。如需完全控制順序和佈局，請在這裡轉換，然後使用“整理 PDF”工具重新排列頁面。

有任何內容被上傳嗎？

不——解碼和 PDF 構建在您的瀏覽器中用 pdf-lib 進行。

幕後原理

瀏覽器原生解碼每個 SVG 圖片，將其繪製到 canvas 上，pdf-lib 將其嵌入為一頁——適合圖片的頁面使用圖片自身的比例（在 96 DPI 下），或圖片在 A4/Letter 上居中並保留邊距。

實際示例

三張聊天支援對話的 SVG 截圖，一起選擇，變成一份整潔的 3 頁 PDF，您可以將其附加到工單上——沒有門戶會拒絕它，這與原始格式不同。
