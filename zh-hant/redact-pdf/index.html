簡而言之： “遮蓋 PDF”工具永久刪除您覆蓋的內容：在任何頁面上的敏感區域繪製黑色矩形，工具將每個頁面重建為圖片，框被繪製在其中——下面的文字在檔案中根本不再存在，因此無法被複制、搜尋或揭露。

誠實的權衡： 因為頁面被重建為圖片以保證刪除，遮蓋 PDF 的文字是 不再可選擇或搜尋 在任何頁面上，檔案可能更大。這是無法撤銷的遮蓋的代價——它在這裡說明，而不是隱藏。

常見問題

被覆蓋的內容真的被刪除了，還是隻是隱藏了？

真的被刪除了。每個頁面被渲染為圖片，黑框被繪製到該圖片中，全新的 PDF 僅從這些圖片構建。原始文字層永遠不會進入新檔案，因此下面沒有任何內容可供複製、搜尋或揭示。

為什麼我遮蓋的 PDF 中的文字不再可選擇？

因為現在每個頁面都是圖片——這正是保證刪除的原因。如果您需要可選擇的文件，請僅對用於分享的副本進行遮蓋，並將原件私密儲存。

有人能用編輯器刪除黑框嗎？

不。這些框不是放置在文字之上的單獨物件；它們是頁面圖片本身的一部分，就像印在紙上的墨水。在編輯器中移動或刪除物件無法帶回從未儲存過的畫素。

檔案大小會改變嗎？

通常它會變大，因為圖片頁面比文字頁面重——尤其是長文件。頁面以清晰的 2x 解析度和良好質量的 JPEG 壓縮渲染，以平衡清晰度和大小。

工作原理

工具在您的瀏覽器中用 PDF.js 渲染每個 PDF 頁面。當您在頁面上拖動時，您的矩形以該頁面的真實 PDF 座標儲存。下載時，每個頁面以 2x 解析度再次渲染到螢幕外的 canvas 上，您的黑色矩形被繪製到 canvas 上，canvas 儲存為 JPEG。然後用 pdf-lib 組裝一份僅包含這些頁面圖片的新 PDF。原始檔案的文字、向量和隱藏層永遠不會被複制到輸出中——這就是為什麼被覆蓋的內容無法從中恢復。

實際示例

一所學校必須分享成績表，但要隱藏學生的身份證號碼。職員在所有 3 頁的身份證列上畫了一個框，然後下載 results-redacted.pdf。之後，她嘗試選擇並複製共享檔案中的數字——不可能，因為那一列現在只是黑色畫素。

常見問題解答

重建頁面的解析度是多少？

頁面以其正常大小的兩倍（2x，約 144 DPI）渲染，並以其原始頁面尺寸儲存為高質量 JPEG 圖片，因此列印輸出保持清晰，而檔案保持合理。

我應該以不同方式遮蓋掃描件嗎？

不。掃描頁面已經是圖片，同樣的固化方法適用：被覆蓋的畫素在重建的圖片中被黑色替換。

遮蓋也會刪除後設資料嗎？

重建的 PDF 是一個新檔案，不復制原件的文字或隱藏頁面內容。原件的基本文件資訊不會被保留；如果檔名稱或後設資料本身敏感，請重新命名下載檔案並用我們的“編輯 PDF 資訊”工具檢查它。

我可以只遮蓋一頁並將其餘頁面保留為文字嗎？

不能用本工具——所有頁面都重建為圖片，使過程統一，沒有任何內容會在未處理的頁面上漏過。這是一個 的安全選擇。

在分享遮蓋檔案之前，我應該檢查什麼？

開啟它並翻閱每個頁面：確認每個框都以小邊距完全覆蓋其目標，並嘗試選擇文字——您應該無法選擇任何內容，這證實了固化有效。
