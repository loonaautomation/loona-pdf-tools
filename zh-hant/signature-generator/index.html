常見問題

下載的簽名真的透明嗎？

是。PNG 帶有真正的 alpha 通道：除墨跡外的每個地方都完全或部分透明，因此它像紙上的真筆一樣覆蓋在表單線條和文字之上——沒有白色框。

哪種方法看起來最像我的真實簽名？

用觸控筆或手指繪製，或上傳您在白紙上的真實簽名的清晰照片。輸入的樣式整潔一致，但它們使用裝置字型而不是您自己的筆跡。

為什麼輸入的樣式在另一臺裝置上看起來不同？

輸入的樣式使用您正在使用的裝置上安裝的手寫字型——不下載字型檔案。每個系統的草書字型略有不同，預覽始終顯示將要下載的確切內容。

我的簽名會被上傳或儲存到任何地方嗎？

不。繪製、輸入、背景去除和 PNG 下載都在您的瀏覽器中進行。您的簽名永遠不會離開您的裝置。

工作原理

本工具完全在您的瀏覽器中在 HTML canvas 上構建您的簽名。在繪製模式下，您的筆畫儲存為單獨的路徑，因此“撤銷”可以刪除最後一筆，更改筆的顏色或寬度僅影響新筆畫。在輸入模式下，您的姓名以您裝置上安裝的手寫風格字型渲染——不載入外部或付費字型資產。在上傳模式下，照片逐畫素從白色背景轉換為透明度。下載前，工具可以掃描 alpha 通道，找到可見墨跡的邊界框，並裁剪掉空邊緣。結果是一張標準的透明 PNG，您可以在任何地方重複使用。

常見問題解答

白色背景去除如何工作？

對於每個畫素，工具測量其最暗通道與白色的距離。處於或接近白色的畫素變為透明，深色墨跡保持實心，灰色邊緣畫素變為部分透明，使筆畫保持平滑邊緣。強度滑塊控制去除淺灰色紙張底紋的力度。

如何從照片中獲得最乾淨的結果？

用深藍色或黑色墨水在純白紙上簽名，在明亮、均勻的光線下正面拍攝，無陰影，並裁剪到緊貼簽名。然後提高去除強度，直到紙張色調消失，又不會侵蝕墨跡。

下載的 PNG 有多大？

繪製和上傳的簽名保持其工作解析度（640 px 寬的簽名板，或您照片本身的大小）；輸入的簽名以大尺寸渲染然後修剪。勾選“修剪”後，空的透明邊緣會被裁剪掉，並留有小的安全邊距。

我可以直接從此頁面簽署 PDF 嗎？

此頁面製作簽名圖片。要將其放到 PDF 上，請開啟我們的“簽署 PDF”工具並將此 PNG 上傳為簽名圖片——它以實時預覽在任何頁面上定位和調整其大小。

簽名圖片具有法律約束力嗎？

貼上的簽名圖片是一種簡單的電子簽名。它被廣泛接受用於日常表單，但規則因國家和文件型別而異；高價值的法律合同可能需要經過認證的電子簽名服務。
