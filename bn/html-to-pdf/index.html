HTML থেকে PDF রূপান্তরকারী

সংক্ষেপে: এই টুল ব্রাউজারের নিজের ইঞ্জিন দিয়ে আপনার HTML রেন্ডার করে এবং একটি ছাপা দৃশ্য খোলে যেখানে আপনি এটি PDF হিসেবে সংরক্ষণ করেন — পিক্সেল-বিশ্বস্ত CSS, শূন্য আপলোড।

বেশিরভাগ 'HTML to PDF' সাইট আপনার মার্কআপ একটি সার্ভার সারিতে আপলোড করে। এটি আপনার ডিভাইসে ইতিমধ্যে থাকা ছাপা ইঞ্জিন ব্যবহার করে — দ্রুততর, ব্যক্তিগত, এবং আধুনিক CSS-তে আরও ভালো।

নকশা অনুযায়ী ব্যক্তিগত: আপনার ফাইলগুলো JavaScript দিয়ে 100% আপনার ব্রাউজারে প্রক্রিয়া করা হয়। সেগুলো কখনো সার্ভারে আপলোড হয় না, কখনো সংরক্ষিত হয় না এবং আমরা কখনো দেখি না - ট্যাব বন্ধ করুন এবং সবকিছু চলে যায়।

এটি কীভাবে কাজ করে, ধাপে ধাপে

  1. HTML পেস্ট করুন বা একটি .html ফাইল লোড করুন — প্রিভিউ লাইভ হালনাগাদ হয়।
  2. একটি নতুন ট্যাবে ছাপা দৃশ্য খুলতে বোতাম চাপুন।
  3. ছাপার ডায়ালগে 'Save as PDF' বেছে নিন এবং সংরক্ষণ করুন।

সাধারণ জিজ্ঞাসা

সার্ভার ছাড়া HTML কীভাবে PDF হয়ে যায়?

আপনার নিজের ব্রাউজারের print-to-PDF দিয়ে — Chrome ও Edge প্রতিটি 'Save as PDF'-এর জন্য যে একই ইঞ্জিন ব্যবহার করে। টুলটি আপনার HTML একটি পরিষ্কার ছাপা দৃশ্যে রেন্ডার করে এবং ছাপা ডায়ালগ খোলে; আপনি প্রিন্টার হিসেবে 'Save as PDF' বেছে নেন। পূর্ণ CSS (ছাপা স্টাইলশিট ও @page নিয়মসহ) মানা হয়, যা সার্ভার-মুক্ত রূপান্তরকারী সাধারণত ভুল করে।

আমার CSS কি কাজ করবে?

হ্যাঁ — কারণ রেন্ডারিং ইঞ্জিন নিজেই ব্রাউজার। মার্জিন ও পৃষ্ঠার আকার নিয়ন্ত্রণের জন্য আপনার HTML-এ @media print ও @page ব্যবহার করুন।

আমার HTML কি আপলোড হয়?

না। এটি একটি স্যান্ডবক্স প্রিভিউ ও একটি স্থানীয় ছাপা দৃশ্যে স্থানীয়ভাবে রেন্ডার হয়।

ভেতরে যেভাবে কাজ করে

প্রিভিউ একটি স্যান্ডবক্স iframe ব্যবহার করে (স্ক্রিপ্ট চলতে পারে না)। ছাপা দৃশ্য আপনার সঠিক HTML একটি নতুন ট্যাবে লেখে এবং ব্রাউজার ছাপা ডায়ালগ ডাকে। রূপান্তরকারী নিজেই ব্রাউজার বলে, flexbox, grid, ওয়েব ফন্ট ও ছাপা CSS সবই ঠিক আপনার নিজের মেশিনে যেমন আচরণ করে — কোনো সার্ভার রেন্ডারার তা প্রতিশ্রুতি দিতে পারে না।
