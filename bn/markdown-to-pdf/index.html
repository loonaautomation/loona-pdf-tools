Markdown থেকে PDF রূপান্তরকারী

সংক্ষেপে: এই টুল আপনার Markdown একটি স্টাইল করা পৃষ্ঠায় রেন্ডার করে এবং PDF হিসেবে সংরক্ষণের জন্য একটি ছাপা দৃশ্য খোলে — আপনার ব্রাউজারে।

Markdown-এ লেখা README, নোট ও খসড়া প্রায়ই এডিটর থেকে একটি ডকুমেন্ট হিসেবে যেতে হয়। এই রূপান্তরকারী সেগুলো পরিষ্কারভাবে সাজায় (serif মূল অংশ, পরিপাটি কোড ব্লক) এবং আপনাকে একটি PDF দেয়।

নকশা অনুযায়ী ব্যক্তিগত: আপনার ফাইলগুলো JavaScript দিয়ে 100% আপনার ব্রাউজারে প্রক্রিয়া করা হয়। সেগুলো কখনো সার্ভারে আপলোড হয় না, কখনো সংরক্ষিত হয় না এবং আমরা কখনো দেখি না - ট্যাব বন্ধ করুন এবং সবকিছু চলে যায়।

এটি কীভাবে কাজ করে, ধাপে ধাপে

  1. Markdown পেস্ট করুন বা একটি .md ফাইল লোড করুন — প্রিভিউ লাইভ হালনাগাদ হয়।
  2. ছাপা দৃশ্যের জন্য বোতাম চাপুন।
  3. ছাপার ডায়ালগে 'Save as PDF' বেছে নিন।

সাধারণ জিজ্ঞাসা

কোন Markdown সমর্থিত?

হেডিং (# থেকে ####), মোটা, তির্যক, ইনলাইন কোড, কোড ব্লক, বুলেট তালিকা, লিংক ও অনুভূমিক রেখা — দৈনন্দিন 95%। টেবিল ও বসানো ছবি এই হালকা রূপান্তরকারী দিয়ে রেন্ডার হয় না; সেই সীমা লুকানোর বদলে এখানে বলা হয়েছে।

PDF কীভাবে তৈরি হয়?

রেন্ডার করা HTML একটি ছাপা দৃশ্যে খোলে এবং আপনার ব্রাউজারের 'Save as PDF' ফাইলটি তৈরি করে — তাই ফন্ট ও পৃষ্ঠাযুক্তকরণ আপনার ব্রাউজারের সেরা মান।

আমার লেখা কি আপলোড হয়?

না — রেন্ডারিং স্থানীয়ভাবে হয়।

ভেতরে যেভাবে কাজ করে

একটি ছোট উদ্দেশ্য-নির্মিত রেন্ডারার মূল Markdown কাঠামো সামলায় এবং ছাপার জন্য আউটপুট সাজায় (720px প্রস্থ, serif মূল অংশ)। ছাপার দৃশ্যটি আপনার ব্রাউজারের PDF ইঞ্জিন ব্যবহার করে।

বাস্তব উদাহরণ

পেস্ট করা একটি প্রজেক্ট README পরিষ্কার 3 পৃষ্ঠার PDF সারসংক্ষেপে পরিণত হয় — হেডিং, বুলেট তালিকা ও কোডের নমুনা অক্ষত — একজন অ-প্রযুক্তিগত ক্লায়েন্টকে ইমেল করার জন্য প্রস্তুত।
