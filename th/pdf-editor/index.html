Loona PDF Editor

สรุป: Loona PDF Editor ช่วยให้คุณเพิ่มข้อความ รูปภาพ รูปร่าง และไฮไลต์บนหน้า PDF ใดก็ได้ ปิดทับความผิดพลาดด้วยไวท์เอาต์ วาดด้วยมืออย่างอิสระ และวางลายเซ็นที่วาดหรือพิมพ์ — จากนั้นดาวน์โหลดไฟล์ที่เสร็จสมบูรณ์ มันเพิ่มและปิดทับเนื้อหา มันไม่เขียนข้อความเดิมของ PDF ใหม่

ต้องการเพิ่มหมายเหตุลงในแบบฟอร์ม แก้ยอดรวมในใบแจ้งหนี้ วางโลโก้ของคุณ หรือเซ็นจดหมาย — โดยไม่ต้องพิมพ์และสแกน? เปิด PDF ที่นี่ เพิ่มสิ่งที่คุณต้องการลงบนหน้าโดยตรง แล้วดาวน์โหลดไฟล์ที่เสร็จสมบูรณ์ ทุกอย่างเกิดขึ้นบนอุปกรณ์ของคุณ: ไม่มีการอัปโหลด ไม่ต้องสมัครสมาชิก ไม่มีขีดจำกัดจำนวนหน้า ไม่มีลายน้ำ

องค์ประกอบที่คุณเพิ่ม

เพิ่มลายเซ็นของคุณ

วาดลายเซ็นของคุณบนแผ่น หรือพิมพ์ชื่อของคุณแล้วเราจะเปลี่ยนเป็นรูปลายเซ็น ลายเซ็นจะถูกวางบนหน้าปัจจุบันเป็นรูปภาพที่ย้ายได้

เป็นส่วนตัวโดยการออกแบบ: ไฟล์ของคุณถูกประมวลผล 100% ในเบราว์เซอร์ของคุณด้วย JavaScript พวกมันไม่เคยถูกอัปโหลดไปยังเซิร์ฟเวอร์ ไม่เคยถูกจัดเก็บ และไม่เคยถูกเราเห็น - ปิดแท็บแล้วทุกอย่างก็หายไป

วิธีแก้ไข PDF

  1. คลิกกล่องด้านบนและเลือก PDF ของคุณ ไฟล์จะเปิดที่นี่ในเบราว์เซอร์ของคุณ — ไม่มีการอัปโหลดอะไรเลย
  2. เลือกเครื่องมือ: ข้อความ สี่เหลี่ยมผืนผ้า ไฮไลต์ ไวท์เอาต์ หรือวาด — หรือเพิ่มรูปภาพหรือลายเซ็น
  3. คลิกหรือลากบนหน้าเพื่อวางองค์ประกอบ ใช้เครื่องมือเลือกเพื่อย้ายมัน ลากมุมสีทองเพื่อปรับขนาด หรือลบมันหากคุณเปลี่ยนใจ
  4. ย้ายไปมาระหว่างหน้าด้วยปุ่มก่อนหน้า / ถัดไป หรือเมนูแบบเลื่อนลงของหน้า ทุกหน้าเก็บองค์ประกอบของตัวเองไว้ ดังนั้นคุณจึงแก้ไขเอกสารยาวๆ ได้ทีละหน้า
  5. เมื่อทุกอย่างดูถูกต้อง คลิก "ส่งออก PDF ที่แก้ไขแล้ว" สิ่งที่คุณเพิ่มจะถูกแบนราบลงบนหน้าเดิม และไฟล์ที่เสร็จสมบูรณ์จะดาวน์โหลดเป็น ชื่อไฟล์ของคุณ-edited.pdf

โปรแกรมแก้ไขนี้ทำอะไรได้และทำอะไรไม่ได้

นี่คือโปรแกรมแก้ไขแบบวางซ้อน (overlay) และเราอยากบอกคุณตรงๆ ว่ามันหมายความว่าอย่างไร แทนที่จะให้คุณมารู้ทีหลัง

สิ่งที่ทำได้

  • เพิ่มข้อความใหม่ ที่ใดก็ได้บนหน้า ในแบบอักษรคลาสสิกห้าแบบ (Helvetica, Helvetica Bold, Times, Times Bold และ Courier) ทุกขนาดและทุกสี
  • เพิ่มรูปภาพ — โลโก้ ตราประทับ รูปถ่าย — และวางลายเซ็นที่คุณวาดด้วยเมาส์หรือนิ้ว หรือพิมพ์ชื่อของคุณ
  • วาดสี่เหลี่ยมและไฮไลต์เพื่อทำเครื่องหมายในเอกสาร และวาดด้วยมืออย่างอิสระด้วยเครื่องมือปากกา
  • ปิดทับความผิดพลาดด้วยไวท์เอาต์: วาดบล็อกทึบแสงทับคำหรือตัวเลขที่ผิด แล้วพิมพ์คำที่ถูกต้องทับลงไป
  • ย้าย ปรับขนาด และลบทุกสิ่งที่คุณเพิ่ม บนหน้าใดก็ได้ และส่งออก PDF ที่เสร็จสมบูรณ์และแบนราบแล้วหนึ่งไฟล์

สิ่งที่ทำไม่ได้

  • มันไม่เปลี่ยน ย้าย หรือจัดเรียงข้อความเดิมของ PDF ใหม่เหมือนโปรแกรมประมวลผลคำ คำที่มีอยู่แล้วในไฟล์จะอยู่ที่เดิมทุกประการ
  • หากต้องการแก้คำผิด ให้ปิดทับคำที่ผิดด้วยไวท์เอาต์แล้วพิมพ์คำที่ถูกต้องทับลงไป — นั่นคือวิธีแก้ที่ตรงไปตรงมา และใช้ได้ดีกับแบบฟอร์ม ใบแจ้งหนี้ และจดหมาย
  • ไวท์เอาต์ที่นี่เป็นเพียงการปิดทับทางสายตา: เนื้อหาที่ถูกปิดยังคงอยู่ภายในไฟล์ใต้บล็อกนั้น หากคุณต้องลบเนื้อหาที่ละเอียดอ่อนออกอย่างถาวรก่อนแชร์ โปรดใช้เครื่องมือ ปิดทับข้อมูลใน PDF ของเราแทน ซึ่งจะเผาบล็อกลงในรูปภาพหน้าที่สร้างใหม่
  • มันเปิด PDF ที่ป้องกันด้วยรหัสผ่านไม่ได้ และไม่ใช่เครื่องมือกรอกแบบฟอร์ม — สำหรับฟิลด์แบบฟอร์มที่มีอยู่ ให้ใช้ กรอกแบบฟอร์ม PDF

ความเป็นส่วนตัว — ไฟล์ของคุณไม่เคยออกจากอุปกรณ์

ทุกขั้นตอน — การเปิด การแสดงผล การแก้ไข และการส่งออก — ทำงาน 100% ในเบราว์เซอร์ของคุณด้วย JavaScript (PDF.js แสดงผลหน้า pdf-lib เขียนไฟล์ที่เสร็จสมบูรณ์) PDF ของคุณไม่เคยถูกอัปโหลดไปยังเซิร์ฟเวอร์ ไม่เคยถูกจัดเก็บ และไม่เคยถูกเราเห็น และตัวโปรแกรมแก้ไขเองก็ไม่ส่งคำขอเครือข่ายใดๆ ขณะที่คุณทำงาน ปิดแท็บแล้วทุกอย่างก็หายไป ไม่ต้องสมัครสมาชิก ไม่มีขีดจำกัดจำนวนหน้า และไม่มีลายน้ำ

คำถามที่พบบ่อย

มันเปลี่ยนคำเดิมใน PDF ของฉันได้ไหม?

ไม่ได้ Loona PDF Editor เพิ่มและปิดทับเนื้อหาบนหน้า มันไม่สามารถเขียนใหม่ ย้าย หรือจัดเรียงข้อความที่มีอยู่แล้วในไฟล์ได้ หากต้องการแก้คำที่ผิด ให้วาดบล็อกไวท์เอาต์ทับมันแล้วพิมพ์คำที่ถูกต้องทับลงไป — ในทางสายตา หน้าจะอ่านได้ตรงตามที่คุณต้องการ

ฉันจะแก้คำผิดใน PDF ด้วยโปรแกรมแก้ไขนี้ได้อย่างไร?

เลือกเครื่องมือไวท์เอาต์และลากบล็อกทับคำที่ผิด จากนั้นเลือกเครื่องมือข้อความ (หรือปุ่มเพิ่มข้อความ) พิมพ์คำที่ถูกต้องในแบบอักษรและขนาดที่เข้ากัน แล้วลากไปวางทับไวท์เอาต์ ส่งออก แล้วหน้าที่เสร็จสมบูรณ์จะแสดงเฉพาะคำที่ถูกต้อง

PDF ของฉันถูกอัปโหลดไปยังเซิร์ฟเวอร์หรือไม่?

ไม่ โปรแกรมแก้ไขทำงานทั้งหมดในเบราว์เซอร์ของคุณ: PDF.js วาดหน้าบนหน้าจอและ pdf-lib สร้างไฟล์ที่เสร็จสมบูรณ์บนอุปกรณ์ของคุณ ไม่มีอะไรถูกอัปโหลด จัดเก็บ หรือถูกเราเห็น และไม่ต้องสมัครสมาชิก

Loona PDF Editor ฟรีจริงหรือ?

ใช่ — ฟรี ไม่ต้องสมัครสมาชิก ไม่มีขีดจำกัดจำนวนหน้า และไม่มีลายน้ำบนไฟล์ที่ส่งออก คุณสามารถแก้ไข PDF ได้มากเท่าที่ต้องการ

ฉันเซ็น PDF ในโปรแกรมแก้ไขนี้ได้ไหม?

ได้ คลิก "เพิ่มลายเซ็น" วาดลายเซ็นของคุณบนแผ่นด้วยเมาส์หรือนิ้ว — หรือพิมพ์ชื่อของคุณเพื่อเปลี่ยนเป็นรูปลายเซ็น — แล้วมันจะถูกวางบนหน้าปัจจุบันเป็นรูปภาพที่ย้ายและปรับขนาดได้ นี่คือลายเซ็นแบบภาพ ไม่ใช่ลายเซ็นดิจิทัลที่ใช้ใบรับรอง สำหรับงานเซ็นอย่างเดียว คุณยังสามารถใช้เครื่องมือเซ็น PDF เฉพาะของเราได้

ไวท์เอาต์ลบสิ่งที่มันปิดทับออกอย่างถาวรหรือไม่?

ไม่ และเราจะไม่แกล้งทำเป็นว่ามันลบ ไวท์เอาต์วาดสิ่งปิดทับที่ทึบแสงเหนือเนื้อหา เพื่อไม่ให้มันแสดงหรือพิมพ์ออกมาอีก — แต่เนื้อหาเดิมยังคงอยู่ข้างใต้ภายในไฟล์ หากเนื้อหานั้นละเอียดอ่อนและต้องหายไปตลอดกาล ให้ใช้เครื่องมือปิดทับข้อมูลใน PDF ของเรา ซึ่งสร้างแต่ละหน้าใหม่เป็นรูปภาพโดยเผาบล็อกลงไป

ฉันใช้แบบอักษรใดได้บ้างสำหรับข้อความที่เพิ่ม?

แบบอักษร PDF มาตรฐานห้าแบบ: Helvetica, Helvetica Bold, Times, Times Bold และ Courier ในทุกขนาดและทุกสี เนื่องจากแบบอักษรเหล่านี้มีอยู่ในโปรแกรมอ่าน PDF ทุกตัว ข้อความที่คุณเพิ่มจึงแสดงผลอย่างถูกต้องทุกที่โดยไม่ทำให้ไฟล์ใหญ่ขึ้น

องค์ประกอบของฉันจะอยู่ในตำแหน่งที่ถูกต้องหรือไม่?

ใช่ องค์ประกอบถูกจัดเก็บแยกตามหน้าในพิกัด PDF จริง (หน่วยพอยต์) ไม่ใช่พิกเซลบนหน้าจอ ดังนั้นเมื่อส่งออกไฟล์ แต่ละองค์ประกอบจะถูกวาดลงบนหน้าของมันในตำแหน่ง ขนาด และลำดับที่คุณจัดไว้ทุกประการ — ไม่ว่าหน้าจะมีขนาดเท่าใด

วิธีการทำงาน

เมื่อคุณเปิดไฟล์ PDF.js จะแสดงผลหน้าปัจจุบันลงบนผืนผ้าใบในเบราว์เซอร์ของคุณ ทุกสิ่งที่คุณเพิ่ม — กล่องข้อความ รูปภาพ สี่เหลี่ยมผืนผ้า ไฮไลต์ บล็อกไวท์เอาต์ เส้นวาดมืออิสระ หรือลายเซ็น — จะถูกวาดบนชั้นโปร่งใสเหนือผืนผ้าใบนั้น และจัดเก็บไว้สำหรับหน้านั้นในพิกัด PDF จริง วัดเป็นหน่วยพอยต์ การสลับหน้าไม่เคยทำให้องค์ประกอบปะปนกัน: แต่ละหน้าเก็บรายการของตัวเองไว้ ตามลำดับที่คุณเพิ่ม เมื่อส่งออก pdf-lib จะเปิดไฟล์ต้นฉบับของคุณและวาดทุกองค์ประกอบลงบนหน้าของมันที่พิกัดเดียวกันนั้น โดยแปลงตำแหน่งจากบนลงล่างบนหน้าจอเป็นระบบพิกัดของ PDF เอง แล้วบันทึกผลลัพธ์โดยมี -edited ในชื่อ เนื่องจากหน้าเดิมถูกเก็บไว้และมีเพียงสิ่งที่คุณเพิ่มเท่านั้นที่ถูกวาดทับ ผลลัพธ์จึงยังคงเป็น PDF จริงที่เลือกข้อความได้ — ต่างจากเครื่องมือที่สร้างหน้าใหม่เป็นรูปภาพ

PDF ใบแจ้งหนี้แสดงยอดรวมที่ผิด "Rs 4,500" และไม่มีโลโก้ธุรกิจของคุณ คุณลากบล็อกไวท์เอาต์ทับยอดรวมเดิม เพิ่มข้อความ "Rs 5,400" ใน Helvetica Bold ทับลงไป วางรูปโลโก้ของคุณที่ด้านบนของหน้า และเซ็นชื่อที่ด้านล่างโดยพิมพ์ชื่อของคุณในกล่องลายเซ็น คลิกเพียงครั้งเดียวที่ส่งออก PDF ที่แก้ไขแล้ว ก็จะดาวน์โหลด invoice-edited.pdf — แก้ไขแล้ว มีแบรนด์แล้ว และเซ็นแล้ว โดยส่วนที่เหลือของใบแจ้งหนี้ไม่ถูกแตะต้อง
