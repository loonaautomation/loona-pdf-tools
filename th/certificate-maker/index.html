เครื่องมือสร้างใบรับรองฟรีออนไลน์ - ใบรับรองที่พิมพ์ได้

สรุป: พิมพ์ชื่อผู้รับและรายละเอียดไม่กี่อย่าง ดูการออกแบบใบรับรองเองบนตัวอย่าง A4 สด จากนั้นดาวน์โหลด PDF ที่พร้อมพิมพ์ (หรือ PNG) - ฟรี ไม่ต้องสมัครและไม่มีลายน้ำ ทั้งชั้นเรียนหรือหลักสูตรที่จะรับรอง? เปลี่ยนเป็นโหมดจำนวนมาก วางหนึ่งชื่อต่อบรรทัด และรับ PDF หนึ่งไฟล์ที่มีใบรับรองสำหรับทุกชื่อ

ใบรับรองมักหมายถึงเครื่องมือออกแบบที่คุณใช้ไม่ค่อยเป็น เทมเพลตที่ถูกล็อกไว้หลังกำแพงจ่ายเงิน หรือค่าธรรมเนียมดาวน์โหลดที่น่าอึดอัดในขั้นตอนสุดท้าย ที่นี่ทุกอย่างเกิดขึ้นบนหน้านี้ ดีไซน์สำเร็จรูปสามแบบ ทุกคำแก้ไขได้ ตราทองถูกวาดให้โดยอัตโนมัติ และ PDF ที่เสร็จแล้วสร้างในเบราว์เซอร์ของคุณ ชื่อและรายละเอียดจึงไม่เคยออกจากอุปกรณ์ของคุณ

ฟิลด์อื่นทุกฟิลด์ด้านบน หลักสูตร วันที่ ผู้ออก ลายเซ็น และดีไซน์ ยังคงเหมือนเดิมในใบรับรองทุกใบ มีเพียงชื่อเท่านั้นที่เปลี่ยน บรรทัดว่างจะถูกละเว้นและชื่อซ้ำจะถูกเก็บไว้

เป็นส่วนตัวโดยการออกแบบ: ใบรับรองของคุณถูกออกแบบและ PDF ของคุณถูกสร้าง 100% ในเบราว์เซอร์ของคุณด้วย JavaScript ชื่อและรายละเอียดไม่เคยถูกอัปโหลดไปยังเซิร์ฟเวอร์ ไม่เคยถูกจัดเก็บ และเราไม่เคยเห็น - ปิดแท็บและทุกอย่างก็หายไป นั่นสำคัญกับใบรับรอง: รายชื่อของชั้นเรียนอยู่บนอุปกรณ์ของคุณเอง

วิธีสร้างใบรับรอง

  1. เลือกหนึ่งในสามดีไซน์และพิมพ์รายละเอียดของคุณ ชื่อเรื่อง ชื่อผู้รับ บรรทัดหลักสูตร คำอธิบาย วันที่ ผู้ออก และชื่อลายเซ็น ตัวอย่าง A4 แนวนอนวาดตัวเองใหม่ขณะที่คุณพิมพ์
  2. สำหรับใบรับรองใบเดียว คลิก "ดาวน์โหลด PDF" สำหรับไฟล์ที่พร้อมพิมพ์ หรือ "ดาวน์โหลด PNG" หากคุณต้องการรูปภาพเพื่อแชร์
  3. สำหรับใบรับรองจำนวนมากพร้อมกัน ให้เปลี่ยนเป็นโหมดจำนวนมาก วางหนึ่งชื่อต่อบรรทัด (สูงสุด 200) แล้วคลิก "สร้าง PDF จำนวนมาก" คุณจะได้ PDF หนึ่งไฟล์ที่มีหนึ่งหน้าต่อชื่อ พร้อมพิมพ์

คำถามที่พบบ่อย

เครื่องมือสร้างใบรับรองนี้ฟรีจริงไหม?

ใช่ มันฟรีทั้งหมด ไม่ต้องสมัครและไม่มีลายน้ำ รวมถึงโหมดจำนวนมาก เว็บไซต์ใบรับรองจำนวนมากให้คุณออกแบบฟรีแล้วคิดค่าดาวน์โหลด ที่นี่ดาวน์โหลดก็ฟรีด้วย

ชื่อที่ฉันพิมพ์ถูกอัปโหลดไปที่ใดหรือไม่?

ไม่ ใบรับรองถูกวาดและ PDF ถูกสร้าง 100% ภายในเบราว์เซอร์ของคุณ ชื่อ วันที่ และรายละเอียดอื่นทุกอย่างไม่เคยออกจากอุปกรณ์ของคุณ

โหมดจำนวนมากสร้างใบรับรองได้กี่ใบ?

สูงสุด 200 ใบรับรองใน PDF เดียวต่อการรัน วางหนึ่งชื่อต่อบรรทัด บรรทัดว่างจะถูกละเว้นและชื่อซ้ำจะถูกเก็บไว้ นักเรียนสองคนที่มีชื่อเดียวกันจึงได้รับใบรับรองคนละใบ

ใบรับรองมีขนาดเท่าใด?

ใบรับรองทุกใบเป็นหน้า A4 มาตรฐานในแนวนอน วาดที่ 150 dpi จึงพิมพ์คมชัดบนเครื่องพิมพ์ที่บ้านหรือสำนักงานทุกเครื่อง เลือก 'ขนาดจริง' หรือ 100% ในกล่องโต้ตอบเครื่องพิมพ์ของคุณเพื่อให้พอดีเป๊ะ

ฉันเปลี่ยนดีไซน์ได้ไหม?

ใช่ มีดีไซน์ในตัวสามแบบ - ทองหรูหรา น้ำเงินสมัยใหม่ และคลาสสิก - และทุกคำบนใบรับรองแก้ไขได้: ชื่อเรื่อง ชื่อผู้รับ บรรทัดหลักสูตร คำอธิบาย วันที่ ผู้ออก และชื่อลายเซ็น

วิธีการทำงาน

ใบรับรองถูกวาดบนแคนวาส HTML ที่ขนาด A4 แนวนอนเต็ม (297 x 210 mm ที่ 150 dpi - 1754 x 1240 พิกเซล) ทุกองค์ประกอบถูกวาดใหม่จากข้อความของคุณทุกครั้งที่คุณพิมพ์: เส้นขอบสองเส้นและลวดลายมุม ชื่อเรื่อง ตราทองพร้อมหางริบบิ้น และเส้นลายเซ็นในสไตล์สคริปต์ เมื่อคุณดาวน์โหลด PDF ภาพวาดที่เสร็จแล้วจะถูกวางบนหน้า A4 แนวนอนโดยไลบรารี pdf-lib ซึ่งเป็นไลบรารีเดียวกับที่เครื่องมือ PDF อื่นของเราใช้ ไฟล์จึงพิมพ์ตรงตามที่ตัวอย่างดู ในโหมดจำนวนมาก ภาพวาดเดียวกันถูกทำซ้ำหนึ่งครั้งต่อชื่อลงใน PDF หลายหน้าเดียว โดยมีแถบความคืบหน้าเพื่อให้คุณดูรายการยาวเสร็จ

ตัวอย่างที่ลงมือทำ

ครูจบเวิร์กช็อปฝึกอบรมสองวันกับผู้เข้าร่วม 28 คน เธอเปิดโหมด Bulk คงชื่อเรื่อง "Certificate of Participation" ตั้งบรรทัดหลักสูตรเป็นชื่อเวิร์กช็อปของเธอ วางชื่อ 28 ชื่อจากทะเบียนของเธอ หนึ่งชื่อต่อบรรทัด แล้วคลิก Generate หนึ่งนาทีต่อมาเธอมี PDF 28 หน้าหนึ่งไฟล์ เธอพิมพ์โดยตรวจทานกับทะเบียนอีกครั้ง เซ็นทุกหน้าเหนือเส้นลายเซ็นที่พิมพ์ และแจกใบรับรองในวันเดียวกัน ไม่ต้องใช้ซอฟต์แวร์ออกแบบ ไม่มีการอัปโหลดชื่อนักเรียนของเธอ และไม่มีค่าธรรมเนียม

การใช้งานทั่วไป

  • ใบรับรองการจบหลักสูตรและการฝึกอบรมสำหรับทั้งชั้นเรียนใน PDF เดียว
  • ใบรับรองความชื่นชมสำหรับนักเรียน เจ้าหน้าที่ หรืออาสาสมัคร
  • ใบรับรองการเข้าร่วมเวิร์กช็อป สัมมนา และเว็บสัมมนา
  • ใบรับรองความสำเร็จครั้งเดียวเพื่อพิมพ์ที่บ้านหรือแชร์เป็น PNG

คำถามที่พบบ่อย

ฉันเพิ่มโลโก้ของตัวเองหรือรูปภาพลายเซ็นที่เขียนด้วยมือได้ไหม?

ไม่ได้ในเวอร์ชันนี้ ดีไซน์ใช้ตราในตัวและชื่อลายเซ็นที่พิมพ์ หลายคนพิมพ์ใบรับรองและเซ็นด้วยมือเหนือเส้นลายเซ็น ซึ่งดูเป็นส่วนตัวกว่าอยู่แล้ว

ทำไมชื่อจึงหดลงบนใบรับรองบางใบ?

ชื่อที่ยาวมากจะถูกลดขนาดโดยอัตโนมัติเพื่อให้พอดีหนึ่งบรรทัดภายในเส้นขอบเสมอ การย่อชื่อกลางมักคงขนาดที่ใหญ่และสง่างามกว่าไว้

โหมดจำนวนมากเปลี่ยนอะไรนอกจากชื่อไหม?

ไม่ ชื่อเรื่อง หลักสูตร คำอธิบาย วันที่ ผู้ออก ลายเซ็น และดีไซน์เหมือนกันในทุกหน้า มีเพียงชื่อผู้รับเท่านั้นที่เปลี่ยน เหมือนกองที่พิมพ์และกรอกทีละชื่อเป๊ะ ๆ
