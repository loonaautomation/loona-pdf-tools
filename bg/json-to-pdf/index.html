Конвертор от JSON към PDF

Накратко: този инструмент проверява и красиво отпечатва вашия JSON, след което го подрежда като чист моноширинен PDF — във вашия браузър.

Отговорите от API, конфигурационните файлове и изнесените данни често трябва да се споделят с хора, които не четат сурови JSON файлове. PDF файлът със страници е универсалното средство за предаване.

Поверително по проект: вашите файлове се обработват 100% във вашия браузър с JavaScript. Те никога не се качват на сървър, никога не се съхраняват и никога не се виждат от нас - затворете раздела и всичко изчезва.

Как работи, стъпка по стъпка

  1. Поставете JSON или заредете .json файл.
  2. Натиснете „Конвертирай“ — невалидният JSON се съобщава с точната грешка при разбора.
  3. Изтеглете форматирания PDF.

Често задавани въпроси

Проверява ли се JSON?

Да — първо се разглежда; невалиден JSON дава точната грешка на програмата за разбор вместо счупен PDF. Валидният JSON се отпечатва красиво с отстъп от 2 интервала.

Защо моноширинен?

JSON е код: оформлението с Courier запазва отстъпите и влагането четливи, точно като в редактор.

Качват ли се моите данни?

Не — разборът и изграждането на PDF стават във вашия браузър.

Под капака

JSON се разглежда (което го проверява), презаписва се с еднакъв отстъп, след което се рисува ред по ред с pdf-lib в Courier, като дългите редове се пренасят и страниците се оформят автоматично.

Пример с решение

Отговор от API с 900 реда се превръща в PDF от 12 страници, който можете да прикачите към доклад за грешка — четлив за всеки, без нужда от програма за преглед на JSON.
