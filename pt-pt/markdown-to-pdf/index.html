Conversor de Markdown para PDF

Em resumo: esta ferramenta reproduz o seu Markdown numa página com estilo e abre uma vista de impressão para guardar como PDF — no seu navegador.

README, notas e rascunhos escritos em Markdown precisam muitas vezes de sair do editor como um documento. Este conversor dá-lhes um estilo limpo (corpo com serifa, blocos de código arrumados) e entrega-lhe um PDF.

Privado desde a conceção: os seus ficheiros são processados 100% no seu navegador com JavaScript. Nunca são carregados para um servidor, nunca guardados e nunca vistos por nós - feche o separador e tudo desaparece.

Como funciona, passo a passo

  1. Cole Markdown ou carregue um ficheiro .md — a pré-visualização atualiza em direto.
  2. Prima o botão para a vista de impressão.
  3. Escolha 'Guardar como PDF' na caixa de diálogo de impressão.

Perguntas Frequentes

Que Markdown é suportado?

Títulos (# a ####), negrito, itálico, código em linha, blocos de código, listas com marcadores, ligações e réguas horizontais — os 95% do dia a dia. As tabelas e as imagens incorporadas NÃO são reproduzidas por este conversor leve; esse limite é indicado aqui em vez de escondido.

Como é produzido o PDF?

O HTML reproduzido abre numa vista de impressão e o 'Guardar como PDF' do seu navegador cria o ficheiro — pelo que os tipos de letra e a paginação têm a melhor qualidade do seu navegador.

O meu texto é carregado?

Não — a renderização acontece localmente.

Por dentro

Um pequeno renderizador feito à medida trata os principais elementos do Markdown e dá estilo ao resultado para impressão (medida de 720px, corpo com serifa). A vista de impressão utiliza o motor de PDF do seu navegador.

Exemplo resolvido

Um README de projeto colado torna-se um resumo PDF limpo de 3 páginas — títulos, listas com marcadores e exemplos de código intactos — pronto para enviar por e-mail a um cliente sem conhecimentos técnicos.
