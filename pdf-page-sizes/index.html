Frequently Asked Questions

What do points mean?

The point is PDF's native unit: 72 points = 1 inch = 25.4 mm. A4 is 595 x 842 points; US Letter is 612 x 792 points.

Why do pages in one file have different sizes?

Merges, scans and exports often mix sizes - for example A4 text pages with a Letter-size form. The table names each page's nearest standard size so the odd ones stand out.

Does this tool change my PDF?

Never. It only reads the file in your browser and displays what it finds. No download is produced.

What does rotation mean in the table?

Some pages are stored sideways with a rotation flag (90, 180 or 270 degrees). Viewers honour the flag; the dimensions shown are the stored page box, and rotation is listed separately so you can spot pages our Rotate PDF tool can fix permanently.

How it works

The inspector opens your file twice over in your browser: pdf-lib reads the document information (title, author, creator, producer, page count) and each page's size and rotation, while the raw file header gives the PDF version. Every page's width and height in points are converted to millimetres (x 25.4 / 72) and inches ( / 72), then matched against a table of standard paper sizes within a few points of tolerance. Everything is read-only.

Worked example

A merged 10-page report prints badly. The checker shows pages 1-9 are A4 but page 10 - an attached form - is US Letter and rotated 90 degrees. Two minutes in Resize PDF Pages and Rotate PDF, and the reprint is perfect.

Frequently asked questions

Which standard sizes are recognised?

A3, A4, A5, A6, US Letter, US Legal and Tabloid, matched within a small tolerance in either orientation; anything else is shown as Custom with its exact dimensions.

Where does the PDF version come from?

From the file header and, when present, the document catalog - the version the file claims to conform to, such as PDF 1.7.

Can I see sizes in centimetres instead?

Millimetres are shown for every page; divide by 10 for centimetres. Inches are shown to two decimals for Letter-style workflows.
