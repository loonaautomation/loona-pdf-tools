Remove PDF Annotations Online - Free

In short: the Remove PDF Annotations tool strips the markup layer from a PDF - comments, highlights, underlines, sticky notes, stamps and drawn annotations - while leaving the actual page content, text and images exactly as they were.

Review markup is useful while a document is being edited, and embarrassing when the final copy goes out with comments still attached. Strip every annotation here before you share the clean version.

Note: form fields are not annotations and are not removed by this tool - use Flatten PDF for those. Also, an annotation that was already flattened into the page content by another program is part of the page and cannot be separated.

Frequently Asked Questions

Which annotations are removed?

All standard annotation objects attached to pages: text comments, highlights, underlines, strike-throughs, sticky notes, stamps, freehand ink, shapes and link annotations are removed as annotation objects.

Wait - links too?

Yes, clickable links are annotations in PDF, so they are stripped along with the markup. If a document's links matter, keep an original copy - the visible text of a link remains, only its clickability goes.

Does removing annotations change the document text?

No. Annotations live in a separate list on each page; deleting that list cannot touch the page's own content stream.

My highlights are still visible after using this - why?

Those highlights were flattened into the page by whatever program created the file, so they are page content now, not annotations. No annotation remover can separate them.

How it works

Every PDF page can carry an Annots array - the list of comment and markup objects shown on top of the page. The tool opens the file with pdf-lib, counts the entries in each page's Annots array, deletes those arrays, and saves a clean copy. Page content streams are never opened or altered, which is why the document itself cannot be harmed by the process.

Worked example

A teacher receives a worksheet covered in a colleague's review highlights and sticky-note comments. After one pass here, the shared copy shows only the worksheet - 14 annotations removed, content untouched.

Frequently asked questions

How does the tool count annotations?

Each page of a PDF carries an Annots list. The tool reads those lists with pdf-lib before and after removal, and reports the honest counts.

Will the file get smaller?

Slightly, when annotations carried attachments or long comment threads. Usually the change is small.

Are digital signatures removed?

Signature fields are form fields, not page annotations, and are not removed by this tool.
