HTML을 PDF로 변환하는 도구

요약하면: 이 도구는 브라우저 자체 엔진으로 HTML을 렌더링하고 PDF로 저장하는 인쇄 보기를 열어요 — 픽셀 단위로 충실한 CSS, 업로드 제로예요.

대부분의 'HTML을 PDF로' 사이트는 마크업을 서버 대기열에 업로드해요. 이 도구는 기기에 이미 있는 인쇄 엔진을 사용해요. 더 빠르고, 비공개이며, 최신 CSS를 더 잘 처리해요.

설계부터 비공개: 파일은 JavaScript로 브라우저에서 100% 처리돼요. 서버에 절대 업로드되지 않고, 저장되지 않고, 우리가 볼 수 없어요. 탭을 닫으면 모든 것이 사라져요.

단계별 작동 방식

  1. HTML을 붙여 넣거나 .html 파일을 불러오세요 — 미리보기가 실시간으로 업데이트돼요.
  2. 새 탭에서 인쇄 보기를 열려면 버튼을 누르세요.
  3. 인쇄 대화 상자에서 'PDF로 저장'을 선택하고 저장하세요.

자주 묻는 질문

서버 없이 HTML이 어떻게 PDF가 되나요?

자신의 브라우저의 인쇄하여 PDF로 만들기를 통해 해요. Chrome과 Edge가 모든 'PDF로 저장'에 사용하는 같은 엔진이에요. 도구는 깔끔한 인쇄 보기에서 HTML을 렌더링하고 인쇄 대화 상자를 열어요. 프린터로 'PDF로 저장'을 선택하세요. 전체 CSS(인쇄 스타일시트와 @page 규칙 포함)가 지켜져 서버 없는 변환기가 보통 틀리는 부분을 정확히 해요.

내 CSS가 작동할까요?

네 — 렌더링 엔진이 브라우저 자체이기 때문이에요. HTML에서 여백과 페이지 크기 제어를 위해 @media print와 @page를 사용하세요.

내 HTML이 업로드되나요?

아니에요. 샌드박스 처리된 미리보기와 로컬 인쇄 보기에서 로컬로 렌더링돼요.

내부 구조

미리보기는 샌드박스 처리된 iframe을 사용해요(스크립트가 실행될 수 없어요). 인쇄 보기는 정확한 HTML을 새 탭에 쓰고 브라우저 인쇄 대화 상자를 호출해요. 변환기가 곧 브라우저이기 때문에, flexbox, grid, 웹 글꼴, 인쇄 CSS는 모두 본인 컴퓨터에서와 정확히 같게 동작해요 — 어떤 서버 렌더러도 그것을 약속할 수 없어요.

실제 예시

A4 여백에 대한 @page 규칙이 있는 HTML 송장 템플릿은 픽셀 단위로 완벽한 PDF 송장을 만들어요. 템플릿이 설계된 그대로의 출력이에요.
