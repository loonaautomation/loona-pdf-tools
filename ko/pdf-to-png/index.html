온라인으로 PDF를 PNG로 변환 - 무료

요약하면: PDF를 PNG로 변환 도구는 모든 PDF 페이지를 고품질 PNG 이미지로 렌더링해요. JPG와 달리, 내용이 없는 페이지 영역은 투명한 상태로 유지돼요.

디자이너, 교사, 개발자는 슬라이드, 오버레이, 문서화를 위해 PDF 작품을 PNG로 필요로 하는 경우가 많아요. 여기서 각 페이지를 인쇄 해상도까지 변환하세요. 투명도가 유지되고 모든 페이지가 자체 다운로드로 제공돼요.

또는 여기에 끌어다 놓으세요
설계부터 비공개: 파일은 JavaScript로 브라우저에서 100% 처리돼요. 서버에 절대 업로드되지 않고, 저장되지 않고, 우리가 볼 수 없어요. 탭을 닫으면 모든 것이 사라져요.

PDF를 PNG로 변환하는 방법

  1. PDF 파일을 선택하세요. 페이지 수가 자동으로 나타나요.
  2. 해상도를 선택하세요: 표준, 높음 또는 인쇄(3x)를 선택하세요.
  3. "PNG로 변환"을 클릭하고 필요한 페이지 이미지를 다운로드하세요.

자주 묻는 질문

PNG인가 JPG인가 - 무엇을 선택해야 하나요?

선명한 텍스트, 선 그림, 투명 배경에는 PNG를 선택하세요. 사진과 더 작은 파일 크기에는 JPG를 선택하세요.

투명도가 정말로 유지되나요?

네. 페이지는 배경 채우기 없이 렌더링되어, 빈 영역은 PNG에서 투명한 상태로 유지돼요.

PNG 파일은 왜 JPG보다 큰가요?

PNG는 무손실이라 모든 픽셀을 정확히 유지해요. 그 정밀함은 파일 크기를 대가로 해요.

내 파일이 업로드되나요?

아니에요. 모든 렌더링은 브라우저 안에서 로컬로 이뤄져요.

작동 방식

JPG 자매 도구처럼, 이 도구는 PDF.js로 PDF를 로컬에서 불러와 각 페이지를 페이지 자연 크기의 1.5, 2, 3배로 캔버스에 그려요. 차이는 그다음에 일어나요: 캔버스는 투명한 상태로 유지돼요. 배경이 칠해지지 않고, 모든 픽셀을 렌더링된 그대로 유지하는 무손실 형식인 PNG로 내보내져요. 완성된 각 페이지는 파일 이름을 딴 자체 다운로드 링크로 제공돼요. 예를 들어 diagram-page1.png. 모든 작업은 브라우저에서 실행되고 파일은 기기를 떠나지 않아요.

실제 예시

가게 주인은 로고와 가격 배지가 있는 2페이지 PDF를 가지고 있는데 작품 주변에 빈 공간이 있어요. 다음 설정으로 변환해요 높음 (2x) 그리고 PNG 두 개를 모두 다운로드해요. 빈 영역이 투명한 상태로 유지됐기 때문에, 배지를 흰 상자 없이 사진과 포스터에 편집 앱에서 바로 올려놓을 수 있고, PNG는 아무것도 잃지 않아 가장자리가 완벽히 선명해요.

자주 묻는 질문

PNG는 어떤 해상도로 나오나요?

선택한 배율은 페이지의 자연 크기에 곱해져요. 높음(2x)의 A4 페이지는 약 1190 x 1684 픽셀이 되고, 인쇄(3x)에서는 약 1785 x 2526 픽셀이 되어 슬라이드, 인쇄, 세부 다이어그램에 충분해요.

이미지는 PDF에 삽입된 원본 사진인가요?

아니에요. 도구는 각 완성 페이지를 하나의 이미지로 렌더링해요. 텍스트, 사진, 그림이 페이지가 보이는 그대로 함께 있어요. PDF 안에 저장된 별도 이미지 파일을 꺼내지 않아요.

모든 페이지를 ZIP으로 함께 다운로드할 수 있나요?

아니에요, ZIP 옵션은 없어요. 모든 페이지가 자체 다운로드 링크를 받아서 필요한 페이지만 저장하고 나머지는 무시할 수 있어요.

색상과 가는 선은 정확하게 유지될까요?

네. PNG는 무손실이라 내보낸 픽셀은 렌더링된 페이지와 정확히 일치해요. 텍스트나 가는 선 주위에 압축 artifact가 없어요. 절충은 JPG보다 파일이 크다는 것이에요.

비밀번호로 보호된 PDF를 변환할 수 있나요?

아니에요. 보호된 파일은 렌더링을 위해 열 수 없어요. 먼저 평소 쓰는 리더에서 PDF 잠금을 푼 뒤, 잠금이 풀린 사본을 변환하세요.

PNG 속 텍스트를 검색할 수 있나요?

아니에요. PNG는 페이지의 그림이라 단어를 선택하거나 검색할 수 없어요. 실제 텍스트가 필요하면 PDF를 텍스트로 변환 도구를 사용하세요.
