온라인으로 PDF에 워터마크 추가 - 무료

요약하면: 워터마크 추가 도구는 CONFIDENTIAL, DRAFT 또는 학교나 회사 이름 같은 텍스트를 PDF의 모든 페이지에 찍어요. 크기, 불투명도, 각도, 색상을 선택할 수 있어요.

워터마크는 소유권과 상태를 한눈에 표시해요. 초안은 초안으로 남고, 기관 이름이 문서와 함께 이동해요. 텍스트를 입력하고 얼마나 진하거나 옅게 보일지 조정해 다운로드하세요.

설계부터 비공개: 파일은 JavaScript로 브라우저에서 100% 처리돼요. 서버에 절대 업로드되지 않고, 저장되지 않고, 우리가 볼 수 없어요. 탭을 닫으면 모든 것이 사라져요.

PDF에 워터마크를 추가하는 방법

  1. 도장을 찍을 PDF를 선택하세요.
  2. 워터마크 텍스트를 입력하고 크기, 불투명도, 각도, 색상, 레이아웃(가운데 도장 하나 또는 타일)을 설정하세요.
  3. "워터마크 추가"를 클릭하고 도장이 찍힌 PDF를 다운로드하세요.

자주 묻는 질문

워터마크를 나중에 제거할 수 있나요?

워터마크 텍스트는 일반 내용처럼 각 페이지에 그려져요. 보안 잠금은 아니에요. 진짜 보호를 위해서는 비밀번호로 보호된 PDF가 맞는 도구예요.

어떤 불투명도를 사용해야 하나요?

0.15-0.25 정도가 페이지 내용을 가리지 않으면서 도장이 선명하게 보이는 값이에요. 더 낮으면 은은해지고, 더 높으면 강하게 드러나요.

타일 레이아웃은 무엇을 하나요?

가운데에 도장 하나 대신, 텍스트가 페이지 전체에 격자로 반복돼요. 잘라 내기가 더 어려워요.

내 파일이 업로드되나요?

아니에요. 워터마크는 브라우저에서만 적용돼요.

작동 방식

PDF는 pdf-lib로 브라우저에서 로컬로 열려요. 절대 업로드되지 않아요. 그리고 도구는 Helvetica Bold 글꼴을 삽입하고 기존 내용 위에 그려서 모든 페이지에 텍스트를 찍어요. 크기(24부터 60 pt까지), 기울기(평평함, 30, 45, 60도), 색상(회색, 빨간색, 파란색, 검은색), 그리고 희미한 0.05부터 확실한 0.6까지 불투명도 슬라이더의 강도를 제어해요. 가운데 레이아웃에서는 도장 하나가 페이지 가운데에 있고, 타일 레이아웃에서는 도장이 페이지 전체에 격자로 반복돼요. 결과는 이름에 -watermarked가 붙은 새 파일로 다운로드돼요.

실제 예시

프리랜서가 새 클라이언트에게 12페이지 디자인 제안서를 보내려는데 결제 전에 보호하고 싶어 해요. DRAFT라고 입력하고, 48 pt 타일 레이아웃, 45도 각도, 회색, 불투명도 0.20을 선택해요. 다운로드한 proposal-watermarked.pdf의 모든 페이지에는 대각선 DRAFT 패턴이 반복되어 선명하게 읽히면서도 아래 디자인을 가리지 않아요.

자주 묻는 질문

워터마크는 페이지 내용 위에 찍히나요, 아래에 찍히나요?

위쪽이에요. 텍스트는 페이지 자체 내용 뒤에 그려져서 텍스트, 이미지, 스캔 위에 모두 보이도록 유지돼요. 워터마크의 목적이 정확히 그것이에요.

선택한 몇 페이지만 워터마크를 넣을 수 있나요?

아니에요. 도장은 문서의 모든 페이지에 적용돼요. DRAFT나 CONFIDENTIAL 같은 상태 표시에는 보통 원하는 바예요. 한 섹션만 보호하려면 먼저 그 페이지를 추출하고 추출된 파일에 워터마크를 넣으세요.

로고나 사진을 워터마크로 사용할 수 있나요?

이 도구에서는 아니에요. Helvetica Bold로 텍스트를 찍어요. 로고가 한 페이지 PDF로 존재하면 여기서 비슷한 효과는 불가능해요. 브랜드 이름의 짧은 텍스트 버전이 실용적인 선택이에요.

문서를 인쇄할 때 워터마크가 보이나요?

네. 찍힌 텍스트는 실제 페이지 내용이라 화면에 나타나는 그대로, 선택한 불투명도로 정확히 인쇄돼요. 종이로 읽을 문서는 불투명도를 적당히 유지해야 하는 이유가 하나 더 있어요.

워터마크 텍스트를 우르두어, 아랍어, 중국어로 입력할 수 있나요?

내장 Helvetica 글꼴은 표준 라틴 문자, 숫자, 일반적인 기호만 커버해서 아랍어나 중국어 같은 문자는 찍을 수 없어요. CONFIDENTIAL 같은 영어 텍스트나 회사 이름은 안정적으로 작동해요.
