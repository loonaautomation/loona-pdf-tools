온라인으로 PDF 파일 비교 - 무료

요약하면: PDF 비교 도구는 두 PDF 파일의 텍스트를 페이지별로 읽고, 어떤 줄이 제거됐고, 어떤 줄이 추가됐고, 어떤 줄이 그대로인지 정확히 보여 줘요. 먼저 요약, 그다음 강조된 페이지별 차이 비교예요.

누군가 계약서, 과제, 보고서의 2번째 버전을 보냈는데 실제로 무엇이 바뀌었는지 알아야 하나요? 원본을 문서 A로, 새 파일을 문서 B로 불러오세요. 몇 초 만에 동일, 변경, 추가 페이지의 요약과, 강조된 모든 변경 줄을 받아요. 두 문서를 직접 나란히 읽지 않아도 돼요.

두 PDF 파일을 비교하는 방법

  1. 원본 PDF를 문서 A로, 수정된 PDF를 문서 B로 선택하세요.
  2. "PDF 비교"를 클릭하고 요약을 읽으세요: 동일한 페이지, 변경된 페이지, 한 파일에만 있는 페이지가 몇 개인지 알려 줘요.
  3. 페이지별 차이 비교를 스크롤하세요. A에서 제거된 줄은 빨간색으로, B에 추가된 줄은 초록색으로, 변경되지 않은 줄은 회색으로 표시돼요.

무엇이 비교되고 — 무엇이 비교되지 않는지

이 도구는 다음을 비교해요 추출된 텍스트 두 문서 중에서, PDF 리더가 선택하고 복사할 수 있는 바로 그 텍스트예요. 그 덕분에 편집된 문구, 변경된 숫자, 삭제된 조항, 추가된 단락을 찾는 데 신뢰할 수 있어요. 그 제한을 명심하세요:

  • 텍스트만이에요. 이미지, 로고, 글꼴, 색상, 간격, 레이아웃의 변경은 감지되지 않아요. 텍스트가 동일하면 두 페이지가 다르게 보여도 "Same"으로 비교될 수 있어요.
  • 스캔한 PDF는 비어 있는 것으로 표시돼요. 스캔은 페이지의 사진이라 텍스트 레이어가 없어요. 페이지에 텍스트가 없다고 나오면 거의 확실히 스캔된 것이에요. 먼저 OCR을 실행하세요. 예를 들어 무료 도구인 Loona Text Tools의 Image to Text (OCR) 도구로 설정한 뒤, 텍스트 기반 결과와 비교해 보세요.
  • 페이지는 번호로 맞춰져요. A의 3페이지는 B의 3페이지와 비교돼요. 앞쪽 가까이에 페이지가 삽입됐다면, 텍스트가 이동만 했어도 뒤의 모든 페이지가 변경된 것으로 표시될 수 있어요. 그래도 요약은 전체 그림을 알려 줘요.
  • 공백이 정리돼요. PDF 내부 저장에서 생기는 여분의 공백과 줄 바꿈 차이는 정규화되어, 순전히 장식적인 간격 차이가 실제 변경 사항을 묻어 버리지 않아요.

자주 묻는 질문

이 PDF 비교 도구는 정확히 무엇을 검사하나요?

두 PDF의 추출된 텍스트를 페이지별, 줄별로 비교해요. 첫 번째 문서에서 제거된 줄과 두 번째 문서에 추가된 줄이 강조 표시돼요. 이미지, 글꼴, 색상, 레이아웃은 비교하지 않아요.

스캔한 내 PDF에 비교할 텍스트가 없는 이유는 무엇인가요?

스캔된 PDF는 페이지의 그림이라 도구가 읽을 텍스트 레이어가 없어요. 먼저 OCR을 실행하세요. 예를 들어 무료 도구인 Loona Text Tools의 Image to Text (OCR) 도구 - 결과를 텍스트 기반 PDF로 저장한 뒤 비교해 보세요.

두 파일 사이에서 페이지는 어떻게 맞춰지나요?

1페이지는 1페이지와, 2페이지는 2페이지와 비교되는 식이에요. 한 문서에 페이지가 더 많으면, 추가 페이지는 조용히 무시되는 대신 A에만 있음 또는 B에만 있음으로 보고돼요.

내 PDF 파일이 서버에 업로드되나요?

아니에요. 두 파일 모두 JavaScript로 브라우저 안에서 완전히 열리고 비교돼요. 아무것도 업로드, 저장되지 않고 우리가 볼 수 없어요.

유사도 백분율은 무엇을 뜻하나요?

두 문서 모두에서 그대로 유지된 텍스트 줄의 비율이에요: 변경되지 않은 줄 수의 두 배를 A와 B의 전체 줄 합계로 나누고 백분율로 표시해요. 100%는 추출된 텍스트가 동일하다는 뜻이에요.

작동 방식

각 파일은 pdf.js로 브라우저에서 열려요. 파일은 절대 업로드되지 않고, 모든 페이지의 텍스트가 항목별로 추출돼요. 같은 시각적 줄에 있는 항목은 함께 묶이고, 여분의 공백은 축소되고, 빈 줄은 버려져 페이지별로 깔끔한 텍스트 줄 목록이 돼요. 그다음 각 페이지의 두 버전이 LCS(최장 공통 부분 수열) 차이 비교로 비교돼요. 프로그래머가 문서 버전을 비교할 때 쓰는 같은 기법이에요: 같은 순서로 양쪽에 모두 나타나는 줄은 변경 없음으로 표시되고, 나머지는 A에서 제거됐거나 B에 추가된 것으로 보고돼요. 줄 목록이 정확히 일치하는 페이지는 동일한 페이지로, 번호로 짝지어져 차이가 하나라도 있는 페이지는 변경된 페이지로, 더 짧은 문서의 길이를 넘는 페이지는 A에만 있음 또는 B에만 있음으로 셉니다. 유사도 백분율은 변경되지 않은 줄 수의 두 배를 두 문서의 전체 줄 수로 나눈 값이에요.

실제 예시

공급업체가 수정된 12페이지 견적서를 이메일로 보내요. 원본을 문서 A로, 새 파일을 문서 B로 불러오세요. 요약에는 동일한 페이지 10개, 변경된 페이지 2개, 텍스트 유사도 98%가 표시돼요. 4페이지에서 차이 비교는 빨간 줄 하나 - "Delivery within 30 days" - 와 초록 줄 하나 - "Delivery within 45 days" - 를 강조하고, 9페이지에서는 원본에 없던 처리 수수료를 추가하는 새 초록 줄이 나와요. 12페이지를 전부 다시 읽는 대신 두 가지 변경 사항으로 바로 가서 공급업체에 문의하면 돼요.

자주 묻는 질문

맨 앞에 전체 페이지가 삽입되어 있으면 어떻게 되나요?

페이지는 번호로 맞춰지기 때문에 첫 페이지가 삽입되면 모든 것이 밀려요: B의 1페이지가 기존 1페이지와 비교되는 식이라 대부분의 페이지가 변경된 것으로 표시돼요. 줄 단위 차이 비교는 실제 편집 내용을 여전히 보여 주고, 마지막의 "B에만 있음" 개수를 보면 페이지가 추가됐다는 것을 알 수 있어요. 더 깔끔한 결과를 원하면 페이지 추출 도구로 삽입된 페이지를 추출한 뒤 나머지 페이지를 순서대로 비교하세요.

비밀번호로 보호된 PDF를 비교할 수 있나요?

아니에요. pdf.js는 비밀번호 없이 암호화된 파일을 열 수 없으며, 이 도구는 비밀번호를 절대 묻지 않아요. 먼저 파일을 만든 소프트웨어에서 보호를 제거한 뒤, 잠금이 풀린 사본을 비교하세요.

서식 변경도 차이로 셉니까?

아니에요. 굵은 텍스트, 새 글꼴, 이동한 여백은 추출된 텍스트를 바꾸지 않으므로 보고되지 않아요. 추가, 제거, 편집된 단어와 숫자만 보고돼요.

얼마나 큰 문서를 비교할 수 있나요?

고정된 페이지 제한은 없어요. 아주 긴 문서(수백 페이지)는 모든 페이지가 본인 기기에서 읽히고 차이 비교되기 때문에 더 오래 걸리고, 극도로 짙은 페이지는 더 단순한 줄 맞추기 처리로 대체돼요. 요약 개수는 어느 쪽이든 올바르게 유지돼요.

일부 줄이 인쇄된 페이지와 비교해 분리되거나 합쳐져 보이는 이유는 무엇인가요?

PDF는 텍스트를 문장이 아니라 위치가 정해진 조각으로 저장해요. 이 도구는 같은 시각적 줄에 있는 조각들을 묶는데, 이는 대부분의 문서에서 인쇄된 레이아웃과 일치해요. 다만 두 단 레이아웃에서는 가끔 섞일 수 있어요. 단어 자체는 항상 문서의 실제 텍스트예요.
