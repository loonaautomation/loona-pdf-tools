온라인으로 PDF 양식 채우기 - 무료

요약하면: PDF 양식 채우기 도구는 실제 입력 가능한 양식 입력란이 있는 PDF를 열어, 모든 입력란을 단순한 상자, 표시, 목록으로 표시하고, 완성된 양식을 다운로드할 수 있게 해요. 입력란을 편집 가능한 상태로 두거나, 원하면 페이지에 평탄화해서요.

정부 양식, 학교 입학, 구직 신청, 은행 서류는 입력 가능한 PDF로 오는 경우가 많지만, 누구나 PDF 편집기를 가지고 있는 것은 아니에요. 여기서 양식을 열고, 도구가 찾은 입력란에 답변을 입력한 뒤, 파일을 어디에도 업로드하지 않고 완성된 사본을 다운로드하세요.

PDF에서 찾은 양식 입력란

다운로드한 PDF에서 양식을 평탄화하세요
평탄화하면 답변이 페이지에 구워져 인쇄된 텍스트처럼 보이고 더 이상 편집할 수 없어요. 최종 제출에 가장 좋아요. 이것을 선택하지 않으면(기본값) 입력란이 편집 가능한 상태로 유지되어 본인이나 사무실에서 나중에 답변을 바꿀 수 있어요.
이 PDF에는 입력 가능한 양식 입력란이 없어요. 스캔했거나 평면 양식일 수 있어요. 상자와 줄은 페이지 위의 그림일 뿐 파일 안에 실제 입력란이 없어서 이 도구(또는 어떤 도구)도 입력할 것이 없어요. 양식이 사무실이나 웹사이트에서 왔다면 “fillable”이나 “editable”라고 설명된 버전을 찾아보세요. 그 버전은 여기서 작동해요.
설계부터 비공개: 파일은 JavaScript로 브라우저에서 100% 처리돼요. 서버에 절대 업로드되지 않고, 저장되지 않고, 우리가 볼 수 없어요. 탭을 닫으면 모든 것이 사라져요.

PDF 양식을 채우는 방법

  1. 입력 가능한 PDF 양식을 선택하세요. 도구가 읽어서 들어 있는 모든 양식 입력란을 나열해요.
  2. 텍스트 상자에 답변을 입력하고, 확인란에 표시하고, 드롭다운과 라디오 버튼에서 고르세요.
  3. 평탄화할지 결정한 뒤(기본값: 끔, 입력란은 편집 가능한 상태로 유지돼요) “작성한 PDF 다운로드”를 클릭하세요.

자주 묻는 질문

도구가 내 PDF에 양식 입력란이 없다고 말하는 이유는 무엇인가요?

양식처럼 보이는 많은 PDF는 실제로 평면 페이지예요. 줄과 상자는 그냥 그림이고 파일 안에 실제 입력 가능한 입력란이 없어요. 실제 양식 입력란(AcroForm)으로 만들어진 PDF만 이런 방식으로 채울 수 있어요. 스캔한 종이 양식은 거의 항상 평면이에요.

평탄화와 평탄화하지 않는 것의 차이는 무엇인가요?

평탄화하지 않으면 답변은 양식 입력란에 저장되어 나중에 어떤 PDF 편집기에서도 여전히 편집할 수 있어요. 평탄화는 답변을 페이지 자체에 구워 넣어요: 보이는 그대로 인쇄되지만 입력란은 사라지고 더 이상 바꿀 수 없어요.

어떤 입력란 종류가 지원되나요?

텍스트 입력란(여러 줄 포함), 확인란, 드롭다운 목록, 라디오 버튼 그룹, 옵션 목록이에요. 서명 입력란과 푸시 버튼은 텍스트로 채울 수 없어 정보용으로만 나열돼요.

내 양식 답변이 어디에든 업로드되나요?

아니에요. PDF는 pdf-lib로 브라우저 안에서 완전히 열리고 채워져요. 아무것도 업로드, 저장되지 않고 우리가 볼 수 없어요.

작동 방식

도구는 pdf-lib로 브라우저 안에서 PDF를 열어요. 파일은 절대 업로드되지 않아요. 그리고 문서의 양식 정의(AcroForm이라고 불러요)를 읽어요. 찾은 모든 입력란은 맞는 제어로 표시돼요: 텍스트 입력란에는 텍스트 상자, 확인란에는 표시 상자, 드롭다운과 옵션 목록에는 목록, 라디오 그룹에는 라디오 버튼 세트예요. 각각은 양식이 이미 가지고 있는 답변으로 미리 채워져 있어요. 다운로드하면 답변은 같은 입력란에 다시 쓰이고 입력란 모양이 새로 고쳐져서, 어떤 PDF 리더에서도 값이 올바르게 표시돼요. 평탄화에 표시하면 입력란은 페이지 내용 자체에 병합되고 입력란으로서는 제거돼요. 완성된 파일은 이름에 -filled가 추가되어 저장돼요.

실제 예시

학교 사무실에서 입력 가능한 PDF로 입학 신청서를 보내왔어요. 입력란은 9개예요: 학생 이름, 생년월일, 지원 학급(드롭다운), 집 주소(여러 줄 텍스트 입력란), 첨부 서류 확인란 두 개, 그리고 교통수단 라디오 그룹(버스 또는 자가용)이에요. 여기서 파일을 열면 요약에 입력란 9개(텍스트 4개, 확인란 2개, 드롭다운 1개, 라디오 그룹 1개, 옵션 목록 1개)가 표시돼요. 답변을 입력하고 표시한 뒤, 사무실에서 철자를 고칠 수 있도록 평탄화은 선택하지 않은 채 admission-filled.pdf를 다운로드하면 이메일로 보낼 준비가 끝나요.

자주 묻는 질문

종이에서 스캔한 양식을 채울 수 있나요?

아니에요. 그리고 이 방법으로는 어떤 도구도 솔직히 할 수 없어요. 스캔은 양식의 사진이라 파일 안에 입력란이 없어요. 인쇄해서 손으로 채우거나, 발신자에게 원본 입력 가능 버전을 달라고 해야 해요.

일부 입력란은 목록에 나타나지만 입력할 수 없는 이유는 무엇인가요?

서명 입력란과 푸시 버튼은 텍스트 답변 입력란이 아니라서, 완전성을 위해 나열되지만 정보용으로만 표시돼요. 서명하려면 나머지 양식을 채운 뒤 PDF 서명 도구를 사용하세요.

작성한 양식은 Adobe Acrobat과 다른 리더에서도 여전히 작동할까요?

네. 답변은 새로 고쳐진 모양과 함께 표준 양식 입력란 값으로 저장돼요. Acrobat과 다른 리더가 기대하는 정확히 그것이에요. 평탄화하지 않는 한 입력란은 거기에서도 완전히 편집 가능한 상태로 유지돼요.

도구가 내 PDF에서 다른 것도 바꾸나요?

아니에요. 입력한 입력란 값만 쓰여요. 페이지, 이미지, 글꼴, 레이아웃은 건드려지지 않고, 평탄화를 포함해 페이지 수는 절대 바뀌지 않아요.

이미 양식 안에 있는 답변은 어떻게 되나요?

그것들은 각 입력란에 미리 채워져 표시돼요. 유지하거나, 편집하거나, 지우세요. 다운로드는 버튼을 클릭할 때 화면에 있는 것을 항상 써요.
