온라인으로 PDF에 페이지 번호 추가 - 무료

요약하면: 페이지 번호 추가 도구는 선택한 스타일, 위치, 크기로 PDF의 모든 페이지에 페이지 번호를 찍어요. 선택적 시작 숫자가 있어요.

과제, 보고서, 법률 서류 묶음은 페이지 번호가 있으면 따라가기 쉽고 회의에서 참조하기도 좋아요. 여기서 몇 초 만에 찍어 보세요: "Page 1", "1 of 10" 또는 단순 숫자를 고르고, 위나 아래에 배치한 뒤 다운로드하세요.

PDF에 페이지 번호를 추가하는 방법

  1. 번호를 매길 PDF를 선택하세요.
  2. 숫자 스타일, 위치, 글자 크기, 시작 숫자를 고르세요.
  3. "페이지 번호 추가"를 클릭하고 도장이 찍힌 PDF를 다운로드하세요.

자주 묻는 질문

1이 아닌 숫자부터 번호 매기기를 시작할 수 있나요?

네. 시작 숫자를 설정하세요. 이 파일이 다른 문서를 이어갈 때 유용해요.

어떤 위치를 사용할 수 있나요?

위쪽이나 아래쪽, 왼쪽, 가운데, 오른쪽 — 모두 여섯 가지 위치예요.

숫자가 내 내용을 덮을까요?

숫자는 각 페이지의 여백 영역에 그려져요. 내용이 가장자리까지 차 있으면 반대 위치를 선택하세요.

번호 매기기를 위해 파일이 업로드되나요?

아니에요. 도장 찍기는 전적으로 브라우저에서 일어나요.

작동 방식

도구는 pdf-lib로 브라우저 안에서 PDF를 열어 파일이 절대 업로드되지 않는 상태에서 표준 Helvetica 글꼴을 삽입하고 모든 페이지에 번호를 직접 그려요. 각 페이지 자체의 너비와 높이를 계산한 뒤, 선택한 크기의 진한 회색으로 텍스트를 옆에서 36 포인트, 아래쪽 가장자리에서 24 포인트 위(위쪽에서 30 포인트 아래)에 배치해요. 번호 매기기는 스타일을 따라요: 단순한 1, Page 1, 1 of 10 또는 - 1 - 이며, 시작 숫자부터 위쪽으로 세어 올라가고, 문서는 이름에 -numbered가 추가된 새 파일로 저장돼요.

실제 예시

24페이지 프로젝트 보고서를 제출해야 하고 페이지 번호가 필요해요. 스타일 'Page 1', 위치 아래쪽 가운데, 11 pt 크기를 선택하고, 시작 숫자는 1로 두세요. 다운로드한 report-numbered.pdf는 모든 페이지 아래쪽 가운데에 'Page 1'부터 'Page 24'까지 표시되어 인쇄하거나 이메일로 보낼 준비가 돼요.

자주 묻는 질문

표지에 번호를 매기지 않을 수 있나요?

건너뛰기 옵션은 없어요. 숫자는 모든 페이지에 그려져요. 흔한 우회 방법은 페이지 추출 도구로 표지를 추출하고, 여기서 남은 페이지에 번호를 매긴 뒤, PDF 병합으로 표지를 다시 앞에 병합하는 것이에요.

숫자는 어떤 글꼴과 색상으로 인쇄되나요?

선택한 9부터 12 pt 크기의 진한 회색 Helvetica예요. 중립적인 스타일은 대부분의 문서에 잘 맞고, 내용에서 주의를 빼앗지 않으면서 읽기 쉽게 유지돼요.

5부터 시작하면 '1 of 10' 스타일은 무엇을 표시하나요?

스타일은 시작 숫자를 따라요. 그래서 5부터 시작하는 10페이지 문서는 5 of 14, 6 of 14 등으로 14 of 14까지 표시돼요. 합계가 조정되어 마지막 페이지가 여전히 그 숫자와 맞아요.

번호는 가로 페이지나 크기가 섞인 페이지에서도 작동하나요?

네. 위치는 각 페이지 자체의 너비와 높이에서 따로 계산되어, 가로 페이지도 세로 페이지처럼 올바른 모서리나 가운데에 번호를 받아요.

나중에 번호를 제거할 수 있나요?

그것들은 인쇄된 텍스트처럼 각 페이지 내용의 영구적인 일부가 되어, 나중에 단순히 끌 수 없어요. 번호 없는 사본이 필요할 수 있으면 원본 파일을 보관하세요.
