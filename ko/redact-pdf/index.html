온라인으로 PDF 가리기(레닥션) - 무료 (진짜 구워 넣기 레닥션)

요약하면: PDF 가리기(레닥션) 도구는 덮은 것을 영구적으로 제거해요: 어떤 페이지에서든 민감한 영역 위에 검은 직사각형을 그리면, 도구는 모든 페이지를 상자가 칠해진 이미지로 다시 만들어요. 아래의 텍스트는 파일에 더 이상 존재하지 않아서 복사, 검색, 드러낼 수 없어요.

편집기에서 검은 도형으로 텍스트를 덮는 것은 가리기(레닥션)가 아니에요. 단어가 종종 아래에 숨은 채로 남아 복사할 수 있어요. 이 도구는 안전한 방식으로 해요: 모든 페이지가 검은 상자가 구워진 그림으로 다시 만들어져 덮인 내용이 정말로 사라져요.

솔직한 절충: 페이지는 제거를 보장하기 위해 이미지로 다시 만들어지기 때문에, 가린(레닥션) PDF의 텍스트는 더 이상 선택하거나 검색할 수 없어요 어떤 페이지에서든, 그리고 파일이 더 클 수 있어요. 그것은 취소할 수 없는 레닥션의 대가예요. 그리고 그것은 숨겨지지 않고 여기에 명시했어요.

페이지 위를 드래그해 검은 상자를 그리세요. 필요한 만큼 여러 페이지에서 반복하세요. 상자는 페이지별로 기억돼요.

설계부터 비공개: 파일은 JavaScript로 브라우저에서 100% 처리돼요. 서버에 절대 업로드되지 않고, 저장되지 않고, 우리가 볼 수 없어요. 탭을 닫으면 모든 것이 사라져요.

이 도구 사용법

  1. 민감한 내용이 있는 PDF를 선택하세요.
  2. 페이지를 고르고 그 위를 드래그해 제거할 각 이름, 번호, 사진, 단락 위에 검은 상자를 그리세요.
  3. 다른 페이지에서 반복하세요. 모든 상자가 나열되어 실수를 취소할 수 있어요.
  4. 가리기(레닥션) 및 다운로드를 클릭하세요. 모든 페이지는 상자가 구워진 이미지로 다시 만들어져요.

자주 묻는 질문

덮인 내용이 정말로 제거되나요, 아니면 그냥 숨겨지나요?

정말로 제거돼요. 각 페이지는 이미지로 렌더링되고, 검은 상자는 그 이미지에 칠해지며, 그 이미지들로만 완전히 새로운 PDF가 만들어져요. 원본 텍스트 레이어는 새 파일에 절대 들어가지 않아서 아래에 복사, 검색, 드러낼 것이 없어요.

가린(레닥션) PDF의 텍스트는 왜 더 이상 선택할 수 없나요?

모든 페이지가 이제 그림이기 때문이에요. 바로 그것이 제거를 보장해요. 선택 가능한 문서가 필요하면 공유용 사본만 가리고(레닥션) 원본은 비공개로 보관하세요.

누군가 편집기로 검은 상자를 제거할 수 있나요?

아니에요. 상자는 텍스트 위에 놓인 별도 객체가 아니에요. 종이에 인쇄된 잉크처럼 페이지 이미지 자체의 일부예요. 편집기에서 객체를 이동하거나 삭제해도 저장되지 않은 픽셀을 되돌릴 수 없어요.

파일 크기가 바뀔까요?

보통 커져요. 이미지 페이지가 텍스트 페이지보다 무겁기 때문이에요. 특히 긴 문서에서 그래요. 페이지는 선명한 2x 해상도에 좋은 품질의 JPEG 압축으로 렌더링되어 선명함과 크기의 균형을 맞춰요.

작동 방식

도구는 PDF.js로 브라우저에서 각 PDF 페이지를 렌더링해요. 페이지 위를 드래그하면 직사각형은 그 페이지의 실제 PDF 좌표로 저장돼요. 다운로드할 때는 모든 페이지가 2x 해상도로 화면 밖 캔버스에 다시 렌더링되고, 검은 직사각형이 캔버스에 칠해지며, 캔버스는 JPEG로 저장돼요. 그다음 그 페이지 이미지들만으로 pdf-lib로 새 PDF가 조립돼요. 원본 파일의 텍스트, 벡터, 숨은 레이어는 출력에 절대 복사되지 않아요. 덮인 내용을 그 파일에서 복구할 수 없는 이유가 바로 그것이에요.

실제 예시

학교는 성적표를 공유해야 하지만 학생들의 ID 번호는 숨겨야 해요. 사무원은 3페이지 모두에서 ID 열 위에 상자를 그리고 다운로드해요 results-redacted.pdf. 이후에 공유된 파일에서 숫자를 선택해 복사하려고 해 보지만 불가능해요. 그 열은 이제 단순한 검은 픽셀일 뿐이니까요.

자주 묻는 질문

다시 만든 페이지는 어떤 해상도인가요?

페이지는 평소 크기의 두 배(2x, 약 144 DPI)로 렌더링되어 원래 페이지 치수에 고품질 JPEG 이미지로 저장돼요. 그래서 인쇄물은 선명하게 유지되면서 파일은 적당한 수준을 유지해요.

스캔은 다르게 가려야(레닥션) 하나요?

아니에요. 스캔 페이지는 이미 이미지이고, 같은 구워 넣기가 적용돼요: 덮인 픽셀은 다시 만든 이미지에서 검은색으로 대체돼요.

가리기(레닥션)가 메타데이터도 제거하나요?

다시 만든 PDF는 새 파일이며 원본의 텍스트나 숨은 페이지 내용을 복사하지 않아요. 원본의 기본 문서 정보는 이어지지 않아요. 파일 이름이나 메타데이터 자체가 민감하면 다운로드를 이름 바꾸고 PDF 정보 편집 도구로 확인하세요.

한 페이지만 가리고(레닥션) 나머지는 텍스트로 유지할 수 있나요?

이 도구로는 아니에요. 모든 페이지가 이미지로 다시 만들어져 과정이 균일하고 처리되지 않은 페이지에서 아무것도 빠져나가지 않아요. 의도적인 안전 선택이에요.

가린(레닥션) 파일을 공유하기 전에 무엇을 확인해야 하나요?

열어서 모든 페이지를 넘겨 보세요: 각 상자가 작은 여백으로 목표를 완전히 덮는지 확인하고, 텍스트 선택을 시도해 보세요. 아무것도 선택할 수 없어야 하는데, 이는 구워 넣기가 작동했음을 확인해 줘요.
