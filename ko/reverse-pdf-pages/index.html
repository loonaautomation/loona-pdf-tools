온라인으로 PDF 페이지 순서 뒤집기 - 무료

요약하면: PDF 페이지 뒤집기 도구는 문서의 페이지 순서를 뒤집어요: 마지막 페이지가 첫 페이지가 되고, 마지막에서 두 번째가 두 번째가 되는 식이에요. 뒤에서 앞으로 스캔되거나 내보내진 문서의 한 번 클릭 해결책이에요.

일부 스캐너와 내보내기 도구는 PDF를 역순으로 만들어요. 그리고 긴 문서를 다시 스캔하면 실제 시간이 낭비돼요. 대신 여기서 파일을 뒤집으세요. 페이지 자체는 건드려지지 않고 순서만 뒤집혀요.

이 도구 사용법

  1. 뒤에서 앞으로 된 PDF를 선택하세요.
  2. 페이지 뒤집기 및 다운로드를 클릭하세요.
  3. 결과를 여세요. 기존 마지막 페이지가 이제 1페이지예요. 도구를 두 번 실행하면 원래 순서가 복원돼요.

자주 묻는 질문

뒤집기가 페이지 자체를 바꾸나요?

아니에요. 페이지 내용, 품질, 크기는 정확히 복사돼요. 순서만 바뀌어요. 텍스트는 선택 가능한 상태로 유지되고 이미지는 원본으로 유지돼요.

스캔한 내 문서가 거꾸로인 이유는 무엇인가요?

자동 급지 장치가 있는 많은 스캐너는 묶음을 마지막 페이지부터 스캔하고, 일부 소프트웨어는 역순으로 내보내요. 파일을 뒤집는 것이 다시 스캔하는 것보다 빨라요.

문서의 일부만 뒤집을 수 있나요?

이 도구는 전체 파일을 뒤집어요. 부분 제어가 필요하면 썸네일을 어떤 순서로든 드래그할 수 있는 PDF 정리를 사용하세요.

페이지 제한이 있나요?

우리가 정한 제한은 없어요. 작업은 기기에서 일어나므로 아주 긴 문서는 기기의 메모리에만 의존해요.

작동 방식

도구는 pdf-lib로 PDF를 불러와 그 페이지를 정확히 역순의 색인 순서(마지막에서 첫 번째로)로 새 문서에 복사하고 저장해요. 페이지는 완전한 객체로 복사돼요. 내용 스트림, 글꼴, 이미지는 원본과 공유되고 다시 렌더링되지 않아서 품질과 파일 동작이 보존돼요.

실제 예시

40페이지 스캔 기록이 급지대에서 40페이지부터 거꾸로 나와요. 여기서 한 번 클릭하면 실제 1페이지부터 시작하는 사본이 만들어져 공유할 준비가 돼요.

자주 묻는 질문

북마크와 링크는 여전히 올바르게 가리킬까요?

페이지는 새 문서로 복사되어 내부 북마크와 링크는 이어지지 않아요. 페이지 내용 자체는 완전해요.

페이지 수가 홀수인 문서는 어떻게 되나요?

가운데 페이지는 가운데에 남아 있어요. 뒤집기는 순서의 순수한 거울상이라 홀수 개수와 짝수 개수 모두에 해당해요.

뒤집기를 취소할 수 있나요?

네 — 뒤집힌 파일을 이 도구로 다시 실행하면 원래 순서가 정확히 돌아와요.
