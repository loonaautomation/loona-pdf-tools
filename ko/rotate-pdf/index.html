온라인으로 PDF 페이지 회전 - 무료

요약하면: PDF 회전 도구는 페이지를 90, 180, 270도로 영구적으로 돌려요. 파일의 모든 페이지든 선택한 범위만든 상관없이, 수정된 사본을 저장해요.

스캔한 문서는 옆으로 나오는 것을 좋아해요. 영원히 고개를(또는 휴대폰을) 기울이는 대신, 페이지를 한 번 회전하고 모든 리더에서 올바른 방향으로 열리는 고정된 PDF를 저장하세요.

클릭해서 PDF 파일을 선택하세요
또는 여기에 끌어다 놓으세요
설계부터 비공개: 파일은 JavaScript로 브라우저에서 100% 처리돼요. 서버에 절대 업로드되지 않고, 저장되지 않고, 우리가 볼 수 없어요. 탭을 닫으면 모든 것이 사라져요.

PDF 페이지를 회전하는 방법

  1. 잘못 돌아간 페이지가 있는 PDF를 선택하세요.
  2. 각도를 고르세요. 90, 180, 270도이며, 선택적으로 2-4 같은 페이지 범위로 제한할 수 있어요.
  3. "PDF 회전"을 클릭하고 수정된 문서를 다운로드하세요.

자주 묻는 질문

회전은 영구적인가요?

네. 페이지 회전은 저장된 파일에 쓰여서, 모든 리더와 프린터가 페이지를 새 방식으로 표시해요.

일부 페이지만 회전할 수 있나요?

네. 페이지 상자에 2-4 같은 범위(또는 1, 3 같은 단일 페이지)를 입력하세요. 비워 두면 모든 페이지가 회전돼요.

회전이 품질을 바꾸나요?

아니에요. 각 페이지의 방향 표시만 바뀌어요. 내용은 건드려지지 않아요.

내 페이지는 섞여 있어요. 어떤 것은 맞고 어떤 것은 틀려요. 그럴 때는 어떻게 하나요?

두 번에 나누어 회전하세요: 먼저 대다수를 고치고, 그다음 파일을 다시 실행해 남은 페이지만 회전하세요.

작동 방식

PDF 페이지에는 내장된 회전 설정이 있어 모든 리더와 프린터에게 어느 방향으로 보여 줄지 알려 줘요. 이 도구는 pdf-lib로 파일을 로컬에서 불러와, 선택한 각도(시계 방향 90, 180, 270도)를 모든 페이지 또는 입력한 페이지 범위에 대해 그 저장된 설정에 더하고, 결과를 새 파일로 저장해요. 그 파일에는 다음이 있어요 -회전됨 이름에 추가돼요. 방향 설정만 바뀌어요: 페이지 내용 자체는 다시 그려지거나, 다시 압축되거나, 어떤 방식으로도 건드려지지 않아서 품질과 파일 크기가 사실상 동일하게 유지되고, 모든 것은 업로드 없이 브라우저에서 일어나요.

실제 예시

사무원이 10페이지 신청서를 스캔했지만 3, 4, 5페이지가 스캐너를 옆으로 통과했어요. PDF를 불러오고 각도는 그대로 둬요 시계 방향 90도라고 입력해요 3-5 페이지 상자에 입력하고, PDF 회전을 클릭해요. 다운로드한 파일은 form-rotated.pdf 그 세 페이지를 모든 곳(리더, 휴대폰, 프린터)에서 똑바로 보여 주고, 다른 일곱 페이지는 건드려지지 않아요.

자주 묻는 질문

각도는 시계 방향인가요, 반시계 방향인가요?

세 각도 모두 표시된 대로 시계 방향으로 돌아요. 페이지가 반대 방향으로 돌아야 하면 시계 방향 270도를 선택하세요. 반시계 방향 90도와 같아요.

페이지가 이미 파일에서 회전되어 있으면 어떻게 되나요?

새 각도는 페이지가 이미 가진 어떤 회전에도 더해지고, 합계는 360도에서 한 바퀴 돌아요. 그래서 이미 90도에 저장된 페이지를 270도 회전하면 0으로 돌아와요. 회전 없이 똑바로 선 상태예요.

파일이 커지거나 품질이 떨어지나요?

의미 있는 방식으로는 어느 쪽도 아니에요. 각 페이지 설정의 작은 회전 값만 바뀌어요. 텍스트, 이미지, 글꼴은 정확히 그대로 이어져 파일 크기가 거의 그대로 유지돼요.

휴대폰에서 PDF를 회전할 수 있나요?

네. 도구는 모든 최신 모바일 브라우저에서 실행되고, 처리는 휴대폰 자체에서 일어나요. 저장소에서 파일을 고르고 각도를 설정하면 수정된 PDF가 기기에 다운로드돼요.

잘못된 방향으로 회전했어요. 취소할 수 있나요?

원본 파일은 절대 수정되지 않아요. 회전은 새 다운로드 사본에만 쓰여요. 원본을 반대 각도(90 대신 270, 그 반대도 마찬가지)로 다시 실행하거나, 새 파일을 남은 양만큼 회전해 합계 360에 도달하게 하세요.

비밀번호로 보호된 PDF를 회전할 수 있나요?

아니에요. 보호 때문에 파일을 열고 다시 저장할 수 없어요. 먼저 평소 쓰는 PDF 리더에서 비밀번호를 제거한 뒤, 잠금이 풀린 사본을 여기서 회전하세요.
