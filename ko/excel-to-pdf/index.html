Excel을 PDF로 변환하는 도구

요약하면: 이 도구는 Excel 워크북을 정돈된 PDF로 만들어요 — 시트당 표 하나, 머리글 행이 모든 페이지에 반복되고, 전적으로 브라우저에서 만들어져요.

스프레드시트는 편집용이고 PDF는 공유용이에요. 이 변환기는 .xlsx, .xls 또는 .csv 파일을 읽어 모든 시트를 인쇄 준비가 된 PDF에 깔끔한 표로 배치해요. 숫자와 날짜는 Excel에 표시되는 그대로예요.

클릭해서 Excel 또는 CSV 파일을 선택하세요
또는 여기에 끌어다 놓으세요 — .xlsx, .xls 또는 .csv예요
설계부터 비공개: 파일은 JavaScript로 브라우저에서 100% 처리돼요. 서버에 절대 업로드되지 않고, 저장되지 않고, 우리가 볼 수 없어요. 탭을 닫으면 모든 것이 사라져요.

단계별 작동 방식

  1. .xlsx, .xls 또는 .csv 파일을 선택하거나 끌어다 놓으세요.
  2. 페이지 크기와 방향을 고르세요 — 자동에서는 시트에 열이 많으면 가로를 선택해요.
  3. PDF로 변환을 누른 뒤, 나타나는 링크에서 결과를 다운로드하세요.

기능

  • 워크북의 모든 시트는 자체 표가 되어 새 페이지에서 시작해요.
  • 서식이 적용된 값: 숫자, 통화, 날짜는 원시 일련번호가 아닌, Excel에 표시되는 그대로 나타나요.
  • 각 시트의 첫 번째 행은 머리글로 취급되어 모든 페이지 위에 반복돼요.
  • 긴 텍스트는 잘리는 대신 셀 안에서 줄이 바뀌어요.
  • 넓거나 좁은 시트를 위한 페이지 크기, 방향, 너비에 맞추기 제어가 있어요.
  • 업로드도, 가입도, 워터마크도 없어요 — 파일은 기기를 절대 떠나지 않아요.

자주 묻는 질문

.xlsx가 지원되나요?

네 — 최신 .xlsx 워크북, 오래된 .xls 파일, 일반 .csv 파일이 모두 페이지에서 로컬로 읽혀요. 추가 기능도 계정도 필요 없어요.

여러 시트는 어떻게 되나요?

워크북의 모든 시트는 자체 표가 되어 워크북 순서대로 새 페이지에서 시작하고, 시트 이름이 제목으로 인쇄돼요.

수식이 변환되나요?

결과를 받아요 — Excel이 마지막으로 계산해 파일에 저장한 값이 일반 서식으로 표시돼요. 수식 자체는 인쇄되지 않아요.

차트와 색상은 왜 PDF에 나타나지 않나요?

이 변환기는 시트의 값을 깔끔한 표로 내보내요. 차트, 이미지, 셀 색상, 글꼴, 병합된 셀 레이아웃은 이어지지 않아요. 스타일이 적용된 시트의 픽셀 단위로 완벽한 사본이 필요하면 Excel 자체에서 PDF로 인쇄하세요.

내 파일이 업로드되나요?

아니에요. 워크북은 파싱되고 PDF는 전적으로 브라우저에서 만들어져요 — 서버로 아무것도 보내지 않아요.

내부 구조

파일은 SheetJS로 파싱되고 PDF 표는 jsPDF와 그 AutoTable 플러그인으로 그려져요. 세 라이브러리 모두 이 사이트 자체의 라이브러리 폴더에서 불러와요 — 작업하는 동안 CDN에서 아무것도 가져오지 않고, 아무것도 기기를 떠나지 않아요. 충실한 표 내보내기예요 — 스프레드시트 복제는 아니에요: 셀 값과 그 표시 서식은 이어지지만, 차트, 이미지, 색상, 병합된 셀 레이아웃은 이어지지 않아요. 위의 FAQ에 분명히 명시했어요.

실제 예시

성적 시트와 수납 시트가 있는 직원 워크북은 PDF 하나로 두 개의 표가 돼요. 각 시트는 자체 페이지에 있고 머리글 행이 전체에 반복되어 사무실 파일용으로 이메일로 보내거나 인쇄할 준비가 돼요.
