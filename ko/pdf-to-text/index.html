온라인으로 PDF를 텍스트로 변환 - 무료

요약하면: PDF를 텍스트로 변환 도구는 PDF의 모든 페이지에서 읽을 수 있는 텍스트를 추출해 편집 가능한 상자에 표시해, 복사하거나 .txt 파일로 다운로드할 준비가 돼요.

PDF에서 손으로 텍스트를 복사하는 것은 느리고 지저분해요. 이 추출기는 문서의 텍스트 레이어를 페이지별로 읽어 노트, 인용, 편집, 번역에 쓸 수 있는 깔끔하고 재사용 가능한 텍스트를 제공해요.

  2. "텍스트 추출"을 클릭하고 각 페이지가 읽히는 동안 잠시 기다리세요.
  3. 상자에서 텍스트를 복사하거나 .txt 파일로 다운로드하세요.

일부 텍스트가 누락되거나 뒤죽박죽인 이유는 무엇인가요?

도구는 PDF의 내장 텍스트 레이어를 읽어요. 스캔한 PDF는 텍스트의 그림이라 텍스트 레이어가 없어요. 그런 것들은 OCR이 필요하고, 일부 PDF는 특이한 읽기 순서로 텍스트를 저장해요.

추출된 텍스트를 편집할 수 있나요?

네. 결과는 복사하거나 다운로드하기 전에 편집 가능한 텍스트 상자에 나타나요.

페이지 제한이 있나요?

고정된 제한은 없어요. 긴 문서는 기기에서 처리하는 데 조금 더 오래 걸릴 뿐이에요.

내 문서가 업로드되나요?

아니에요. 추출은 브라우저에서 100% 실행돼요.

작동 방식

Word, Excel 또는 웹 페이지에서 만든 대부분의 PDF에는 숨은 텍스트 레이어가 있어요. 페이지 레이아웃과 함께 저장된 실제 문자예요. 이 도구는 PDF.js로 파일을 로컬에서 열어 그 텍스트 레이어를 페이지별로 읽고, 저장된 조각들을 페이지의 세로 위치로 다시 줄에 묶어요. 결과는 다음과 함께 조립돼요 --- N페이지 --- 각 페이지 앞의 표시가 편집 가능한 텍스트 상자에 배치되어, 복사하거나 일반 .txt 파일로 다운로드할 준비가 돼요. OCR(그림 읽기) 단계는 없어요: 도구는 파일 자체가 포함한 텍스트만 반환할 수 있고, 모든 것은 브라우저에서 일어나요. 문서는 절대 업로드되지 않아요.

실제 예시

학생이 강의 노트 12페이지 세트를 PDF로 다운로드하고 정의를 자신의 문서에 넣고 싶어 해요. 파일을 도구로 실행하면 상자에 12페이지 전체가 채워지고, 각 페이지는 자체 항목 아래에 표시돼요 --- N페이지 --- 제목이에요. 필요 없는 페이지를 삭제하고, 제목 한두 개를 정리한 뒤, 나머지를 과제에 복사해요. 그리고 전체 추출을 다음으로 저장하기도 해요 extracted-text.txt 나중을 위해요.

자주 묻는 질문

내 PDF는 스캔인데 결과가 비어 있어요. 왜 그런가요?

스캔된 PDF는 페이지의 사진이에요. 우리 눈에는 텍스트처럼 보이지만 파일에는 도구가 읽을 텍스트 레이어가 없어요. 스캔에는 사진 속 글자를 인식하는 OCR 소프트웨어가 필요해요. 이 도구는 실제 텍스트 레이어를 충실하고 정확하게 읽는 일만 의도적으로 수행해요.

출력에서 페이지는 어떻게 구분되나요?

각 페이지는 다음 내용의 줄로 시작해요 --- 1페이지 ---, --- 2페이지 --- 와 같은 방식으로, 원래 순서대로라서 어떤 단락이 어떤 페이지에서 왔는지 항상 알 수 있어요.

표와 다단 레이아웃이 유지되나요?

부분적으로만 그래요. 줄은 파일에 텍스트가 저장된 순서와 위치대로 다시 만들어져서 단순한 문서는 자연스럽게 읽혀요. 다단 페이지나 복잡한 표에서는 저장된 순서가 섞일 수 있고, 복사하기 전에 편집 상자에서 빠르게 정리해야 할 수 있어요.

정확히 무엇을 다운로드하나요?

이름이 다음과 같은 단순 텍스트 파일 하나예요 extracted-text.txt 상자 안의 모든 것 — 만든 모든 편집을 포함해요. 일반 텍스트에는 글꼴이나 서식이 없어서 Word, 이메일, 메모 앱에 깔끔하게 붙어요.

몇 페이지의 텍스트만 필요해요. 선택할 수 있나요?

페이지 선택기는 없어요. 도구는 모든 페이지를 추출해요. 빠른 작업 방법은 모두 추출한 뒤 원하지 않는 것을 삭제하는 것이에요 --- N페이지 --- 복사하거나 다운로드하기 전에 상자 안의 섹션을 확인하세요.

영어 외의 언어에서도 작동하나요?

네, 문자가 PDF의 텍스트 레이어에 저장된 언어에 대해서는, 문자가 저장된 대로 추출돼요. 읽기 순서는 파일의 내부 순서를 따른다는 점에 유의하세요. 일부 오른쪽에서 왼쪽으로 쓰는 문서는 읽기 순서가 아닌 시각적 순서로 저장해요.
