온라인으로 PNG를 PDF로 변환 - 무료

요약하면: PNG를 PDF로 변환 도구는 하나 이상의 PNG 이미지를 하나의 PDF로 결합해요. A4, Letter 또는 이미지에 맞춘 페이지 크기와 여백을 선택할 수 있어요.

스크린샷, 다이어그램, 디자인 내보내기는 대개 느슨한 PNG 파일로 존재해요. 여기서 하나의 전문적인 PDF로 모으세요: 페이지 크기를 선택하고 여백을 설정한 뒤, 이메일로 보내거나 인쇄하기 쉬운 문서를 다운로드하세요.

PNG를 PDF로 변환하는 방법

  1. 위 상자로 PNG 이미지를 하나 이상 추가하세요(JPG 파일도 가능해요).
  2. 문서에 맞게 페이지 크기, 방향, 여백을 선택하세요.
  3. "PDF 만들기"를 클릭하고 완성된 파일을 다운로드하세요.

자주 묻는 질문

투명 PNG는 투명한 상태로 유지되나요?

PNG 자체는 변경 없이 삽입돼요. 대부분의 PDF 뷰어는 인쇄된 것처럼 흰 페이지 배경 위에 투명도를 표시해요.

PNG와 JPG 이미지를 섞을 수 있나요?

네. 두 형식 모두 같은 목록에 추가할 수 있고 하나의 PDF의 페이지가 돼요.

내 이미지가 어디에든 업로드되나요?

아니에요. PDF는 브라우저에서 조립돼요. 서버로 아무것도 보내지 않아요.

이미지에 맞추기는 무엇을 하나요?

각 PDF 페이지의 크기를 이미지 자체의 비율에 맞춰서 잘리거나 채워지는 것이 없어요.

작동 방식

도구는 전적으로 브라우저에서 pdf-lib로 완전히 새로운 PDF를 만들어요. 추가하는 각 PNG는 정확히 그대로 문서에 삽입돼요. 이미지 데이터 자체는 다시 압축되거나 변경되지 않고, 자체 페이지를 받아요. 페이지 크기(A4, Letter, 또는 각 이미지에 맞춤), 방향, 여백을 선택하면 모든 이미지는 비율을 유지하며 페이지 안에 맞게 조정되어 가운데에 배치돼요. JPG 파일도 작동해요. 같은 방식으로 삽입돼요. PDF 만들기를 클릭하면 완성된 문서는 다음으로 저장돼요 images.pdf. 사진은 기기를 떠나지 않아요.

실제 예시

학생이 손으로 쓴 숙제 6페이지를 휴대폰에서 PNG 스크린샷으로 찍어요. 여섯 개를 모두 추가하고 다음을 선택해요 A4 와 함께 작음 여백을 설정해 페이지가 선생님에게 균일하게 보이게 하고, PDF를 만들어요. 깔끔한 파일 하나가 나와요 images.pdf - 추가한 순서대로 깔끔한 A4 여섯 페이지가 완성되어 학교 포털에 올릴 준비가 됐어요.

자주 묻는 질문

이미지 순서를 바꿀 수 있나요?

페이지는 목록의 순서를 따라요. 파일을 추가한 순서예요. 드래그로 순서 바꾸기는 없어요: 이미지를 이동하려면 제거 버튼으로 제거하고 끝에 다시 추가하거나, 원하는 순서대로 세트를 다시 추가하세요.

완성된 파일 이름은 무엇인가요?

항상 다음으로 저장돼요 images.pdf. 브라우저나 다운로드 폴더에 같은 파일이 이미 있으면 숫자가 붙을 수 있어요. 나중에 다른 파일처럼 이름을 바꾸면 돼요.

내 PNG는 PDF 안에서 품질을 잃을까요?

아니에요. PNG와 JPG 이미지는 바이트 단위로 변경 없이 삽입돼요. 페이지 크기와 여백 설정은 저장된 이미지의 품질이 아니라, 이미지가 페이지에 얼마나 크게 그려질지만 결정해요.

어떤 이미지 형식을 추가할 수 있나요?

PNG와 JPG(JPEG)만 가능해요. 파일 선택기는 그 두 형식을 받아요. WebP나 GIF 같은 다른 형식은 먼저 PNG나 JPG로 변환해야 해요.

내 이미지의 방향이 서로 다르면 어떻게 되나요?

방향 선택: 자동에서는 각 페이지가 자체 이미지를 따라요. 넓은 이미지는 가로 페이지, 높은 이미지는 세로 페이지를 얻어요. 이미지에 맞추기에서는 모든 페이지가 이미지의 정확한 비율과 일치해요.

이미지를 몇 개까지 결합할 수 있나요?

도구에는 고정된 제한이 없어요. 아주 큰 세트는 전체 PDF가 브라우저에서 조립되기 때문에 기기의 메모리에 의해서만 제한돼요. 일반적인 사진 수십 장은 괜찮아요.
