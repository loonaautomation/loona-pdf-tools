온라인으로 PDF 페이지 정리 - 무료

요약하면: PDF 정리 도구는 PDF의 모든 페이지를 썸네일로 표시해서, 페이지를 새 순서로 드래그하고, 옆으로 된 페이지를 회전하고, 필요 없는 페이지를 삭제할 수 있게 해요. 그다음 결과를 새 PDF로 저장하세요. 완전히 무료이고 아무것도 업로드하지 않아요.

스캐너는 순서를 제대로 맞추는 경우가 드물어요: 페이지가 섞여 나오고, 빈 종이가 끼어들고, 한 페이지가 옆으로 와요. 인쇄하고 다시 스캔하는 대신, PDF를 여기에 넣고 문서가 읽혀야 하는 방식으로 썸네일을 배열한 뒤, 깔끔하고 올바르게 순서가 정해진 사본을 다운로드하세요.

클릭해서 PDF 파일을 선택하세요
또는 여기에 끌어다 놓으세요 - 약 50 MB 아래의 파일에서 가장 잘 작동해요
설계부터 비공개: 파일은 JavaScript로 브라우저에서 100% 처리돼요. 서버에 절대 업로드되지 않고, 저장되지 않고, 우리가 볼 수 없어요. 탭을 닫으면 모든 것이 사라져요. 원본 파일은 절대 수정되지 않아요. 도구는 항상 새 PDF를 만들어요.

PDF 페이지를 정리하는 방법

  1. 위 상자를 클릭하거나 PDF를 끌어다 넣으세요. 페이지가 썸네일로 나타나요.
  2. 썸네일을 새 위치로 드래그하거나, 아래의 왼쪽/오른쪽 화살표 버튼을 사용하세요(휴대폰에서 더 쉬워요). 회전 버튼을 눌러 옆으로 된 페이지를 돌리고, 삭제 버튼을 눌러 필요 없는 페이지를 제거하세요.
  3. "PDF 저장"을 클릭하면 재정리된 문서가 표시된 순서 그대로 자동으로 다운로드돼요.

자주 묻는 질문

여기서 PDF를 정리하는 것은 무료인가요?

네. PDF 정리 도구는 가입도, 워터마크도, 우리가 부과하는 페이지 제한도 없이 완전히 무료예요.

내 파일이 서버에 업로드되나요?

아니에요. 정리는 JavaScript를 사용해 브라우저 안에서 100% 일어나요. 파일은 기기를 절대 떠나지 않아요.

페이지 순서를 어떻게 바꾸나요?

페이지 썸네일을 새 위치로 드래그하거나, 각 썸네일 아래의 왼쪽/오른쪽 화살표 버튼을 사용하세요. 휴대폰과 태블릿에서 편리해요.

정리하면서 페이지를 회전하거나 제거할 수 있나요?

네. 회전 버튼은 누를 때마다 페이지를 90도 돌리고, 삭제 버튼은 새 PDF에서 페이지를 제거해요. 초기화 버튼은 원래 순서를 복원하고 모든 페이지를 되돌려요.

정리할 수 있는 가장 큰 PDF는 무엇인가요?

도구에는 고정된 제한이 없지만, 약 50 MB 아래의 파일에서 가장 잘 작동해요. 모든 것은 기기의 메모리에서 실행되므로 아주 큰 파일은 기기에 여유 메모리가 얼마나 있는지에 의존해요.

작동 방식

파일은 브라우저 안에서 바로 열려요. 어떤 서버에도 아무것도 업로드되지 않아요. 페이지 미리보기는 Firefox가 PDF를 표시하는 데 사용하는 같은 엔진인 pdf.js 라이브러리가 그려요. 저장을 클릭하면 pdf-lib 라이브러리가 완전히 새로운 문서를 만들고 썸네일의 정확한 순서대로 페이지를 복사해, 설정한 회전을 적용하고 삭제한 페이지는 빼요. 페이지는 인쇄되거나 다시 렌더링되는 것이 아니라 통째로 복사되기 때문에 텍스트는 선택 가능한 상태로 유지되고, 벡터 그림은 선명하게 유지되며, 이미지는 원래 데이터를 유지해요. 완성된 문서는 자동으로 다운로드되고, 원본 파일은 기기에 건드려지지 않은 채로 남아 있어요.

실제 예시

6페이지 과제를 스캔했더니 페이지가 1, 3, 2, 6, 5, 4 순서로 나왔어요. 5페이지는 옆으로 되어 있고 끝에는 빈 스캐너 뚜껑 페이지가 있어요. 스캔을 여기에 넣고, 3페이지를 2페이지 뒤로 드래그하고, 마지막 세 페이지를 4, 5, 6 순서로 드래그하고, 옆으로 된 페이지에서 회전을 한 번 누르고, 빈 페이지를 삭제한 뒤 저장을 클릭하세요. 처음부터 끝까지 완벽하게 읽히는 깔끔한 6페이지 PDF 하나를 받아요.

일반적인 용도

  • 페이지 순서가 뒤죽박죽이거나 뒤집혀 나온 스캔을 고치는 데 좋아요.
  • 스캐너나 프린터가 추가한 빈 페이지를 제거하는 것이에요.
  • 요약이나 서명 페이지를 보고서의 앞이나 뒤로 이동하는 것이에요.
  • 신청서, 수료증, ID 사본을 사무실이 요청한 순서대로, 병합하거나 보내기 전에 한 번에 정리하는 것이에요.

자주 묻는 질문

정리하면 내 페이지의 품질이 바뀔까요?

아니에요. 페이지는 있는 그대로 새 문서에 정확히 복사돼요. 텍스트는 선택 가능한 상태로 유지되고 이미지는 원래 품질과 크기를 유지해요. 각 페이지는 자체 원래 페이지 크기도 유지해요.

페이지가 하나뿐인 PDF를 정리할 수 있나요?

네. 한 페이지 PDF는 정상적으로 열려요. 페이지가 옆으로 되어 있으면 회전하고 다시 저장할 수 있고, 그대로 두어도 돼요.

실수로 페이지를 삭제했어요. 되돌릴 수 있나요?

네. "순서 초기화"를 클릭하면 도구는 모든 페이지를 원래 순서로 복원해요. 기기의 원본 파일도 어느 쪽으로든 절대 바뀌지 않아서, 항상 그 파일에서 다시 시작할 수 있어요.

비밀번호로 보호된 PDF를 정리할 수 있나요?

아니에요. 열려면 비밀번호가 필요한 파일은 도구가 읽을 수 없어 오류를 표시해요. 먼저 파일을 만든 앱에서 비밀번호를 제거한 뒤 여기서 정리하세요.

인터넷 속도가 정리에 영향을 주나요?

아니에요. 이 페이지가 불러와지면 모든 작업은 기기의 메모리에서 일어나므로, 느린 연결에서도 정리가 그만큼 빨라요. 파일은 어디로도 이동하지 않아요.
