온라인으로 텍스트를 PDF로 변환 - 무료

요약하면: 텍스트를 PDF로 변환 도구는 입력하거나 붙여 넣은 텍스트를 제대로 서식이 적용된 PDF 문서로 만들어요. 글자 크기와 페이지 크기를 선택할 수 있고, 자동 줄바꿈과 페이지 나누기가 돼요.

메모, 에세이, 편지, 초안은 제출하거나 공유하려면 PDF가 되어야 하는 경우가 많아요. 여기에 텍스트를 붙여 넣고 글자 크기를 고르면 어떤 기기에서도 올바르게 보이는 깔끔한 여러 페이지 PDF를 받을 수 있어요.

설계부터 비공개: 파일은 JavaScript로 브라우저에서 100% 처리돼요. 서버에 절대 업로드되지 않고, 저장되지 않고, 우리가 볼 수 없어요. 탭을 닫으면 모든 것이 사라져요.

텍스트를 PDF로 변환하는 방법

  1. 상자에 텍스트를 입력하거나 붙여 넣으세요.
  2. 글자 크기와 페이지 크기(A4 또는 Letter)를 선택하세요.
  3. "PDF 만들기"를 클릭하세요. 긴 텍스트는 필요한 만큼 여러 페이지에 걸쳐 흘러요.

자주 묻는 질문

어떤 글꼴이 사용되나요?

PDF는 Helvetica를 사용해요. 추가 다운로드 없이 모든 PDF 리더가 올바르게 표시하는 깔끔한 내장 글꼴이에요.

우르두어나 아랍어 문자로 쓸 수 있나요?

표준 PDF 글꼴에는 우르두어/아랍어 글리프가 포함되어 있지 않아서, 이 도구에서는 오른쪽에서 왼쪽으로 쓰는 문자가 지원되지 않아요. 라틴 문자 언어는 완전히 작동해요.

내 텍스트가 어디에든 저장되나요?

아니에요. PDF는 브라우저에서 생성되고 텍스트는 탭을 닫으면 사라져요.

나중에 페이지 번호를 추가할 수 있나요?

네 — 결과를 페이지 번호 추가 도구로 실행해 좋아하는 스타일로 번호를 찍으세요.

작동 방식

일반 텍스트를 입력하거나 붙여 넣으면 도구가 pdf-lib를 사용해 브라우저에서 PDF로 조판해요. 내장 Helvetica 글꼴로 모든 단어를 측정하고 선택한 페이지 크기(A4 또는 Letter, 약 2 cm의 고정 여백과 글자 크기의 1.4배인 편안한 줄 간격)의 텍스트 영역에 맞게 줄을 바꿔요. 텍스트의 빈 줄은 단락 간격으로 유지되고, 페이지가 가득 차면 텍스트는 모든 것이 배치될 때까지 다음 페이지로 흘러요. 글자 크기(10부터 16 pt까지)와 파일 이름을 고르면 완성된 PDF가 즉시 다운로드되고, 텍스트는 기기를 절대 떠나지 않아요.

실제 예시

학생이 노트 앱에서 900단어 에세이를 완성하고 PDF로 제출해야 해요. 텍스트를 붙여 넣고 기본값을 그대로 유지해요 12 pt 위에 A4파일 이름을 english-essay.pdf인 확인란을 추가하고 PDF 만들기를 클릭해요. 에세이는 단락이 그대로 유지된 채 3페이지에 깔끔하게 나뉘어 나와서 학급 포털에 바로 올릴 수 있어요.

자주 묻는 질문

제목을 굵게 하거나 글꼴을 바꿀 수 있나요?

아니에요. 도구는 선택한 한 가지 크기의 Helvetica로 깔끔하고 균일한 일반 텍스트를 만들어요. 굵게, 기울임, 제목, 글꼴 제어가 없어요. 스타일이 적용된 문서는 워드 프로세서에서 작성하고 그 PDF를 내보내세요.

텍스트를 얼마나 붙여 넣을 수 있나요?

도구에는 고정된 문자나 페이지 제한이 없어요. 텍스트는 필요한 만큼 여러 페이지에 걸쳐 흘러요. PDF는 기기에서 로컬로 만들어지므로 전체 챕터나 긴 보고서도 괜찮아요.

내 단락 구분이 유지되나요?

네. 입력한 각 줄 바꿈은 새 줄을 시작하고, 빈 줄은 보이는 간격이 되어, 단락은 쓴 그대로 정확히 분리된 상태로 유지돼요. 단어는 한 단어가 전체 페이지 너비보다 길지 않는 한 줄 중간에 절대 끊기지 않아요.

여백이나 줄 간격을 조정할 수 있나요?

이 도구에서는 아니에요. 여백은 모든 면에서 약 2 cm(56 포인트)로 고정되고 줄 간격은 글자 크기의 1.4배로 고정돼요. 대부분의 에세이, 편지, 과제에 맞게 선택한 값이에요.

어떤 특수 문자가 작동하나요?

é, ü, ñ 같은 강세 문자와 유로 기호 같은 기호를 포함한 일반적인 라틴 문자 문자는 내장 글꼴로 올바르게 그려져요. 우르두어, 아랍어나 중국어 같은 문자의 문자는 표준 PDF 글꼴로 그릴 수 없어 지원되지 않아요.

나중에 PDF 텍스트를 편집할 수 있나요?

PDF에는 실제 선택 가능한 텍스트가 들어 있어 어떤 PDF 편집기로도 나중에 바꿀 수 있어요. 가장 간단한 방법은 원본 텍스트를 유지하고, 그것을 편집한 뒤, 여기서 새 PDF를 만드는 것이에요. 몇 초면 돼요.
