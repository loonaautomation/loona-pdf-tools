Loona PDF Editor

요약: Loona PDF Editor를 사용하면 모든 PDF 페이지 위에 텍스트, 이미지, 도형, 형광펜 표시를 추가하고, 실수를 화이트아웃으로 가리고, 자유롭게 그리고, 그리거나 입력한 서명을 배치한 뒤 완성된 파일을 다운로드할 수 있어요. 콘텐츠를 추가하고 가리는 도구이며, PDF의 원본 텍스트를 다시 쓰지는 않아요.

양식에 메모를 추가하거나, 송장의 합계를 정정하거나, 로고를 배치하거나, 편지에 서명해야 하나요 — 인쇄하고 스캔할 필요 없이요? 여기서 PDF를 열고, 필요한 것을 페이지에 직접 추가한 뒤 완성된 파일을 다운로드하세요. 모든 작업은 기기에서 이뤄져요: 업로드 없음, 가입 없음, 페이지 제한 없음, 워터마크 없음.

페이지에서 사용하는 방법: 도구를 선택한 뒤 아래 페이지를 클릭하거나 드래그하세요. 텍스트 도구로는 텍스트가 시작될 위치를 클릭하거나 텍스트 추가 버튼을 사용하세요. 사각형, 형광펜, 화이트아웃은 드래그해서 그려요. 선택 도구로 요소를 클릭하면 이동할 수 있고, 금색 모서리를 드래그하면 크기를 조정하거나 삭제할 수 있어요. 요소는 페이지마다 따로 기억돼요.

추가한 요소

서명 추가하기

패드에 서명을 그리거나 이름을 입력하면 서명 이미지로 만들어 드려요. 서명은 현재 페이지에 이동할 수 있는 이미지로 배치돼요.

프라이버시 설계: 파일은 JavaScript로 브라우저 안에서 100% 처리돼요. 서버에 업로드되지 않고, 저장되지 않으며, 저희가 보지도 않아요 - 탭을 닫으면 모든 것이 사라져요.

PDF 편집 방법

  1. 위 상자를 클릭하고 PDF를 선택하세요. 파일이 브라우저 안에서 바로 열려요 — 아무것도 업로드되지 않아요.
  2. 도구를 선택하세요: 텍스트, 사각형, 형광펜, 화이트아웃, 그리기 — 또는 이미지나 서명을 추가하세요.
  3. 페이지를 클릭하거나 드래그해서 요소를 배치하세요. 선택 도구로 이동하고, 금색 모서리를 드래그해 크기를 조정하거나, 마음이 바뀌면 삭제하세요.
  4. 이전 / 다음 버튼이나 페이지 드롭다운으로 페이지를 오가세요. 각 페이지가 자체 요소를 유지하므로 긴 문서도 페이지별로 편집할 수 있어요.
  5. 모든 것이 괜찮으면 "편집한 PDF 내보내기"를 클릭하세요. 추가한 내용이 원본 페이지에 평탄화되고 완성된 파일이 파일명-edited.pdf로 다운로드돼요.

이 편집기가 할 수 있는 것과 할 수 없는 것

이것은 오버레이 편집기이며, 그 의미가 무엇인지 나중에 알게 하기보다 솔직하게 알려 드리고 싶어요.

할 수 있는 것

  • 새 텍스트 추가 — 페이지 어디에든, 다섯 가지 고전 글꼴(Helvetica, Helvetica Bold, Times, Times Bold, Courier)로, 원하는 크기와 색상으로 추가할 수 있어요.
  • 이미지 추가 — 로고, 도장, 사진 — 그리고 마우스나 손가락으로 서명을 그리거나 이름을 입력해 배치할 수 있어요.
  • 사각형과 형광펜을 그어 문서에 표시하고, 펜 도구로 자유롭게 그릴 수 있어요.
  • 실수를 화이트아웃으로 가리기: 잘못된 단어나 숫자 위에 불투명한 블록을 그리고 그 위에 정정한 내용을 입력하세요.
  • 추가한 모든 것은 어느 페이지에서든 이동, 크기 조정, 삭제할 수 있고, 평탄화된 완성 PDF 하나를 내보낼 수 있어요.

할 수 없는 것

  • 워드 프로세서처럼 PDF의 원본 텍스트를 바꾸거나, 이동하거나, 재배열하지 않아요. 파일에 이미 있는 단어는 정확히 그 자리에 그대로 남아 있어요.
  • 오타를 고치려면 잘못된 단어를 화이트아웃으로 가리고 그 위에 정정한 내용을 입력하세요 — 이것이 솔직한 우회 방법이며, 양식, 송장, 편지에는 아주 잘 맞아요.
  • 여기의 화이트아웃은 시각적인 덮개예요: 가려진 내용은 블록 아래 파일 안에 여전히 남아 있어요. 공유하기 전에 민감한 내용을 영구적으로 제거해야 한다면, 대신 PDF 가리기(레닥션) 도구를 사용하세요. 상자를 다시 만든 페이지 이미지에 구워 넣어요.
  • 비밀번호로 보호된 PDF는 열 수 없고, 양식 채우기 도구도 아니에요 — 기존 양식 입력란에는 PDF 양식 채우기를 사용하세요.

프라이버시 — 파일은 기기를 떠나지 않아요

열기, 렌더링, 편집, 내보내기의 모든 단계가 JavaScript로 브라우저 안에서 100% 실행돼요(PDF.js가 페이지를 렌더링하고 pdf-lib가 완성 파일을 작성해요). PDF는 서버에 업로드되지 않고, 저장되지 않으며, 저희가 보지도 않고, 작업하는 동안 편집기 자체도 네트워크 요청을 하지 않아요. 탭을 닫으면 모든 것이 사라져요. 가입도, 페이지 제한도, 워터마크도 없어요.

자주 묻는 질문

PDF의 원본 단어를 바꿀 수 있나요?

아니요. Loona PDF Editor는 페이지 위에 콘텐츠를 추가하고 가리는 도구로, 파일에 이미 있는 텍스트를 다시 쓰거나, 이동하거나, 재배열할 수 없어요. 잘못된 단어를 고치려면 그 위에 화이트아웃 블록을 그리고 그 위에 정정한 내용을 입력하세요 — 시각적으로는 페이지가 원하는 대로 정확히 읽혀요.

이 편집기로 PDF의 오타를 어떻게 고치나요?

화이트아웃 도구를 선택하고 잘못된 단어 위에 블록을 드래그하세요. 그런 다음 텍스트 도구(또는 텍스트 추가 버튼)를 선택하고 어울리는 글꼴과 크기로 정정한 단어를 입력한 뒤 화이트아웃 위 제자리로 드래그하세요. 내보내면 완성된 페이지에는 정정한 내용만 보여요.

제 PDF가 서버에 업로드되나요?

아니요. 편집기는 전적으로 브라우저 안에서 실행돼요: PDF.js가 화면에 페이지를 그리고 pdf-lib가 기기에서 완성 파일을 만들어요. 아무것도 업로드되거나, 저장되거나, 저희가 보지 않으며 가입도 필요 없어요.

Loona PDF Editor는 정말 무료인가요?

네 — 가입 없이 무료이고, 페이지 제한도 없으며, 내보낸 파일에 워터마크도 없어요. 원하는 만큼 얼마든지 PDF를 편집할 수 있어요.

이 편집기로 PDF에 서명할 수 있나요?

네. "서명 추가"를 클릭하고 마우스나 손가락으로 패드에 서명을 그리거나 — 이름을 입력해 서명 이미지로 바꾼 뒤 — 현재 페이지에 이동하고 크기를 조정할 수 있는 이미지로 배치하세요. 이것은 시각적인 서명이며 인증서 기반 전자 서명은 아니에요. 서명 전용 작업에는 전용 PDF 서명 도구도 사용할 수 있어요.

화이트아웃은 가린 것을 영구적으로 제거하나요?

아니요, 그렇지 않은 척하지 않을게요. 화이트아웃은 콘텐츠 위에 불투명한 덮개를 그려서 더 이상 보이거나 인쇄되지 않게 하지만 — 원본 내용은 파일 안 아래쪽에 여전히 남아 있어요. 내용이 민감해서 완전히 없애야 한다면, 각 페이지를 이미지로 다시 만들고 상자를 구워 넣는 PDF 가리기(레닥션) 도구를 사용하세요.

추가하는 텍스트에 어떤 글꼴을 쓸 수 있나요?

다섯 가지 표준 PDF 글꼴: Helvetica, Helvetica Bold, Times, Times Bold, Courier를 원하는 크기와 색상으로 쓸 수 있어요. 이 글꼴들은 모든 PDF 리더에 내장되어 있어서, 추가한 텍스트가 파일 크기를 키우지 않고 어디에서든 올바르게 표시돼요.

추가한 요소가 제자리에 그대로 있을까요?

네. 요소는 화면 픽셀이 아니라 실제 PDF 좌표(포인트)로 페이지별로 저장되기 때문에, 파일을 내보내면 각 요소가 페이지 크기와 관계없이 배치한 정확한 위치, 크기, 순서로 페이지에 그려져요.

PDF 병합

작동 방식

파일을 열면 PDF.js가 현재 페이지를 브라우저의 캔버스에 렌더링해요. 추가하는 모든 것 — 텍스트 상자, 이미지, 사각형, 형광펜, 화이트아웃 블록, 자유 곡선, 서명 — 은 그 캔버스 위의 투명한 레이어에 그려지고, 포인트 단위의 실제 PDF 좌표로 그 페이지에 저장돼요. 페이지를 바꿔도 요소가 섞이지 않아요: 각 페이지가 추가한 순서대로 자체 목록을 유지해요. 내보낼 때 pdf-lib는 원본 파일을 열고 같은 좌표로 모든 요소를 그 페이지에 그리며, 화면의 위에서 아래 위치를 PDF 자체 좌표계로 변환한 뒤 이름에 -edited를 붙여 결과를 저장해요. 원본 페이지가 유지되고 추가한 것만 위에 그려지기 때문에, 출력은 페이지를 그림으로 다시 만드는 도구와 달리 실제 선택 가능한 텍스트 PDF로 남아요.

실제 예시

송장 PDF에 잘못된 합계 "Rs 4,500"이 표시되어 있고 사업 로고가 없어요. 기존 합계 위에 화이트아웃 블록을 드래그하고, 그 위에 Helvetica Bold로 "Rs 5,400" 텍스트를 추가하고, 페이지 맨 위에 로고 이미지를 배치하고, 서명 상자에 이름을 입력해 아래쪽에 서명하세요. 편집한 PDF 내보내기를 한 번 클릭하면 invoice-edited.pdf가 다운로드돼요 — 정정되고, 브랜드가 입혀지고, 서명까지 완료되며 송장의 나머지는 그대로예요.
