온라인으로 PDF 정보(메타데이터) 편집 - 무료

요약하면: PDF 정보 편집 도구는 PDF의 숨은 메타데이터(제목, 작성자, 주제, 키워드, 만든 프로그램, 제작자)를 표시하고, 사본을 저장하기 전에 제목, 작성자, 주제, 키워드를 바꿀 수 있게 해요.

모든 PDF에는 숨은 정보가 있어요: 브라우저 탭과 검색 결과에 표시되는 제목, 작성자 이름 등이에요. 스캔이나 내보내기로 만든 파일은 값이 틀리거나 비어 있는 경우가 많아요. 공유하기 전에 여기서 확인하고 고치세요.

클릭해서 PDF 파일을 선택하세요
또는 여기에 끌어다 놓으세요
설계부터 비공개: 파일은 JavaScript로 브라우저에서 100% 처리돼요. 서버에 절대 업로드되지 않고, 저장되지 않고, 우리가 볼 수 없어요. 탭을 닫으면 모든 것이 사라져요.

PDF 메타데이터를 편집하는 방법

  1. PDF를 선택하세요. 현재 메타데이터가 요약 표에 나타나요.
  2. 제목, 작성자, 주제, 키워드 입력란을 편집하세요.
  3. "새 정보로 PDF 저장"을 클릭하고 업데이트된 사본을 다운로드하세요.

자주 묻는 질문

PDF 메타데이터는 무엇인가요?

파일 안에 저장된 설명 정보예요. 제목, 작성자, 주제, 키워드로, 리더, 검색 엔진, 문서 시스템이 파일을 표시하는 데 사용해요.

메타데이터 편집이 페이지를 바꾸나요?

아니에요. 정보 입력란만 바뀌어요. 페이지 내용은 건드려지지 않아요.

제목이 중요한 이유는 무엇인가요?

메타데이터 제목은 브라우저 탭, PDF 리더 제목 표시줄, 많은 검색 결과에 나타나는 것이에요. 분명한 제목은 문서를 전문적으로 보이게 해요.

작성자 이름을 제거할 수 있나요?

네. 입력란을 지우고 저장하세요. 저장된 사본은 빈 작성자 값을 가져요.

작동 방식

파일을 선택하면 도구는 pdf-lib로 브라우저 안에서 현재 문서 정보를 읽어요. 아무것도 업로드되지 않아요. 그리고 파일에 이미 저장된 제목, 작성자, 주제, 키워드, 만든 프로그램, 제작자를 보여 줘요. 제목, 작성자, 주제, 키워드 상자는 편집을 위해 그 값으로 미리 채워져 있어요. 저장할 때 도구는 새 값을 문서 정보에 쓰고, 수정 날짜를 오늘로 새로 고친 뒤, 이름에 -updated가 붙은 결과를 다운로드해요. 숨은 정보만 바뀌어요. 단 한 페이지도 건드려지지 않아요.

실제 예시

다운로드한 배포 자료 이름은 scan_2026.pdf이고 속성에는 제목이 없고 제작자가 스캐너 프로그램으로 표시돼요. 제목을 'Physics Notes - Chapter 4'로, 작성자를 본인 이름으로, 주제를 'Class 10 Physics'로, 키워드를 'physics, notes, chapter 4'로 설정하세요. 업데이트된 파일은 이제 리더의 제목 표시줄과 속성 패널에 'Physics Notes - Chapter 4'를 표시해서 학생들이 한눈에 알아볼 수 있어요.

자주 묻는 질문

여기서 실제로 편집할 수 있는 입력란은 무엇인가요?

제목, 작성자, 주제, 키워드예요. 만든 프로그램과 제작자는 파일이 현재 무엇을 가졌는지 볼 수 있도록 표시되지만, 이 도구에서는 표시 전용이에요. 그것이 무엇을 바꾸는지에 대한 솔직한 제한이에요.

키워드는 어떻게 입력해야 하나요?

상자에 표시된 그대로 쉼표로 구분하세요. 예를 들어 'invoice, 2026, office'예요. 도구는 저장할 때 여분의 공백과 빈 항목을 정리해 줘요.

수정 날짜도 바뀌나요?

네. 저장은 문서에 현재 날짜와 시간을 수정 날짜로 찍어요. 파일 정보가 업데이트될 때 대부분의 데스크톱 편집기가 하는 것과 일치해요.

새 제목은 어디에서 볼 수 있나요?

어떤 PDF 리더에서든 파일을 열고 문서 속성을 확인하세요. 대부분의 리더는 원시 파일 이름 대신 창이나 탭에 문서 제목을 표시하고, 검색 도구는 파일을 색인할 때 그것을 사용해요.

비밀번호로 보호된 PDF의 정보를 편집할 수 있나요?

아니에요. 정보를 읽고 다시 쓰려면 파일을 열 수 있어야 하며, 보호된 파일은 오류를 표시해요. 먼저 파일을 만든 앱에서 비밀번호를 제거하세요.
