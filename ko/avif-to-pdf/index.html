AVIF를 PDF로 변환하는 도구

요약하면: 이 도구는 AVIF 이미지를 깔끔한 PDF로 변환해요 — 페이지당 이미지 하나, 전적으로 브라우저에서요.

최신 휴대폰의 AVIF 사진은 많은 양식, 오래된 앱, 일부 포털에서 열리지 않아요. PDF로 변환하면 어디에든 제출할 수 있게 돼요.

클릭해서 AVIF 이미지를 선택하세요
또는 여기에 끌어다 놓으세요 — 여러 파일은 순서대로 여러 페이지가 돼요
설계부터 비공개: 파일은 JavaScript로 브라우저에서 100% 처리돼요. 서버에 절대 업로드되지 않고, 저장되지 않고, 우리가 볼 수 없어요. 탭을 닫으면 모든 것이 사라져요.

단계별 작동 방식

  1. AVIF 이미지를 하나 이상 선택하세요.
  2. 맞춤, A4 또는 Letter 페이지를 고르세요.
  3. 변환을 누르고 PDF를 다운로드하세요.

자주 묻는 질문

AVIF를 PDF로 어떻게 변환하나요?

위에서 AVIF 파일을 하나 이상 선택하고 페이지 크기를 고른 뒤 변환을 누르세요. 각 이미지는 선택한 순서대로 하나의 PDF의 한 페이지가 돼요.

품질이 바뀔까요?

AVIF 디코딩에는 최신 브라우저가 필요해요(Chrome, Edge, Safari 16+; Firefox도 지원해요). 도구는 각 AVIF를 디코딩해 PDF에 JPEG로 저장해요. 브라우저가 AVIF를 디코딩할 수 없으면 분명하게 알려 줘요.

페이지 순서를 바꿀 수 있나요?

파일은 선택한 순서대로 추가돼요. 순서와 레이아웃을 완전히 제어하려면 여기서 변환한 뒤 PDF 정리 도구로 페이지를 재배열하세요.

무엇이든 업로드되나요?

아니에요 — 디코딩과 PDF 만들기는 pdf-lib로 브라우저에서 일어나요.

내부 구조

브라우저는 각 AVIF 이미지를 기본으로 디코딩해 캔버스에 그리고, pdf-lib가 페이지로 삽입해요 — 이미지에 맞춘 페이지는 이미지 자체의 비율(96 DPI)을 사용하거나, 이미지는 여백이 유지된 채 A4/Letter에 가운데 배치돼요.

실제 예시

함께 선택한 채팅 지원 대화의 AVIF 스크린샷 세 개는 티켓에 첨부할 수 있는 깔끔한 3페이지 PDF가 돼요 — 원본 형식과 달리 어떤 포털도 거부하지 않아요.
