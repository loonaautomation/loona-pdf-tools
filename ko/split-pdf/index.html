온라인으로 PDF 분할 - 무료

요약하면: PDF 분할 도구는 하나의 PDF를 더 작은 파일로 분리해요. 페이지당 파일 하나, 또는 입력한 각 페이지 범위마다 파일 하나예요. 예를 들어 1-3과 4-6이에요.

긴 문서의 몇 페이지만 보내야 하나요? 여기서 분할하세요: 모든 페이지를 자체 PDF로 만들거나, 범위를 정의해 범위당 깔끔한 파일 하나를 받으세요. 공유, 인쇄, 보관할 준비가 돼요.

클릭해서 PDF 파일을 선택하세요
또는 여기에 끌어다 놓으세요
설계부터 비공개: 파일은 JavaScript로 브라우저에서 100% 처리돼요. 서버에 절대 업로드되지 않고, 저장되지 않고, 우리가 볼 수 없어요. 탭을 닫으면 모든 것이 사라져요.

PDF를 분할하는 방법

  1. 위 상자로 PDF 파일을 선택하세요. 페이지 수가 자동으로 나타나요.
  2. "모든 페이지를 별도 파일로" 또는 "범위로 분할"을 고르고 필요하면 1-3, 4-6 같은 범위를 입력하세요.
  3. "PDF 분할"을 클릭하고 나타나는 링크에서 각 새 파일을 다운로드하세요.

자주 묻는 질문

두 분할 모드의 차이는 무엇인가요?

첫 번째 모드는 페이지당 PDF 하나를 만들어요. 범위 모드는 입력한 각 범위마다 PDF 하나를 만들어요. 예를 들어 1-3, 4-6, 7-10이에요.

내 파일이 어디에든 업로드되나요?

아니에요. 분할은 전적으로 브라우저에서 실행되어 문서는 기기에 남아요.

분할하면 품질이 낮아지나요?

아니에요. 페이지는 정확히 복사돼요. 다시 렌더링되거나 압축되지 않아요.

비밀번호로 보호된 PDF를 분할할 수 있나요?

보호된 파일은 페이지 복사를 막으므로 먼저 PDF 리더에서 비밀번호로 잠금을 풀어야 해요.

작동 방식

여기서 분할하면 페이지를 다시 그리는 일은 절대 없어요. 도구는 pdf-lib로 PDF를 로컬에서 불러와, 각 출력 파일마다 문서의 완전한 사본을 가져와 그 부분에 속하지 않는 모든 페이지를 제거해요. 그래서 남는 페이지는 비트 단위로 원본이며, 텍스트, 이미지, 품질이 건드려지지 않아요. '모든 페이지' 모드에서는 페이지당 부분 하나가 있고, 범위 모드에서는 입력한 각 범위(예: 1-3 또는 4-6)가 부분 하나가 돼요. 부분은 다음으로 저장돼요 yourfile-part1.pdf, yourfile-part2.pdf 와 같은 방식으로, 각각 자체 다운로드 링크가 있어요. 아무것도 업로드되지 않아요. 사본은 브라우저에서 만들어져요.

실제 예시

교사는 40페이지 과정 리더 PDF가 있지만 학급에는 세 덩어리로만 필요해요. 다음을 선택해요 페이지 범위로 분할 그리고 입력해요 1-10, 11-25, 26-40. 링크 세 개가 나타나요 - reader-part1.pdf 처음 열 페이지와 함께, reader-part2.pdf 그리고 reader-part3.pdf - 그래서 전체 대용량 파일 대신 매주 한 부분씩 공유해요.

자주 묻는 질문

모든 부분을 ZIP 파일 하나로 받나요?

아니에요. 각 부분은 자체 다운로드 링크로 나타나 따로 저장돼요. ZIP 옵션은 없어요. 각 링크를 차례로 클릭하세요. 브라우저가 여러 파일 다운로드 허가를 물을 수 있어요.

같은 페이지가 여러 부분에 나타날 수 있나요?

네. 모든 범위는 원본 문서에서 독립적으로 복사되어, 범위는 자유롭게 겹칠 수 있어요. 범위가 그렇게 말하면 5페이지가 부분 1과 부분 2 모두에 있을 수 있어요.

2, 5, 9페이지를 한 파일로 가져올 수 있나요?

직접은 아니에요: 범위 모드에서는 쉼표로 구분된 각 항목이 자체 파일이 되어 2, 5, 9는 한 페이지짜리 PDF 세 개를 제공해요. 별도 페이지를 하나의 문서로 결합하려면 먼저 분할한 뒤 PDF 병합 도구로 합치세요.

출력 파일 이름은 무엇인가요?

그것들은 원본 파일의 이름을 유지하고 다음이 붙어요 부분 그리고 숫자가 추가돼요: 분할 중이에요 contract.pdf 제공해요 contract-part1.pdf, contract-part2.pdf와 같은 방식으로, 지정한 범위의 순서대로 이어져요.

스캔한 PDF를 분할할 수 있나요?

네. 분할은 내용을 읽지 않고 전체 페이지를 있는 그대로 정확히 복사해서, 스캔 및 이미지만 있는 문서도 텍스트 문서만큼 잘 분할돼요.

부분들의 합이 원본 파일 크기와 같아질까요?

보통 전체적으로 조금 더 많아요: 글꼴 같은 공유 항목은 각 부분 파일 안에 저장되어, 여러 부분으로 분할된 문서는 일부 오버헤드를 중복해요. 각 개별 부분은 여전히 원본보다 훨씬 작아요.
