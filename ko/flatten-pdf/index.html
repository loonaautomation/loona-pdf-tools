온라인으로 PDF 평탄화 - 무료

요약하면: PDF 평탄화 도구는 PDF를 최종본으로 만들어요: 입력 가능한 양식 입력란을 페이지 자체에 구워 넣어 답변이 보이는 그대로 인쇄되고 더 이상 입력할 수 없게 하고, 선택적인 이미지 모드는 모든 페이지를 그림으로 다시 만들어 그 위의 모든 것을 평탄화해요.

작성한 양식을 그대로 보내면 그것을 여는 누구나 답변을 편집할 수 있어요. 평탄화는 인쇄가 하는 것처럼 문서를 잠가요. 보이는 것이 모두가 영구적으로 받는 것이에요.

이 도구 사용법

  1. PDF를 선택하세요. 도구가 양식 입력란이 몇 개인지 알려 줘요.
  2. 일반적인 최종 사본을 위해서는 양식 입력란 평탄화에 표시해 두고, 도장, 메모, 레이어까지 모든 것을 평탄화해야 할 때는 이미지 모드를 추가하세요.
  3. 평탄화 및 다운로드를 클릭하고 잠긴 사본을 공유하세요. 편집 가능한 원본은 안전한 곳에 보관하세요.

자주 묻는 질문

평탄화는 실제로 양식 입력란에 무엇을 하나요?

각 입력란의 현재 답변은 일반 페이지 내용으로 페이지에 그려지고, 입력란 자체는 삭제돼요. 그러면 문서는 입력 가능한 입력란이 전혀 없이 열려요. 답변은 읽고 인쇄할 수 있지만 양식 데이터로 편집할 수는 없어요.

PDF에 양식 입력란이 없으면 평탄화가 아무것도 하지 않나요?

양식 평탄화만으로는 아무것도 바뀌지 않아요(도구가 처음에 입력란 개수를 알려 줘서 놀랄 일이 없어요). 이미지 모드는 여전히 페이지를 다시 만들어 주석과 레이어를 평탄화하고 텍스트 레이어를 제거해요.

주석과 도장이 평탄화될까요?

표준 양식 평탄화 모드에서는 양식 입력란이 평탄화돼요. 일부 별도 주석은 남을 수 있어요. 이미지 모드는 페이지가 하나의 그림이 되기 때문에 각 페이지에 보이는 모든 것을 평탄화해요.

평탄화을 취소할 수 있나요?

아니에요. 그것이 바로 목적이에요. 나중에 답변을 바꿔야 할 수도 있으면 평탄화하지 않은 원본을 항상 보관하세요.

작동 방식

양식 평탄화를 위해 도구는 pdf-lib로 PDF를 열어 모든 입력란의 모양을 새로 고쳐 현재 답변이 올바르게 그려지게 한 뒤, 라이브러리의 평탄화 작업을 호출해요: 입력란 모양이 페이지 내용 스트림에 병합되고 양식 정의가 제거돼요. 이미지 모드에서는 대신 각 페이지가 PDF.js로 2x 해상도로 렌더링되어 새 PDF에 JPEG 페이지 이미지로 다시 만들어져요. PDF 가리기 도구와 같은 구워 넣기 방식이라, 상호작용 여부와 관계없이 보이는 모든 요소가 하나의 평평한 그림의 일부가 돼요. 둘 다 전적으로 브라우저에서 실행돼요.

실제 예시

학부모가 PDF 양식 채우기 도구로 입학 신청서를 작성한 뒤, 학교에 이메일로 보내기 전에 여기서 평탄화해요. 학교는 모든 답변을 읽고 인쇄할 수 있지만, 받은 파일에서 아무도 몰래 전화번호를 바꾸거나 다른 칸에 표시할 수 없어요.

자주 묻는 질문

평탄화된 PDF는 동일하게 인쇄되나요?

네. 평탄화하기 전에 도구는 각 입력란의 모양을 새로 고쳐서 보이는 값이 페이지에 구워지는 값이 돼요. 인쇄물은 화면과 일치해요.

평탄화하면 파일이 작아지나요?

양식 평탄화는 보통 크기를 거의 바꾸지 않아요. 이미지 모드는 페이지가 2x JPEG 이미지로 저장되기 때문에 보통 파일이 더 커져요.

일부 도구에서 평탄화한 뒤 입력란 답변이 누락되어 보일 수 있는 이유는 무엇인가요?

잘못 만들어진 일부 양식은 값을 저장하지만 보이는 모양이 없어요. 이 도구는 평탄화하기 전에 pdf-lib로 모양을 다시 생성해서 그런 경우의 대부분을 고쳐요. 값이 애초에 저장된 적이 없으면 구워 넣을 것이 없어요.

평탄화한 뒤에도 텍스트는 선택 가능한가요?

양식을 평탄화한 뒤에도 일반 페이지 텍스트는 선택할 수 있어요. 입력란만 고정된 내용이 돼요. 이미지 모드에서는 페이지가 그림이라 아무것도 선택할 수 없어요.

이미지 모드는 언제 선택해야 하나요?

문서에 스티키 노트, 강조 표시, 도장, 또는 보이는 그대로 잠가야 하는 겹친 그래픽이 있거나, 받는 시스템이 상호작용 요소를 포함한 파일을 거부할 때예요.
