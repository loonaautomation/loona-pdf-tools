온라인으로 PDF 페이지 크기 조정 - 무료

요약하면: PDF 페이지 크기 조정 도구는 전체 PDF의 페이지 크기를 바꿔요. 예를 들어 A4를 US Letter로 또는 Letter를 A4로요. 각 페이지의 내용을 비례적으로 조정해 새 용지에 맞추고 가운데에 배치해서, 해외 문서가 지역 용지에 올바르게 인쇄돼요.

US Letter용으로 디자인된 양식은 A4에 깔끔하게 인쇄되는 경우가 드물고, 반대도 마찬가지예요. 프린터 배율과 씨름하는 대신 문서 자체를 변환하세요. 목표 용지 크기를 한 번 선택하면 모든 페이지가 정확히 그 크기로 다시 만들어져요.

이 도구 사용법

  1. 크기를 조정할 PDF를 선택하세요.
  2. 새 페이지 크기를 고르세요. A4와 US Letter가 대부분의 필요를 충족해요.
  3. 잘리는 것이 없도록 맞추기를 선택한 뒤, 다운로드해 100% / 실제 크기로 인쇄하세요.

자주 묻는 질문

내 내용이 왜곡될까요?

아니에요. 내용은 항상 비례적으로 조정돼요. 가로와 세로에 같은 비율로, 그리고 가운데에 배치돼요. 맞추기에서는 종횡비가 다르면 양쪽에 얇은 여백이 나타날 수 있어요. 늘어나거나 잘리는 것은 없어요.

채우기는 무엇이 다른가요?

채우기는 새 용지가 완전히 덮일 때까지 조정하는데, 가장자리의 내용이 페이지 밖으로 밀려날 수 있어요. 양식이나 편지가 아닌 전면 작품에 적합해요.

크기 조정하면 텍스트 품질이 바뀌나요?

아니에요. 페이지는 원래 벡터 내용으로 삽입되어 조정되어 그려져요. 이미지 기반 변환과 달리 텍스트가 선명하고 선택 가능한 상태로 유지돼요.

A4인가 Letter인가 - 내 프린터에는 무엇이 필요한가요?

세계 대부분은 A4를 사용하고, 미국과 캐나다는 Letter를 사용해요. 문서가 해외에서 인쇄될 예정이면 먼저 그 지역의 크기로 변환하세요.

작동 방식

도구는 pdf-lib로 PDF를 불러와 각 원본 페이지를 재사용 가능한 객체로 삽입하고, 목표 치수로 새 페이지를 만들어요. 하나의 비례 배율(맞춤 또는 채우기)을 계산하고, 삽입된 페이지를 새 용지에 가운데에 두고 한 번 그려요. 원본 페이지는 다시 렌더링되는 것이 아니라 삽입되기 때문에 글꼴, 벡터, 이미지는 어떤 크기에서도 원래 품질을 유지해요.

실제 예시

미국 공급업체가 Letter 크기 가격표를 보내지만 사무실에는 A4만 있어요. A4에 맞추기로 변환하고 실제 크기로 인쇄하면 여백이 올바른 깨끗한 사본이 나와요. 잘린 가격도, 작은 "용지에 맞추기" 글자도 없어요.

자주 묻는 질문

조정된 내용은 얼마나 큰가요?

맞추기에서는 배율 계수가 (새 너비 / 기존 너비)와 (새 높이 / 기존 높이) 중 더 작은 쪽이라서 전체 원본 페이지가 항상 맞아요. 도구는 전후 크기를 알려 줘요.

예를 들어 A5를 A4로 문서를 확대할 수 있나요?

네 — 더 큰 목표 크기를 선택하세요. 벡터 텍스트와 선 그림은 선명하게 유지돼요. 스캔 이미지는 원래 스캔 해상도에 의해 제한돼요.

'내용만 조정'은 무엇을 하나요?

원래 페이지 크기는 유지하지만 선택한 백분율로 내용을 가운데에 그려요. 제본용 안전 여백을 만들거나 프린터 가장자리 제한에서 내용을 줄이는 데 편리해요.

양식 입력란은 크기 조정을 견딜까요?

페이지는 삽입된 페이지 내용으로 다시 만들어져 상호작용 양식 입력란, 북마크, 링크는 이어지지 않아요. 문서의 평평한 최종 버전을 조정하거나, PDF 양식 만들기 도구로 입력란을 추가하기 전에 크기를 조정하세요.
