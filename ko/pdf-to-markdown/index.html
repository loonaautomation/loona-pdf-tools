PDF를 Markdown으로 변환하는 도구

요약하면: 이 도구는 PDF의 텍스트를 추출하고 제목이 글자 크기에서 감지되는 구조화된 Markdown으로 다시 만들어요 — 브라우저에서요.

PDF는 재사용이 아닌 읽기를 위한 것이에요. 이 변환기는 다운로드하기 전에 솔직한 편집 단계를 거쳐, 편집, 게시, 다른 곳에 붙여 넣을 수 있는 Markdown으로 텍스트를 복구해요.

클릭해서 PDF 파일을 선택하세요
또는 여기에 끌어다 놓으세요 — 텍스트 기반 PDF가 가장 잘 작동해요
설계부터 비공개: 파일은 JavaScript로 브라우저에서 100% 처리돼요. 서버에 절대 업로드되지 않고, 저장되지 않고, 우리가 볼 수 없어요. 탭을 닫으면 모든 것이 사라져요.

단계별 작동 방식

  1. 텍스트 기반 PDF를 선택하세요.
  2. 편집기에서 추출된 Markdown을 검토하세요 — 변환기가 잘못 읽은 줄이 있으면 고치세요.
  3. 완성된 파일을 다운로드하세요.

자주 묻는 질문

여기서 PDF를 Markdown으로 변환하는 것은 어떻게 작동하나요?

PDF.js는 문서의 텍스트 레이어 — 리더에서 선택할 수 있는 바로 그 텍스트 — 를 읽어 읽기 순서대로 줄을 다시 만들어요. 글자 크기를 문서의 중앙값과 비교해요: 훨씬 큰 줄은 최상위 제목이 되고, 적당히 큰 줄은 소제목이 돼요.

이미지와 레이아웃은 살아남을까요?

아니에요 — 그리고 이 도구는 처음부터 그렇게 말해요. Markdown 출력은 텍스트 재구성이에요: 이미지는 삽입되지 않고, 다단 레이아웃은 텍스트 순서가 허용하는 한 열별로 읽혀요. 픽셀 단위로 완벽한 사본을 원하면 PDF 자체가 문서예요. 이 변환은 단어를 재사용하기 위한 것이에요.

내 PDF는 스캔이에요. 작동할까요?

스캔한 PDF에는 텍스트 레이어가 없어서 추출이 아무것도 찾지 못해요. 먼저 Loona Text Tools의 OCR 도구로 스캔을 실행한 뒤, 결과 텍스트를 변환하세요.

내 PDF가 업로드되나요?

아니에요 — 추출은 PDF.js로 브라우저에서 실행돼요.

내부 구조

추출은 텍스트 항목을 세로 위치로 줄에 묶고, 왼쪽에서 오른쪽으로 정렬하며, 각 줄의 글자 크기를 페이지 중앙값과 비교해 제목 수준을 지정해요. 페이지 구분은 구분자가 돼요. 결과는 위의 편집기에 나타나서 다운로드하기 전에 무엇이든 고칠 수 있어요. PDF 변환은 절대 완벽하지 않으며, 그렇지 않은 척하는 것은 정직하지 않아요.

실제 예시

12페이지 PDF 보고서는 구조화된 Markdown 문서가 돼요. 제목은 최상위 제목으로, 섹션 제목은 소제목으로, 본문은 단락으로 변환되어 웹사이트나 문서 편집기에 붙여 넣을 준비가 돼요.
