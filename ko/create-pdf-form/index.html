온라인으로 PDF 양식 만들기 - 무료

요약하면: PDF 양식 만들기 도구는 모든 일반 PDF에 실제 입력 가능한 입력란을 추가해요: 입력란이 있어야 할 페이지 위치에 상자를 드래그하고, 이름을 지정하고, 텍스트 입력란이나 확인란을 선택한 뒤, 어떤 리더에서도 채울 수 있는 진짜 AcroForm PDF를 다운로드하세요. 우리 자신의 PDF 양식 채우기 도구를 포함해요.

많은 양식은 줄만 있는 평면 페이지라 아무도 입력할 수 없어요. 이 도구는 그 줄 위에 진짜 양식 입력란을 올려서, 양식을 보내는 사람들이 인쇄하는 대신 휴대폰이나 컴퓨터에서 채울 수 있게 해요.

클릭해서 PDF 파일을 선택하세요
또는 여기에 끌어다 놓으세요 - 평면 양식, 편지 또는 문서예요

페이지 위를 드래그해 입력란의 상자를 그린 뒤 "입력란 추가"를 클릭하세요. 그리지 않고 추가하면 페이지 가운데에 표준 상자가 배치돼요. 입력란 이름은 고유해야 해요.

설계부터 비공개: 파일은 JavaScript로 브라우저에서 100% 처리돼요. 서버에 절대 업로드되지 않고, 저장되지 않고, 우리가 볼 수 없어요. 탭을 닫으면 모든 것이 사라져요.

이 도구 사용법

  1. 어떤 PDF든 선택하세요. 예를 들어 빈 줄이 있는 평면 양식이에요.
  2. 페이지 위를 드래그해 답변이 들어갈 상자를 그리세요.
  3. 입력란 이름을 지정하세요(예: student_name). 텍스트 입력란이나 확인란을 선택하고 입력란 추가를 클릭하세요.
  4. 모든 답변 공간마다 반복한 뒤, 입력 가능한 PDF를 다운로드하고 PDF 양식 채우기 도구에서 테스트하세요.

자주 묻는 질문

입력란은 실제 양식 입력란인가요, 그냥 그림인가요?

실제예요. 다운로드에는 pdf-lib로 만든 표준 AcroForm 정의가 들어 있어요: 입력란은 Adobe Acrobat, 브라우저, 그리고 우리의 PDF 양식 채우기 도구에서 지정한 이름을 가진 진짜 입력 가능한 입력란으로 나타나요.

어떤 입력란 종류를 추가할 수 있나요?

텍스트 입력란(한 줄)과 확인란이에요. 그것들이 대부분의 일상 양식을 커버해요. 드롭다운, 라디오 그룹, 서명 입력란은 여기서 제공되지 않아요. 그 제한은 가짜로 꾸미지 않고 솔직히 명시했어요.

입력란 이름은 왜 고유해야 하나요?

양식 입력란의 이름은 그 정체성이에요. 이름이 같은 두 입력란은 항상 같은 답변을 표시해요. 이 도구는 중복 이름을 막아서 양식이 올바르게 동작하게 해요.

추가한 뒤에 입력란을 이동할 수 있나요?

페이지 아래 목록에서 그것을 제거하고 수정된 위치에 다시 추가하세요. 입력란은 다운로드를 클릭할 때만 다운로드한 파일에 구워지므로, 여기서 실험하는 것은 무료예요.

작동 방식

도구는 실시간 페이지 미리보기에서 입력란 상자를 그릴 수 있도록 PDF.js로 PDF를 렌더링해요. 추가하는 각 입력란은 페이지 번호, 실제 PDF 포인트 좌표의 상자, 종류, 이름과 함께 저장돼요. 다운로드할 때는 pdf-lib가 원본 파일을 열어 맞는 AcroForm 입력란(각 항목마다 텍스트 입력란이나 확인란)을 만들고, 채우는 사람이 입력할 위치를 볼 수 있도록 밝은 배경과 테두리와 함께 저장된 위치에 각 입력란을 그 페이지에 추가해요. 결과는 전적으로 브라우저에서 만들어진 표준 입력 가능 PDF예요.

실제 예시

학교 사무실에 인쇄된 줄이 있는 평면 PDF 입학 신청서가 있어요. 사무원은 줄 위에 상자를 드래그하고 이름을 붙여요 student_name, date_of_birth 그리고 guardian_phone에 이름이 documents_attached를 누르고 양식을 다운로드해요. 이제 학부모님들은 PDF 양식 채우기 도구로 휴대폰에서 양식을 작성해 인쇄 없이 이메일로 보내 주세요.

자주 묻는 질문

위치는 PDF로 어떻게 변환되나요?

렌더링된 페이지에서 화면 픽셀로 그려요. 도구는 페이지의 실제 크기를 사용해 PDF 포인트로 변환하고 세로 축을 뒤집어요. PDF 좌표는 왼쪽 아래에서 시작하는데 화면은 왼쪽 위에서 시작하기 때문이에요.

입력란을 추가하면 내 문서의 페이지가 바뀔까요?

아니에요. 원본 페이지는 pdf-lib로 변경 없이 복사되고 양식 입력란이 위에 겹쳐져요. 텍스트, 이미지, 레이아웃은 있던 그대로 유지돼요.

텍스트 입력란 상자는 얼마나 커야 하나요?

양식에 인쇄된 빈 줄이나 상자의 대략적인 크기예요. 아주 짧은 상자는 일부 리더에서 입력한 텍스트가 시각적으로 잘릴 수 있으므로, 손글씨 크기의 공간에는 높이를 조금 더 주세요.

작성한 답변을 나중에 평탄화할 수 있나요?

네. 양식을 채우는 사람은 누구나 PDF 양식 채우기나 PDF 평탄화 도구를 사용해 최종적이고 변경할 수 없는 제출 사본을 위해 답변을 페이지에 구워 넣을 수 있어요.

양식은 휴대폰에서 작동하나요?

네 — 표준 AcroForm 입력란은 최신 휴대폰과 브라우저에 내장된 PDF 뷰어가 지원해요. 아주 오래되거나 최소한의 뷰어는 입력란 없이 페이지를 표시할 수 있어요.
