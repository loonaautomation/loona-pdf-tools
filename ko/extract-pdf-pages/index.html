온라인으로 PDF에서 페이지 추출 - 무료

요약하면: PDF 페이지 추출 도구는 선택한 페이지만(예: 3페이지와 5부터 8페이지까지)을 원래 순서대로 완전히 새로운 PDF에 복사해요.

60페이지 보고서에서 실제로 필요한 페이지가 네 페이지만 있으면, 그것들을 추출하세요. 페이지를 입력하고, 간결한 새 PDF를 다운로드한 뒤, 정확히 맞는 내용만 공유하세요. 그 이상도, 그 이하도 아니에요.

클릭해서 PDF 파일을 선택하세요
또는 여기에 끌어다 놓으세요
설계부터 비공개: 파일은 JavaScript로 브라우저에서 100% 처리돼요. 서버에 절대 업로드되지 않고, 저장되지 않고, 우리가 볼 수 없어요. 탭을 닫으면 모든 것이 사라져요.

PDF에서 페이지를 추출하는 방법

  1. 원본 PDF를 선택하고 페이지 수를 확인하세요.
  2. 유지할 페이지를 입력하세요. 예를 들어 3, 5-8이에요.
  3. "페이지 추출"을 클릭하고 새 PDF를 다운로드하세요.

자주 묻는 질문

추출된 페이지는 어떤 순서를 따르나요?

페이지는 목록을 어떻게 입력하든 항상 원래 문서 순서대로 나와요.

원본 파일이 바뀌나요?

절대 아니에요. 추출은 새 파일을 만들어요. 원본은 건드려지지 않아요.

한 페이지를 추출할 수 있나요?

네 — 7처럼 그 숫자를 입력하면 돼요.

추출하면 파일 품질이 낮아지나요?

아니에요. 페이지는 텍스트와 이미지가 그대로 복사돼요.

작동 방식

PDF는 기기에 남아 있어요: 브라우저는 pdf-lib로 그것을 열어 나열한 페이지(예: 3, 5-8)를 읽고, 완전히 새로운 빈 문서를 만들어 그 페이지만을 통째로 건드리지 않고 복사해요. 페이지는 다시 렌더링되는 것이 아니라 복사되기 때문에 텍스트는 선택 가능한 상태로 유지되고 이미지는 원래 품질을 유지해요. 새 문서는 이름에 -extracted가 붙어 다운로드되고, 원본 파일은 있던 그대로 남아 있어요.

실제 예시

교사는 40페이지 과정 교재 PDF가 있지만 내일 수업에는 챕터 연습 문제만 필요해요. 3, 5-8을 입력하고 추출을 클릭해요. 다운로드한 book-extracted.pdf에는 정확히 5페이지(3페이지와 5, 6, 7, 8페이지)가 들어 있어 학생들과 공유할 준비가 되고, 전체 교재는 컴퓨터에 그대로 남아 있어요.

자주 묻는 질문

한 번의 추출에서 단일 페이지와 범위를 섞을 수 있나요?

네 — 그 상자가 바로 그 용도예요. 2, 4-6, 11 같은 목록은 한 번에 2, 4, 5, 6, 11페이지를 하나의 새 PDF로 가져와요.

같은 페이지를 두 번 입력하면 어떻게 되나요?

한 번만 포함돼요. 목록은 원하는 페이지의 집합으로 취급되어, 목록의 중복이 결과에 중복된 페이지를 만들지 않아요.

여러 개의 서로 다른 PDF에서 한 번에 페이지를 가져올 수 있나요?

아니에요, 추출은 한 번에 한 문서에서만 작동해요. 실용적인 방법은 각 파일에서 필요한 것을 따로 추출한 뒤 PDF 병합 도구로 결과를 결합하는 것이에요.

추출된 파일에 북마크와 링크가 보존되나요?

페이지 자체는 완전히 복사되지만, 추출된 문서는 새로 만들어져 원본 파일의 북마크 개요는 이어지지 않아요. 페이지 자체에 인쇄되거나 그려진 링크는 페이지의 일부예요.

비밀번호로 보호된 PDF에서 페이지를 추출할 수 있나요?

아니에요. 페이지를 복사하려면 파일을 읽을 수 있어야 하며, 비밀번호로 잠긴 문서는 대신 오류를 표시해요. 먼저 원본 앱에서 비밀번호를 제거한 뒤 여기서 추출하세요.
