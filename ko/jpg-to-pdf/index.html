온라인으로 JPG를 PDF로 변환 - 무료

요약하면: JPG를 PDF로 변환 도구는 하나 이상의 JPG 이미지를 하나의 PDF 문서로 만들어요. A4, Letter 또는 이미지에 맞춘 페이지 크기를 선택할 수 있어요.

숙제 사진, ID 스캔, 영수증, 신청 문서는 하나의 PDF로 보내는 것이 더 쉬워요. JPG 이미지를 추가하고 페이지 크기를 설정하면 몇 초 만에 깔끔하고 공유 가능한 PDF를 다운로드할 수 있어요.

JPG를 PDF로 변환하는 방법

  1. 위 상자로 JPG 이미지를 하나 이상 추가하세요(PNG 파일도 가능해요).
  2. 페이지 크기로 A4, Letter 또는 이미지에 맞추기를 선택하고, 방향과 여백도 선택하세요.
  3. "PDF 만들기"를 클릭하고 문서를 다운로드하세요.

자주 묻는 질문

여러 JPG를 한 PDF에 넣을 수 있나요?

네. 각 이미지는 목록에 표시된 순서대로 한 페이지가 돼요.

어떤 페이지 크기를 골라야 하나요?

A4는 대부분의 양식과 인쇄에 잘 맞아요. Letter는 미국에서 흔해요. 이미지에 맞추기는 각 페이지를 이미지의 비율과 정확히 같게 만들어요.

내 사진이 업로드되나요?

아니에요. PDF는 전적으로 브라우저에서 만들어져요. 이미지는 기기를 절대 떠나지 않아요.

도구가 사진 품질을 낮추나요?

이미지는 원래 품질로 삽입돼요. 페이지에 맞게 조정될 뿐 다시 압축되지 않아요.

작동 방식

추가하는 각 이미지는 pdf-lib로 브라우저 안에서 새 PDF에 삽입돼요. 사진은 절대 업로드되지 않아요. JPEG 파일은 다시 인코딩하지 않고 바이트 단위로 정확히 그대로 저장되고, PNG 파일은 무손실로 삽입되어 PDF 속 사진은 원본과 동일해요. 모든 이미지는 목록의 순서대로 한 페이지가 돼요. 페이지 크기(A4, Letter, 또는 각 페이지를 이미지 크기와 정확히 같게 만드는 맞춤), 방향, 여백을 선택하면 각 사진이 페이지 안에 맞게 조정되어 가운데에 배치돼요. 완성된 파일은 images.pdf로 다운로드돼요.

실제 예시

휴대폰으로 여섯 페이지 종이 양식을 촬영했고 사무실은 PDF 하나를 요청해요. 사진 여섯 장을 추가하고, 페이지 크기는 A4, 방향은 자동, 여백은 작음으로 유지한 뒤 버튼을 클릭하세요: images.pdf가 A4 페이지당 사진 하나씩, 각각 여백 안에 깔끔하게 맞춰져, 촬영한 순서대로 도착해요.

자주 묻는 질문

JPG뿐 아니라 PNG 이미지도 사용할 수 있나요?

네. 도구 이름에도 불구하고, 선택기는 JPG와 PNG 파일을 모두 받고, 한 목록에서 섞을 수 있어요. JPEG는 있는 그대로 삽입되고 PNG는 무손실로 삽입돼요.

페이지 순서를 어떻게 바꾸나요?

페이지는 목록의 순서를 따라요. 이미지를 추가한 순서예요. 여기에는 드래그로 순서 바꾸기가 없어요: 사진을 이동하려면 제거 버튼으로 제거하고 다시 추가해서 끝에 합류하게 하며, 원하는 순서를 만들면 돼요.

'이미지에 맞추기' 페이지 크기는 무엇을 하나요?

모든 페이지의 크기를 자체 그림에 맞춰요. 이미지의 픽셀은 픽셀당 0.75 포인트, 즉 표준 화면-인쇄 배율로 변환되어 사진 주위에 테두리도 빈 페이지 영역도 없어요.

여백은 실제로 얼마나 큰가요?

작음은 모든 면에서 28 포인트(약 10 mm)이고 큼은 56 포인트(약 20 mm)예요. 없음은 사진을 가장자리까지 배치하지만, 대부분의 가정용 프린터는 용지 가장자리까지 인쇄할 수 없어요.

휴대폰 사진이 PDF에서 옆으로 나와요. 왜 그런가요?

도구는 이미지의 저장된 픽셀 치수를 읽어요. 그리고 일부 휴대폰은 실제 방향에 대한 메모와 함께 사진을 옆으로 저장하는데, 이 단순한 삽입은 그것을 적용하지 않아요. 먼저 갤러리나 사진 앱에서 사진을 회전한 뒤 다시 추가하세요.
