자주 묻는 질문

포인트는 무엇을 뜻하나요?

포인트는 PDF의 기본 단위예요: 72 포인트 = 1 inch = 25.4 mm. A4는 595 x 842 포인트이고, US Letter는 612 x 792 포인트예요.

한 파일에서 페이지마다 크기가 다른 이유는 무엇인가요?

병합, 스캔, 내보내기는 크기가 섞이는 경우가 많아요. 예를 들어 A4 텍스트 페이지와 Letter 크기 양식이 섞여요. 표는 각 페이지의 가장 가까운 표준 크기를 알려 줘서 이상한 페이지가 눈에 띄어요.

이 도구가 내 PDF를 바꾸나요?

절대 아니에요. 브라우저에서 파일을 읽기만 하고 찾은 것을 표시해요. 다운로드가 만들어지지 않아요.

표에서 회전은 무엇을 뜻하나요?

일부 페이지는 회전 표시(90, 180, 270도)와 함께 옆으로 저장돼요. 뷰어는 그 표시를 따르고, 표시되는 치수는 저장된 페이지 상자이며, 회전은 별도로 나열되어 PDF 회전 도구로 영구적으로 고칠 수 있는 페이지를 찾을 수 있어요.

작동 방식

검사 도구는 브라우저에서 파일을 두 번에 걸쳐 열어요: pdf-lib는 문서 정보(제목, 작성자, 만든 프로그램, 제작자, 페이지 수)와 각 페이지의 크기와 회전을 읽고, 원시 파일 헤더는 PDF 버전을 제공해요. 모든 페이지의 너비와 높이는 포인트에서 밀리미터(x 25.4 / 72)와 인치( / 72)로 변환된 뒤, 허용 오차가 몇 포인트인 표준 용지 크기 표와 맞춰져요. 모든 것은 읽기 전용이에요.

실제 예시

병합한 10페이지 보고서가 제대로 인쇄되지 않아요. 검사 결과 1-9페이지는 A4인데 첨부 양식인 10페이지는 US Letter이고 90도 회전되어 있었어요. PDF 페이지 크기 조정과 PDF 회전에서 금방이면 재인쇄가 완벽해져요.

PDF 버전은 어디에서 오나요?

파일 헤더와, 있을 경우 문서 카탈로그에서 가져와요. PDF 1.7처럼 파일이 준수한다고 주장하는 버전이에요.

센티미터로 크기를 볼 수 있나요?

밀리미터는 모든 페이지에 표시돼요. 센티미터는 10으로 나누세요. 인치는 Letter 방식 작업을 위해 소수점 두 자리까지 표시돼요.
